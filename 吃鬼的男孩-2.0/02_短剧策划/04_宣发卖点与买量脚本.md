### 1.2 用户心理唤醒点（2.0 新增第四条）

| # | 唤醒点 | 观众心里的问题 | 2.0 素材承担方式 |
| :--- | :--- | :--- | :--- |
| 1 | **好奇心** | 手掌心怎么会长嘴？还能吃怪物变强？ | 第 2-4 集奇观直给，不解释 |
| 2 | **宣泄感** | 被权贵欺负，能反手轰吗？ | 第 10 集碎桌、第 8 集震飞 |
| 3 | **爽感反差** | 冷艳女魔王怎么被驯成吃货？ | 第 78 集收服 + 第 85 集小龙虾 |
| 4 | **代价感（2.0 新增）** | 吃那么多怪物，他会不会被怪物吃掉？ | 每一次吞噬都留痕：干呕、反噬、掌心不受控咬合、纱布咬破 |

* **第四条为什么值钱**：1.0 的张陈越吃越强、零负担，爽感是"免费的"。2.0 把代价做成显性线索，爽感立刻升级为"悬着的爽"。
* 观众开始担心「主角会不会失控」时，续看动机从"看爽"变成"看他扛不扛得住"。这是 2.0 唯一能撑住 113 分钟总时长的心理引擎。
* 代价感只在 **余韵拍**显形。1.0 没有余韵拍，所以 1.0 素材无处可剪——这正是必须另剪一支的实操原因。

### 1.3 2.0 宣发三句定位

* **给投流渠道**：三秒给你一只会吃怪物的右手。
* **给追更用户**：这只手每吃一次，都在拿命付账。
* **给付费用户**：五道墙后面，是这个世界上真正吃人的东西。

## 二、 双节奏模型对照（本文档核心）

### 2.1 两套模型对照表

| 维度 | 正片（2.0 本体） | 投流切片（信息流素材） |
| :--- | :--- | :--- |
| **时长** | 60-75 秒 | 15-35 秒 |
| **目标** | 追更、留存、付费 | 3 秒内不划走 |
| **开头** | 可从场景/人物状态起 | 必须 3 秒内抛奇观 |
| **结尾** | 三级钩子（强/软/留白） | 强钩 + 明确引导（点击/下载） |
| **节奏** | 四拍循环 | 单向冲刺，节拍拉满 |
| **语气** | 叙事、留白 | 台词直给、信息量前置 |
| **单集结构** | 呼吸拍→升级拍→释放拍→余韵拍 | 无结构，只有一条向上的强度曲线 |
| **平均镜头长度** | 4-8 秒，余韵拍可到 12 秒 | 1.2-2.5 秒，超过 3 秒即判死 |
| **信息密度** | 每集只交付 1 件事 + 1 个信息增量 | 35 秒内塞 4 件事：压迫、奇观、兑现、引导 |
| **必须出现** | 代价留痕、关系变化、留白 | 0-3 秒奇观 + 明确的行动指令 |
| **绝对不能出现** | 无 | 铺垫、余韵、解释性台词、慢镜头 |
| **素材来源** | 正片本体 | **另剪一支**（见 2.2 / 2.3） |
| **成功判据** | 次日留存、付费转化率 | 3 秒完播率、点击率 |
| **单条剪辑工时** | 1 集 ≈ 1-1.5 天 | 1 支 ≈ 0.5 天（正片衍生） |

### 2.2 操作纪律（不可协商）

> **投流素材不是正片的压缩版，而是另剪一支。**
> 正片里可以铺垫 20 秒的余韵，素材里一秒都不能有。

* **禁止**：把正片某一集按比例缩短当素材。余韵拍、关系沉淀、信息增量，**全部砍掉**。
* **禁止**：用正片"完整性"绑架素材。素材的唯一 KPI 是 3 秒完播率。
* **要求**：正片 100 集 113 分钟，素材 35 秒。**压缩比 1:194**，不存在"等比压缩"，只存在"重选"。
* **实操判据**：素材里每一秒都要能回答"它承担了哪个职能"。答不出来，就是废话，砍。

### 2.3 双模型对拍摄端的反向要求

2.0 的双节奏不只是剪辑规则，**它要求正片拍摄时就多拍一版素材**。

| 要求 | 具体动作 | 落实集数 |
| :--- | :--- | :--- |
| **横竖两版** | 同一场戏，横版供长线物料，竖版供正片 | 全剧 |
| **补拍素材版** | 关键戏按 9:16 单独补拍一条 30-35 秒纯素材版，背景干净便于抠像 | 第 7-8、66、78、85 集 |
| **奇观独立机位** | 掌心裂口、巨口开合、虚影、邪神，单独机位单独打光，供素材 0-3 秒用 | 第 2、4、34、80、92 集 |
| **无台词版** | 关键释放拍补一条无台词版（只有音效），供字幕压字 | 第 8、10、34、78 集 |
| **代价特写** | 代价留痕补特写（干呕、反噬、掌心咬合、纱布渗色），2.0 独有的钩子素材 | 第 5、16、18、92 集 |

* **不做这一步的后果**：素材只能从付费区（第 19 集后）硬剪，平台审核与"我看过了"的体验会同时崩掉。
* 富江第 66 集才出场、第 78 集才收服，**没有补拍，素材 C 根本不存在**。

### 2.4 素材与正片的复用边界

| 素材级别 | 可用正片画面 | 限制 |
| :--- | :--- | :--- |
| **免费引流级** | 第 1-17 集全量 | 无限制，优先使用 |
| **付费露点级** | 付费区「前 3 秒」镜头 | 仅限平台允许的付费预告位 |
| **补拍级** | 另行拍摄的素材版 | 无限制，唯一无风险来源 |

### 脚本 A：【奇观爆点向 - 开局右手吃怪】

#### 主体分镜（沿用 1.0）

* **最重要的一处修正**：1.0 素材 A 的"吞噬混混"在 2.0 **没有对应镜头**，且是人体吞噬，触碰合规红线。2.0 的吞噬段落**必须改取第 4 集**（天台水魅元素生物首吞，炸成蓝黑光斑）。第 7-8 集的混混只承担"被震飞"，不进入巨口。

* **砍掉的**：第 8 集余韵拍里林清雪追问"那东西不是普通生物"的整段对话。1.0 素材不承担世界观任务。
* **必须留下并加进 1.0 没有的东西**：第 4 集余韵拍里张陈蹲在食堂干呕、闻到红烧肉只觉得"有点香"的**代价特写**。放进第 16-30 秒段尾，让"爽"和"疼"同时落地。

#### 素材剪辑说明

* **核心剪法是手部匹配剪辑**：第 6 集"张陈握住赵鹏的手腕" → 切 → 第 10 集"张陈的手按上五公分厚的实木课桌"。中间跨 4 集，用同一个手部动作做接缝，观众感知不到跳跃。这是 2.0 拉长铺垫后的必然手法。
* **砍掉的**：第 3 集呼吸拍里张陈返校后同学避他如蛇蝎的全景（约 15 秒），只留"只有王艺芷照常把热豆浆放在他桌上"这一拍。
* **砍掉的**：第 6 集里张陈"没动手，只把碗捡起来吹干净灰放回她手里"的克制处理——**但这一拍必须作为 4-15 秒的开头保留**，它是后面爆发的势能来源。
* **砍掉的**：第 11 集班主任索赔、首富之女林清雪一亿站台。这些是信息增量，对素材是纯噪音。
* **必须留下**：第 11 集里王艺芷**默默走过去把张陈散落的书一页页捡回桌上**。1.0 的"校花眼中异彩连连"太轻，2.0 的这一拍更克制，也更贴 2.0 的余韵拍调性。
* **为什么这样砍**：脚本 B 的全部说服力来自"一个动作"（一按碎桌）。铺垫越少，这个动作越炸。所有不服务于"这一按"的镜头都砍。

### 脚本 C：【反差萌与修罗场向 - 驯服冷艳女魔王】

### 6.2 卡点前 2 集预热通则

* **预热素材不等于正片预告**，是从素材库里挑"最接近卡点"的那一支，做**定向加权**投放，不新增制作量。
* **预热只做加法不做减法**：卡点前 2 集是流量峰值窗口，此时**只加投放预算，不换素材方向**。临卡点换素材 = 重新跑学习期。
* **素材的导流落点必须早于卡点**。导流到卡点前一集最稳妥，导流到卡点集会让观众看到解答，付费欲归零。
* **代价感素材在每个卡点前都必须有一支**。2.0 的付费理由不只是"看结果"，还有"看主角扛不扛得住"。

### 6.4 两条纪律

* **素材永远不领先正片超过 3 集**。第 61 集才播的孤岛血庄，素材绝不能提前把富江的收服当主线推给所有人，否则第 78 集卡点的稀缺性归零。
* **正片改了，素材必须重剪**。2.0 后续任何一集重拍，第三章三条素材与第四章两支合集**同步返工**，素材库与正片库共用一份集数对照表。
