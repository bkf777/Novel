## 〇、执行口径（美术开工前必读）

### 0.1 色名取值口径

| 类别 | 允许色名 | 依据 |
| :--- | :--- | :--- |
| 主色板 | 夜灰蓝 / 骨白 / 旧金 / 暗青 / 血珀 / 冷白 / 墨黑 | 总纲 2.1 |
| 角色色标补充 | 深灰制服 / 冷白（镇夜司系）、象牙白 / 银发（罗丹） | 总纲 2.3 |
| 粒子化特效 | 蓝黑色光斑粒子（边缘冷白、核心暗青） | 总纲 4.2 |
| 档案描述归一 | 档案"浅灰"→骨白降饱和；档案"浅灰蓝"→夜灰蓝 | 各角色色彩卡注 |

> **允许的加工**：只允许对色板色做降饱和、提亮与冷暖偏移（骨白偏灰、墨黑提亮为骨白），不允许引入新色相。
> **禁止**：出现上表之外的任何色名；任何颜色都必须能落到上表某一格，否则退修。

### 0.2 锚点分两类

| 类别 | 定义 | 是否随状态码替换 |
| :--- | :--- | :--- |
| 恒定锚点 | 骨架、比例、疤痕、永久性物件 | 全剧不换，用于三视图对齐 |
| 状态标记 | 服装、发色、可替换道具 | 随 S 码替换，不计入锚点 3-5 条配额 |

> 降级型角色（赵鹏）必须保住 ≥3 条恒定锚点，否则第 37 集之后的他会被观众认成新人。

### 0.3 状态码语义

S0-S6 定义见总纲第五节，本文件只列各角色**实际会用到**的码。人类角色按自身生理与心理反应落地，不强套特效。同一集最多跨 2 个码（例：周铮第 59 集 S5→S2）。

### 0.4 通用禁制

禁止血腥、尸体、幼态形象、惩戒性身体接触；异化体消解一律蓝黑色光斑粒子；暴力止于击飞、击晕、击退；恐怖点声音先于画面。

### 1.4 连续性锚点（恒定）

1. 左颊 2cm 横向旧疤
2. 比张陈高 4-5cm 的肩高压迫比例
3. 方圆下颌 + 宽厚颈围
4. 说话前用手背蹭鼻尖的习惯动作
5. 手腕永远戴一件东西（绳 → 电子表），位置不变

### 1.5 色彩卡

| 项 | 色名 | 说明 |

| 主色 | 夜灰蓝 | S0 卫衣与牛仔，S2 下装 |
| 辅色 | 骨白 | 内搭与 S2 衬衫 |
| 受限色 | 旧金 | 仅挑染窄条，单帧面积 ≤2%，仅 6-36 集；第 37 集后退场 |
| 禁止色 | 血珀、墨黑 | 他不与异化体同框，不得出现危险色与深渊色 |

### 1.6 表演锚点

1. 愤怒时下巴前伸、颈侧血管鼓起，手不抬起来只攥拳头
2. 恐惧时脚跟先退半步，肩膀缩起，手挡在脸侧
3. 强撑场面时把礼盒或手机举到胸前当作挡板

### 1.7 竖屏适配

鞋与卫衣印位在 9:16 全身景别里落在最下缘，容易被裁：S0 的球鞋与 S2 的开胶鞋头必须另给低机位特写。挑染在竖屏上半屏安全，但窄条容易在动态中糊掉，补一档顶光下鬓角的静态近景。降级后的衬衫是本角色最强识别点，中景时让人物略偏画面上三分之一，领口空缺处保持露出。

### 1.8 合规自查

第 39 集赵母踩照片、第 59 集他被推上祭坛，两处都只能拍威胁与恐惧反应，不拍踩踏伤害与人祭画面。第 6-12 集对王艺芷的围堵止于围困与推搡，冲突一律改为"控制"而非施暴。

1. 说话时右手食指无意识摩挲左手腕内侧

### 2.8 合规自查

第 28 集血池按"暗青底 + 血珀薄层反光"处理，不出现人体浸泡、不出现飞溅、不出现液体飞沫。骨甲是骨白硬质甲片，不做血肉连接特写；第 36 集剥离全程走冷白细丝 + 暗青粒子，不出现骨骼与解剖细节。

1. 银发后梳、一丝不乱
2. 骨白手套（内衬血珀）
3. 长窄脸 + 高颧骨 + 抬头纹
4. 夜灰蓝调浅瞳，视线不移动
5. 笑容弧度固定，眼角不参与

### 3.5 色彩卡

| 项 | 色名 | 说明 |

| 主色 | 象牙白（总纲 2.3 指定，取骨白提亮口径） | 礼服、衬衫、手套 |
| 辅色 | 银发（2.3 指定）+ 血珀（手套内衬） | 血珀仅在腕口与 S1 眼下可见 |

### 3.6 表演锚点

1. 说话时用戴手套的指腹抚平桌沿或袖口褶皱
2. 笑容保持标准弧度，只有眼角不参与，看久了才觉不对
3. 怕死时左手在背后握拳，手套布料发出摩擦声，语速变慢

### 3.7 竖屏适配

银发与白手套是最强双识别：竖屏里脸放中央上半屏，手套落在下三分之一，背景必须是夜灰蓝或墨黑，银发才不会糊进背景。S3 血巨人体量不做全身横铺，用仰角只给下半个躯干与眼部，冷白瞳高光作为竖屏视觉锚点。

### 3.8 合规自查

第 66 集断臂、第 78 集跳入血池、第 82 集核心碎裂，三处均为禁制高危：断臂用空袖管与冷白残光，献祭只用声音与剪影，核心碎裂一律走蓝黑色光斑粒子，不出现血肉、内脏与自残细节。
