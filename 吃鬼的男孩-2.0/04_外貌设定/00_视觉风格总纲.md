# 《掌中有深渊》2.0 视觉风格总纲

> **本文件的作用**：为 100 集 × 60-75 秒竖屏短剧建立**可执行**的视觉规范。人物设定档案回答"这个人是谁"，本目录回答"这个人长什么样、怎么变、什么绝对不能出现"。
> **适用范围**：选角与定妆、美术与服化道、灯光、摄影、特效、AI 参考图生成、外包监制。
> **合规口径**：以《总案策划与过审指南》第五章"2.0 新增合规条款"为最高约束，本文件所有条目不得与之冲突。

---

## 一、 影像规格与总体基调

| 项 | 规格 | 说明 |
| :--- | :--- | :--- |
| 画幅 | 竖屏 9:16（1080×1920） | 全部构图按竖屏设计，禁止为横屏裁切余量 |
| 帧率 / 快门 | 25fps / 180° | 快门角度保持统一，避免跨集质感跳变 |
| 影调 | 低饱和、高对比，暗部不死黑 | 亮部保留细节，用于信息流素材二次剪辑 |
| 整体气质 | 暗黑冷调 + 人间暖光 | 异化体空间冷（青/蓝/紫），人间烟火暖（黄/红） |
| 禁止 | 彩色霓虹赛博感、大面积洋红滤镜、故障风 | 与"暗黑惊悚 + 现实校园"冲突 |

**核心视觉命题**：*一个普通少年的世界里，裂开了一道不属于人类的口子。*
所有美术决策都从这句话反推 —— 人的部分必须越接近"真实高中生活"越好，异化的部分才越有侵入感。

## 二、 色板

### 2.1 主色板

| 色名 | 色值 | 用途 | 占比建议 |
| :--- | :--- | :--- | :--- |
| 夜灰蓝 | `#141A24` | 夜戏基底、暗场、负空间 | 40% |
| 骨白 | `#E8E4DA` | 校服、绷带、张陈的肤色基调 | 20% |
| 旧金 | `#C9A227` | 唯一暖色焦点：张陈瞳色、神核符文、黑焰内芯 | 8% |
| 暗青 | `#2E5D6B` | 异化体主色、粒子光斑、镜渊世界 | 12% |
| 血珀 | `#8C2B2B` | 危险信号：血纹、血池、韩明指甲 | 6% |
| 冷白 | `#F2F6FA` | 强光、灵光、空间感知、念力 | 8% |
| 墨黑 | `#07090D` | 深渊、邪神、吞噬瞬间 | 6% |

### 2.2 色彩纪律

* **旧金是稀缺资源。** 每一帧里旧金（瞳色、神核、黑焰内芯）总面积不超过画面 2%。一旦金元素铺满，力量感立刻通货膨胀。
* **血珀只用于"危险"，不用于"暴力"。** 2.0 的暴力表现统一为击飞/击晕/击退，命中瞬间用冷白或暗青的冲击波，**不使用血珀飞溅**。
* **张陈与王艺芷的服装主色必须落在骨白与校服蓝白**，这是他们"仍是人"的视觉凭证。异化只允许从**手**开始扩散，不允许爬到脸和身体（脸是他的最后一道防线）。
* **富江是唯一允许大面积冷紫的角色**，因为她是"外来物"。

### 2.3 角色色标

| 角色 | 主色 | 辅色 | 禁止色 |
| :--- | :--- | :--- | :--- |
| 张陈 | 骨白 / 校服蓝白 | 旧金（瞳/焰） | 血珀、墨黑（除吞噬瞬间） |
| 王艺芷 | 米白衬衫 / 浅蓝 | 血珀（仅血纹） | 旧金（她不是力量方） |
| 富江 | 冷紫 / 墨黑长发 | 暗青粒子 | 暖黄、暖红 |
| 贾心 | 浅灰布衣 | 旧金（符咒/卦光） | 血珀 |
| 苏晚 | 黑色作训服 | 冷白 | 旧金 |
| 镇夜司 | 深灰制服 | 冷白 | 旧金、暖色 |
| 暗界议会 | 墨黑 | 旧金封条 | 暗青 |
| 罗丹 | 象牙白 + 银发 | 血珀（手套内衬） | 暗青、暖色 |

## 三、 光线规则

| 场景 | 主光 | 补光 | 禁止 |
| :--- | :--- | :--- | :--- |
| 校园日常（人间） | 侧窗自然光，暖 5200K | 反射补光 极弱 | 硬顶光、舞台感打光 |
| 校园夜景 | 路灯偏橙 + 环境冷蓝 | 眼神光 保留 | 纯色洗墙 |
| 异化体出没 | 冷青侧逆光 5200K→7000K | 无补光，允许死黑 | 暖光、正面照明 |
| 吞噬瞬间 | 暗青粒子自发光 + 旧金内芯 | 人物面部保持 70% 暗 | 白色爆闪、血红滤镜 |
| 镜渊世界 / 血庄 | 单一光源（烛/祭坛），人物半明半暗 | 无 | 均匀照明、彩色氛围灯 |
| 邪神虚影 | 墨黑吞光，只留轮廓边缘冷白 | 无 | 内部细节、面部 |

**竖屏取景提示**：竖屏横向信息量有限，**同一屏最多 2 个视觉重心**。三人以上同框时，中间人必须降低对比度，否则竖屏会糊成一团。

## 四、 造型语法

### 4.1 绷带系统（张陈专属，全剧最重要的一件道具）

右手白色运动绷带是张陈的视觉签名，也是**叙事进度条**。它的状态随剧情推进而变化，是最省力的连续性提示。

| 阶段 | 绷带状态 | 出现集数 |
| :--- | :--- | :--- |
| 常规缠法 | 右手掌根至手腕，3-4 圈，露出指尖 | 1-3 |
| 应急加缠 | 5-6 圈，边缘起毛，渗出一点暗色 | 4-17 |
| 血战加缠 | 全新绷带，缠法更厚更笨拙（藏能力） | 18-35 |
| 战损 | 绷带被咬破一处，边缘焦黑 | 36 |
| 主动拆解 | 只剩手腕一圈，掌心完全暴露 | 80 集后 |
| 完全体 | 无绷带，掌心本身就是一张嘴 | 94 集后 |

### 4.2 粒子化规范（异化体消解，2.0 合规强制）

* 形态：**蓝黑色光斑粒子**，边缘带冷白高光，中心有暗青核心。
* 运动：先向吞噬点塌缩，再被"吸入"，**全程不产生血液或残肢**。
* 声音：细密的"噼啪"声，类比烧红的炭，不使用撕裂/咀嚼的血腥音。
* 密度：单体异化体消解时粒子数在 300-800 之间，避免糊屏。
* 禁止：出现牙齿/骨渣/血雾/残肢/内脏等任何实体残留。

### 4.3 黑焰与深渊口

* **黑焰**：暗紫到墨黑的渐变，内芯一道旧金细线。**只缠在右臂**，不蔓延全身。
* **深渊口张开时的视觉顺序**：先裂皮（暗金符文自裂缝渗出）→ 再开合（獠牙为骨白，齿列约 12-14 枚）→ 最后内壁深不见底（纯墨黑，不做口腔血肉细节）。
* 竖屏建议：口器特写建议给**下半屏**，上方留人物面部，避免观众只看到嘴。

## 五、 状态变体命名规范

每个角色按剧情阶段定义变体代码，用于美术、置装、选角、生成式素材的标签体系。**代码在全项目通用，不得自造。**

| 代码 | 含义 | 通用特征 |
| :--- | :--- | :--- |
| **S0** | 日常 / 初始 | 校服或常服，妆感干净，识别度靠五官不靠特效 |
| **S1** | 觉醒初成 | 局部异变首次出现（手/眼/瞳），强度低于 S2 |
| **S2** | 战斗态 | 服装破损或战损，异变特征外显，呼吸加重 |
| **S3** | 完全释放 | 特效全开，姿态改变，**脸部仍保留人味** |
| **S4** | 崩溃 / 失控 | 特效反噬，异变开始侵蚀非受控部位 |
| **S5** | 代价显形 | 常态化后遗症，人物带伤、带疤、带习惯性动作 |
| **S6** | 终局 / 非人 | 人的部分减少，**冷白或墨黑成为主色** |

**通用纪律**：任何一个角色在同一集内**最多跨越 2 个状态码**。跨 3 个状态会让观众来不及建立识别。

## 六、 连续性锚点规则

每个角色必须确定 **3-5 个不可变特征点**，用于多机位拍摄、外包监制、AI 参考图生成时的对齐。锚点一经确定，全剧不换。

| 角色 | 锚点示例 |
| :--- | :--- |
| 张陈 | ① 右手掌根白绷带 ② 拉链拉到第二颗的旧校服 ③ 眼尾向下的单眼皮 ④ 左手腕内侧一道旧疤 |
| 王艺芷 | ① 剪到极短的指甲 ② 齐耳内扣黑发别一枚素色发夹 ③ 左眉尾一颗小痣 ④ 校服裙右侧第二颗扣子换过 |
| 富江 | ① 左眼角泪痣 ② 墨黑长直发过腰 ③ 锁骨下方第二道旧伤痕（**不展示细节，仅轮廓**） ④ 瞳孔猩红时虹膜边缘有细碎裂纹 |
| 贾心 | ① 白纸折扇的扇骨少一根 ② 布衣右袖口磨破 ③ 拇指戴一枚素圈玉扳指 ④ 发髻歪在右侧 |
| 苏晚 | ① 左手腕编号手环 T-07 ② 短马尾露出后颈 ③ 作训服左肩磨损 ④ 旧铁盒边角磕痕 |

**AI 出图 / 参考图工作流**：每个角色先出一张**标准三视图**（正面/侧面/背面）锁定锚点，再由锚点派生各状态变体。任何一集出现与锚点冲突的造型，视为连续性事故。

## 七、 合规红线（视觉执行版）

| 红线 | 具体禁制 | 替代方案 |
| :--- | :--- | :--- |
| **血腥** | 血肉、内脏、伤口特写、血液飞溅、残肢 | 粒子化消解 / 冷白冲击波 / 击飞击晕 |
| **幼态** | 婴孩面孔、幼儿体型、婴儿鬼形象 | 一律"水魅元素生物"：青绿鳞片、尖耳、触须、异瞳 |
| **惊吓** | 慢镜头死亡、贴脸突袭、长时间尸体特写 | **声音先于画面**：先给声再给影，压迫时间靠留白 |
| **未成年人** | 惩戒性身体接触、扒衣、捆绑 | 冲突止于"控制"：压制、击退、控制住 |
| **恐怖留白** | — | 2.0 镜头更长，恐怖点应减频、加密前置声音提示 |

## 八、 交付与监制清单

美术与外包交付时，每个角色必须附带：

1. **标准三视图**（正面 / 侧面 / 背面，中性光，无特效）
2. **锚点清单**（3-5 条，逐条标注在图上）
3. **状态变体图**（按 S0-S6 该角色实际用到的码，每码至少 1 张）
4. **色彩卡**（含该角色主色/辅色/禁止色的色块与色值）
5. **竖屏构图参考**（1 张，确认在 9:16 下该角色的识别特征不被裁掉）
6. **合规自查表**（对照第七章逐条勾选）

**外包红线**：外包方交付的任一形象若与锚点冲突，或出现第七章禁制，**一律退修，不做局部修补** —— 因为观众对连续性的敏感远高于对单帧精致度的敏感。
