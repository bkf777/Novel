# 《掌中有深渊》2.0 主要角色外貌设定

> **规格依据**：`00_视觉风格总纲.md`。色板、光线、状态码 S0-S6、锚点规则、合规红线均以总纲为准，本文件不另立标准。
> **集数口径**：全部为 2.0 集数（100 集 / 60-75 秒规格）。
> **一句话原则**：这五个人的"人味"必须比"异化"更显眼。观众先认出张陈是那个穿旧校服的男生，再认出他掌心有一张嘴。

| 项 | 设定 |

| 眉 | 剑眉但眉峰不高，不凶，压得住 |

| 发 | 黑色短发，自己剪的，长度到眉骨，刘海能压住半只右眼；左边鬓角比右边短 |

### 1.4 连续性锚点

1. **右手掌根的白绷带**（任何状态都不离手，除 S6）
2. **校服拉链只拉到第二颗**
3. **眼尾向下的单眼皮**
4. **左手腕内侧的旧疤**
5. **左腿裤脚卷两折、右腿不卷**

### 1.5 色彩卡

| | 色名 |
| :--- | :--- |
| 主色 | 骨白（内搭、鞋）、校服蓝白（外套） |
| 辅色 | 旧金（瞳色、神核、黑焰内芯） |
| 禁止色 | 血珀（他不是暴力方，是吞噬方）、暗青（那是异化体的色） |

### 1.6 表演锚点

1. **抿唇先动**：压力越大，下唇先动一下再开口。
2. **压右手**：任何紧张场面，他的左手都会不自觉去按住右手绷带。
3. **看人先看喉咙**：他判断一个人危险不危险时，视线先落在对方的喉结和颈侧。

### 1.7 竖屏适配

* 绷带在右上角，**永远在画面右上三分之一**。张陈在左三分之一时，绷带仍要保持可见 —— 这是识别他的最快通道。
* S3 释放态时，人物不要居中满屏，右上留给黑焰，全屏留给脸。
* 掌部特写建议给**下半屏**，上方留他的脸。观众要看的是"人和口同时存在"，不是一张嘴。

### 1.8 合规自查

* 吞噬瞬间**不出现牙龈、口腔血肉、内壁肌肉**，口内纯墨黑。
* 鳞纹只在**手背与颈侧**，不上脸。脸是他与观众之间的最后契约。
* 与赵鹏等反派冲突一律止于"控制/击退"，不出现身体伤害细节。

### 2.4 连续性锚点

1. **剪到极短的指甲，不涂甲油**
2. **齐耳内扣黑发 + 右侧素色发夹**
3. **左眉尾小痣**
4. **校服裙右侧第二颗扣子换过（新扣子颜色略浅）**
5. **手环蝴蝶结的米白鞋带**

### 2.5 色彩卡

| | 色名 |
| :--- | :--- |
| 主色 | 米白（衬衫）、浅蓝（裙） |
| 辅色 | 血珀（**仅血纹**，且只在手背/手臂） |
| 禁止色 | 旧金（她不是力量方）、冷白（冷白属于苏晚与镇夜司） |

### 2.6 表演锚点

1. **说话前先看对方的手**：她的紧张表现为反复确认对方的手在哪里。
2. **倔强时的下巴微抬**：不认输的时候下巴会抬起来 1 厘米。
3. **护人的时候会往前半步**：不是挡在后面，是主动迎上去。

### 2.7 竖屏适配

* 她的识别点是**发夹和齐耳发**。竖屏里发型容易糊，发夹要选有反光的（金属边），保证在暗场也有一高光点。
* S3 血脉激发时，黑色血纹要沿手臂**自下而上**生长，在竖屏里形成一条向上的引导线，把视线带到脸。
* 与张陈同框时，她比他矮半头，构图上让他略微前移半步，确立保护关系。

### 2.8 合规自查

* 画室戏（21-23 集）**不出现肢体伤害细节**，韩明的施暴以镜面反光、脚步声、物品打翻暗示。
* 她是未成年人设定角色（18 岁），任何冲突止于"控制"与逃脱，不出现惩戒性身体接触。
* 血纹为"皮下墨色洇开"的表现，**不是伤口**，不出现破皮。

| 脸型 | 骨相重，不是甜美脸。下颌线利落，颧骨略高，眉眼浓而长 |

| 83 集后 | 上述 + 张陈塞给她的旧球鞋 | 第一次穿鞋，鞋大两号，走路时啪嗒啪嗒；第 85 集吃小龙虾时**球鞋还没脱** |

| 码 | 集数区间 | 外形变化 |

| **S2** | 67-71 集 | 战斗态：动作快到拖影（竖屏里靠残影和衣物破裂方向表达），发丝末端出现冷紫电弧 |

| **S4** | 89-90 集 | 被杀手打爆数次，**每次复原都不完全一样**：这一次左肩复原慢半拍，第二次发梢少了一截 |
| **S5** | 92-95 集 | 封门后，锁骨下的旧伤痕**第一次显形**（浅白痕，边缘有鳞状细纹） |
| **S6** | 96 集后 | 安静态。收敛煞气时气场女王，卸下防备时**像个刚睡醒的学生** —— 这是她最像人的时刻 |

### 3.4 连续性锚点

1. **左眼角泪痣**
2. **墨黑长直发过腰**
3. **瞳孔猩红时虹膜边缘的细碎裂纹**
4. **收服后大一号的黑卫衣与两号大的球鞋**
5. **锁骨下第二道旧伤痕（只给轮廓）**

### 3.5 色彩卡

| | 色名 |
| :--- | :--- |
| 主色 | 冷紫（煞气）、墨黑（发） |
| 辅色 | 暗青（粒子边缘、瞳裂） |
| 禁止色 | 暖黄、暖红（她不是人间角色）；骨白（除了囚服素白长袍） |

### 3.6 表演锚点

1. **先看再动**：她做任何攻击前，视线一定会先锁定目标的眼睛。收服后这个习惯保留，但改成"看张陈"。
2. **饿的时候舔嘴角**：她饿的时候会有一个极小的、她自己没意识到的舔嘴角动作。
3. **被夸奖时耳朵会红**：千年存在，耳朵还是会红。

### 3.7 竖屏适配

* 长发是她的**纵向武器**：竖屏比横屏更适合她，构图上让她**占满纵向**，头发从顶部垂到画面下沿。
* 暴怒时长发会散开占满背景，**但必须保留脸的可读性** —— 竖屏里头发糊脸是最常见的失败。
* 收服后穿大一号卫衣，**下摆盖过臀**是必要的：她仍然保留着"危险"的身体记忆，但衣物在替她说"她现在安全了"。

### 3.8 合规自查

* 她的锁骨伤痕**只给轮廓**，不给特写，不给成因画面。
* 暴怒时的"撕裂手臂"改为**复原与破损的光影**，不出现血肉。
* 收服后"抱住张陈大腿"（78 集）尺度需克制，镜头**不拍腰部以下**，保持在大腿以上的安全构图。

## 4. 贾心（19 岁）
