## 一、异化体形象设定

### 1.1 A-1 青皮水魅元素生物（一阶）

| 字段 | 设定 |
| :--- | :--- |
| 设计原点 | 暴雨夜"闷热 + 憋闷 + 说不出话"的地脉暗能，在天台积水里凝出的低阶畸变。它吞的是"没能说出口的话"，不是"人"。 |
| 体态 | 人形比例被拉长到 2.2 米，像泡胀后又被抽干；躯干半透，体内可见一条缓慢流动的水线；四肢过长，指间连蹼膜。 |
| 色彩 | 主色暗青 `#2E5D6B`（合规条款所称"青绿"落在暗青区间），鳞片边缘冷白 `#F2F6FA` 高光，甲壳缝隙透夜灰蓝。 |
| 材质 | 半透鳞片分哑光 / 湿润反光两版；蹼膜半透明带水珠；触须表面有黏液拉丝。 |
| 非人化特征 | ① 尖耳：向后长三角，耳廓中央透明；② 触须：头顶 4 条，末端各一颗冷白眼点；③ 魔纹：鳞缝里的旧金细线，图形不规则；④ 异瞳：单眼横瞳，瞳心一圈冷白环；⑤ 头部正面是一块光滑青灰甲壳，**不出现任何人类儿童阶段的面部比例**。 |
| 运动方式 | 不是跑，是"滑"：落地无声，关节反向折叠；出场时先从积水里立起再抽身；受击后身体散成水线再聚拢。 |
| 声音 | **先声于画面**：积水"嗒…嗒…嗒"三下（秒针节奏）+ 一层水下闷响；被咬住时是气泡破灭的"嘶"叠细密噼啪。禁用撕裂 / 咀嚼类音。 |
| 消解过程 | 触须末端先崩，蓝黑色光斑粒子（冷白边 + 暗青核心）分两批向掌心塌缩，再被吸入；粒子数 320-460。详见 §2.1。 |
| 出现集数 | 第 3 集（楼顶断续水声，纯前置声）→ **第 4 集首次被吞噬**（天台）→ 第 20 集后山迷障同类气息回响。 |

**执行补充**

| 项 | 规格 |
| :--- | :--- |
| 竖屏构图 | 全身不超过画幅 70%，头顶留白 15%，保证下集"张陈回头"有信息落点。 |
| 识别锚点 | ① 尖耳后长三角 ② 头顶 4 触须 ③ 面部青灰甲壳 ④ 单横瞳 ⑤ 鳞缝旧金细线。锚点全剧不换。 |
| 出场镜头 | 3 段：积水涟漪（0.8 秒）→ 触须先出画（0.6 秒）→ 全身一次（1.0 秒）。禁止贴脸。 |
| 禁做 | 不做可辨识的儿童体态与面部比例；不做人形化可爱造型；不做荧光赛博感。 |

### 1.2 A-2 溺死怨妇（二阶 · 执念体母体）

| 字段 | 设定 |
| :--- | :--- |
| 设计原点 | 长期被压在水下、无法上浮的那口"憋住的哭声"，与管道地脉暗能结合。它是"水往下走"这个方向的母体，所有下水道黑水的源头。 |
| 体态 | 核心不是人形。躯干是一团倒悬的"发巢"——直径约 1.2 米的黑色发丝球体，吊在天花板；下缘垂出 6-9 条主发触须，可延展到 4 米。下潜时贴地平铺，像一层会移动的黑水膜。 |
| 色彩 | 发丝墨黑 `#07090D`，逆光时每根发丝带冷白边光；巢心光核暗青；水位线浮一层旧金极细矿脉纹（占画面 ≤1%）。 |
| 材质 | 湿发质感，成股垂坠；滴落水珠呈吸光的墨色，不带任何暖红。 |
| 非人化特征 | ① 无脸：正面是一团旋涡状发流，看不到五官；② 无躯干四肢：只有发巢 + 触须；③ 发丝末端聚成"手"形但只有 3 根指，比例错乱；④ 光核睁眼时整颗亮起冷白横瞳；⑤ 触须可在管道内壁"贴合行走"。 |
| 运动方式 | 先"听"（楼道声波方向定向）→ 再"灌"（自下水道口以黑水柱涌上，配"哗——"）→ 最后"缠"（发丝以 0.2 米/秒收紧，节奏是心跳双拍）。 |
| 声音 | **先声于画面**：管道"咕噜咕噜"、隔墙水滴、像有人捂嘴在哭的气音（做远景混响，不做近景鬼叫）。缠人时给"布料被绞紧 + 呼吸变浅"的实感声。 |
| 消解过程 | 黑焰接触处起，黑发一根根化粒子，分 3 批向掌心**塌缩**，每批间隔约 0.4 秒，做出"被一点点抽走"的节奏；粒子数 420-800；塌缩完成后统一**吸入**掌心；最后光核单独崩解为 60-120 粒旧金粒子。 |
| 出现集数 | 第 16 集（代价拍，无实体出场）→ **第 17 集铺垫**（管道黑水与腥味，纯声音）→ **第 18 集爆发**（第一大付费卡点：黑发缠住王艺芷 → 黑焰撕开 → 噬核）。 |

**执行补充**

| 项 | 规格 |
| :--- | :--- |
| 竖屏构图 | 发巢吊在画面上三分之一，黑发触须向下贯穿全屏，形成"垂落压迫"；张陈面部保持在右上三分点。 |
| 识别锚点 | ① 无脸发巢 ② 3 指末端 ③ 暗青光核 ④ 发丝冷白边光 ⑤ 触须贴壁行走。 |
| 接触位 | 缠绕优先取雨伞柄、书包带、前臂等非致命接触点，画面不给颈部压迫特写；如需保留颈部缠绕，只给中景不给特写。 |
| 禁做 | 不做水面下人脸；不做可辨人形躯干；不做湿发贴身剪裁；不做红雾。 |

### 1.3 A-3 血指甲母体 / 血化异化体（三阶，篇章二主线）

| 字段 | 设定 |
| :--- | :--- |
| 设计原点 | 长期压抑的"把自己活成工具"的情绪，混进画室的颜料、松节油与溶剂，再被地脉暗能点燃。身体最先失控的部位是**指甲**。 |
| 体态 | 分两态。**宿主态**：仍是美术老师外形，不出现任何超自然体征。**母体态**（第 28 集撕开伪装）：半米猩红骨甲，十指骨甲呈扇形展开；躯干由画架、调色刀、绷紧画布拼合成人形，缝隙透血珀色微光。 |
| 色彩 | 血珀 `#8C2B2B` 作危险信号（≤6%），骨甲底色骨白 `#E8E4DA`，边缘冷白高光，魔纹旧金（≤2%），环境夜灰蓝。 |
| 材质 | 骨甲 = 哑光骨质 + 折光边；画布躯干 = 干裂帆布与结块油彩（油彩色相锁在总纲色板内）；魔纹为自发光刻线。 |
| 非人化特征 | ① 骨甲取代指甲，指节末端延伸为骨锥；② 每手只 4 指 + 1 根骨刺；③ 竖瞳、骨白虹膜；④ 体表油彩裂纹组成魔纹；⑤ 头部保留老师轮廓但被画板 / 调色板遮蔽，**不出现面孔**。 |
| 运动方式 | 僵直的"模特站姿"，关节反折，脚步整齐；攻击靠画框横扫与骨甲划出的 3 道冷白气痕（不呈现划破类画面）。 |
| 声音 | **先声于画面**：指甲划过画布的"沙——沙"、指甲轻敲调色盘的"哒哒"、没关严的美术柜门吱呀。撕开伪装瞬间先全静 0.8 秒（广播被切断感），再落音。 |
| 消解过程 | 骨甲尖端先崩，粒子向掌心方向退行并聚成一条线；分两段：塌缩 0.5 秒 → 吸入 0.8 秒；粒子数 500-800；画布躯干最后散成冷白薄片再转粒子。 |
| 出现集数 | 第 19 集（王艺芷血纹蔓延，伏笔）→ **第 20-36 集主线** → 第 22 集（女生集体异变）→ 第 28 集（撕开伪装，半米猩红骨甲）→ 第 29-30 集（反噬）→ 第 31-34 集（镇夜司收容战）→ 第 36 集（画室决战 + 念力觉醒）。 |

**执行补充**

| 项 | 规格 |
| :--- | :--- |
| 宿主态细节 | 只在三处失守：袖口下的指甲染成血珀、指甲缝暗色没洗净、剪下的碎屑满篓。观众靠"细节不对"自行发现。 |
| 中阶个体 | 第 22 集被感染的女生共用本节骨甲语言，但骨甲仅 3-5 厘米，不出现母体级体量。 |
| 识别锚点 | ① 半米骨甲扇形展开 ② 4 指 + 骨刺 ③ 画板遮面 ④ 油彩裂纹魔纹 ⑤ 4 脚画架躯干。 |
| 竖屏构图 | 骨甲占上半屏、躯干压下半屏形成上下夹击；第 28 集"撕开伪装"给 1 次全身 1.5 秒。 |
| 禁做 | 不做可辨面孔；不做眼白翻出式狰狞；不做红雾与液体迸出；不做整洁对称构图。 |

### 1.4 A-4 千眼血巨人（三阶顶峰 · 融合体）

| 字段 | 设定 |
| :--- | :--- |
| 设计原点 | 罗丹把整座山庄的"贪"（对天赋的掠夺、对永恒的贪）灌进地脉熔炉，与炉中千年母体融合 —— 一具由上百份猎手贪心合成的容器。原型是**贪**，不是**痛**。 |
| 体态 | 约 100 米高，人立，但比例是"叠罗汉"式的臃肿：躯干由数十层骨甲、铁板、画布、人形台座层层堆叠，像一座会动的塔；双臂长度超过身高，垂地拖行。 |
| 色彩 | 骨白（骨甲）40% + 夜灰蓝（阴影雾）为主，血珀只用于眼群虹膜且靠密度压住占比，冷白作眼白高光；旧金仅出现在胸腔主眼一道细线。 |
| 材质 | 骨甲哑光，熔接缝冷白自发光，像岩浆冷却后的纹路；眼睑为薄骨膜。 |
| 非人化特征 | ① 千眼：上半身骨缝中约 1000 只，直径 0.5-1.2 米，成簇不规则排布，睁开时像一片灯阵；② 头是罗丹面孔的放大底图，被眼群打散，不做清晰五官；③ 每手 3 指，指尖为骨锥；④ 整体无人类体态比例。 |
| 运动方式 | 慢。每步 2-4 秒，落地时地面先出现形变与冷白压力波纹；抬手是 3 秒预告动作（手臂抬起时全身眼睛同时转向目标）。 |
| 声音 | **先声于画面**：远端 30Hz 以下体感低频嗡鸣、骨甲互相摩擦的"咔咔"如冰裂、千百眼睑同时张开的细密"噗噗"；核心开启时是"炉门开风"式长吸气。 |
| 消解过程 | 不是被整吞，是被"拆"：骨甲层逐层剥落，每层表面先**塌缩**成一条向上的粒子流（层间递减 800 → 600 → 400），再被右臂**吸入**；第 82 集罗丹本体单独塌缩为 300-500 粒后吸入掌心。 |
| 出现集数 | 第 77 集（献祭铺垫）→ **第 78 集成型**（第四大付费卡点）→ 79（睁眼）→ 80（饕餮虚影对撞，啃掉半边头颅）→ 81（雷阵打散）→ 82（本体崩解，核心被吸收）。 |

**执行补充**

| 项 | 规格 |
| :--- | :--- |
| 识别锚点 | ① 百米骨塔躯 ② 千眼成簇 ③ 三指骨锥 ④ 熔接缝冷白 ⑤ 胸腔主眼旧金细线。 |
| 眼群设计 | 眼群不做"整片同开"，分 3 档：先 1/10 亮（预警）→ 再 1/3（聚焦）→ 全亮（核心开启）。这是全剧唯一允许的成规模光效。 |
| 竖屏构图 | 竖屏拍不下 100 米，改用"仰角取下半身 + 雾中眼群"两段式：第 78 集只给腰部以下与拖地双臂，全貌留到第 79 集用远景 + 竖屏压缩天空表现。 |
| 比例锚定 | 每次出现必须带一个人类尺度参照（人物 / 建筑 / 车辆）同框，否则百米感消失。 |
| 禁做 | 不做清晰面孔；不做眼球高倍率特写黏在脸上；不做整片眼白泛红；不做层叠剥落时的碎片乱飞。 |

### 1.5 A-5 邪神虚影（神话级 · 终极）

| 字段 | 设定 |
| :--- | :--- |
| 设计原点 | 镜渊世界被压缩、被折叠后形成的"投影残影"—— 不是活物，是空间本身在低语。规则只有一条：**能描述轮廓，不能描述内容**。 |
| 体态 | 黑雾凝成的人形，高约百丈。第 92 集自黑云中探出躯干，只见上半身。肩宽达身高三分之一，无颈部，头与肩直接连成一片雾墙；触须自肩背垂落 30-80 米，末端渐隐为雾。 |
| 色彩 | 主体墨黑 `#07090D` 吞光，边缘 1-2 厘米冷白轮廓光；体表碎影用暗青与夜灰蓝，亮度不超过冷白；**内部无任何细节**（总纲：禁止内部细节与面部）。 |
| 材质 | 黑雾 + 冷白边缘 + 碎影的折射玻璃感；碎影是被压扁的薄片，贴在雾面上流动。 |
| 非人化特征 | ① 无脸、无五官、无眼；② 无"手"，只有触须；③ 比例不合理化（肩 / 身高 1:3）；④ 表面不反光、没有实体边界，看不出体积是怎么撑起来的。 |
| 运动方式 | 慢，但"错"：移动时不转身，是整体平移；触须先动、身体后到；第 92 集"探出躯干"是云层被顶开，而不是身体走出来。 |

## 二、特效执行细则

### 2.1 粒子化消解（总纲 4.2 逐条落地）

| 总纲 4.2 条款 | 可执行规格 |
| :--- | :--- |
| 形态 | 蓝黑色光斑粒子，边缘带冷白高光，中心有暗青核心。单粒直径 2-6 px（以 1080 宽为基准），呈不规则圆斑，不做方形像素。 |
| 颜色渐变 | 崩解瞬间保留异化体自身主色 0.2 秒 → 统一转蓝黑 → 塌缩中段转暗青 → 进入掌心前一帧才透出旧金内芯。 |
| 运动阶段 | **阶段一 塌缩**（0.3-0.5 秒）：粒子失去自主运动，加速向吞噬点聚拢，轨迹为直线加速而非曲线。**阶段二 吸入**（0.6-0.9 秒）：粒子拖尾成流被掌心收走，速度恒定不加速。 |
| 粒子数量 | 单体 300-800，最优区间 450-600；大型个体分层递减（800 / 600 / 400）；同一镜头内不叠加第二股粒子流。 |
| 声音 | 细密"噼啪"（类比烧红的炭），以 12-16 kHz 高频为主 + 极低频底噪；另叠 1 层"气流抽离"whoosh，收尾加 1 声闷合。 |
| 时长 | 单次消解 0.9-1.4 秒；大型个体分 2-3 批，总时长 2.0-3.0 秒；单集内不重复超过 2 次。 |
| 竖屏表现 | 粒子走"下半屏 → 掌心"的对角线汇聚，**不填满下半屏**；同屏可见粒子 ≤180，其余靠密度渐变与运动模糊表达。 |
| 残留禁令 | 全程不出现任何实体残留：牙齿、骨渣、红雾、碎块、离体部件一律禁止；掌心闭合后不得留残影。 |

| 项 | 规格 |
| :--- | :--- |
| 面部避让 | 消解全程人物面部保持 ≥70% 暗部，粒子不进入面部前方 30 cm 空间（禁入区）。 |

### 2.2 黑焰 / 深渊口与异化体粒子的颜色对位

**核心原则**：黑焰负责"开路"，粒子负责"交接"，旧金内芯负责"确认"。三色接力单向不可逆 —— 对方主色 → 暗青 → 旧金内芯。

| 阶段 | 时长 | 画面 | 颜色 | 声音 |
| :--- | :--- | :--- | :--- | :--- |
| ① 起势 | 0.3 s | 右臂黑焰自绷带缝隙窜出，只缠右臂 | 暗紫倾向 → 墨黑渐变，内芯一道旧金细线 | 闷响（低频） |
| ② 接触 | 0.2 s | 黑焰尖与异化体表面相接，交接区出现 1-2 秒混色环 | 对方主色 ↔ 暗青 | 摩擦嘶声 |
| ③ 塌缩 | 0.3-0.5 s | 对方表面裂成粒子，粒子先保留自身主色 0.2 秒 | 对方主色 → 蓝黑 | 噼啪起 |
| ④ 吸入 | 0.6-0.9 s | 粒子流进掌心，掌心内壁亮起内芯 | 蓝黑 → 暗青 → 旧金 | 噼啪峰值 + 抽离 whoosh |
| ⑤ 回压 | 0.2 s | 掌心闭合，内芯闪一次后熄灭 | 旧金 → 墨黑 | 一声闷合 |

**对位细则**

| 项 | 规格 |
| :--- | :--- |
| 深渊口开启顺序 | 裂皮（暗金符文自裂缝渗出）→ 开合（獠牙骨白，12-14 枚）→ 内壁纯墨黑、不做任何生物组织细节。 |
| 竖屏取景 | 口器特写给**下半屏**，上方留人物面部；同一镜头不做"只有嘴"的构图。 |
| 专属交接色 | A-1 暗青 / A-2 墨黑 + 旧金 / A-3 血珀 / A-4 骨白 / A-5 暗青。 |
| 旧金总量 | 单帧 ≤ 画面 2%（总纲 2.2）；交接区混色环的旧金占比也计入。 |
| 拒绝项 | 不用白爆闪、不用红滤镜、不让黑焰蔓延到张陈脸与躯干。 |
| 一致性 | 任何一次吞噬必须完整走完 ①→⑤ 五步，不得跳步；跳步镜头视为连续性事故。 |
