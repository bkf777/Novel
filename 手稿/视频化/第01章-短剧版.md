# 《注销通知》第一章 · 竖屏短剧版（2 集）

> **短剧 ≠ 快节奏。** 快节奏是把句子改短；短剧是**结构重排**——最反常的那一下提到第一帧，每 15 秒一颗信息炸弹，单集 60 秒内断在钩子上，全篇没有内心戏、没有环境铺垫、没有闪回。
>
> 源文：`手稿/第01章-注销通知.md`（定稿）　配套底稿：`手稿/视频化/第01章-快节奏改编.md`（长版，3:04）
> 规格：**2 集 / 共 2 分 10 秒 / 竖屏 9:16**　单集 68 秒 + 62 秒
> 提示词：见 `手稿/视频化/第01章-H3提示词.md`（10 个片段）

## 0. 短剧规格（本版执行标准）

| 项 | 标准 |
|---|---|
| 画幅 | **竖屏 9:16**，关键帧 832×1479（注意：不是长版的 832×1216） |
| 单集时长 | 60–70 秒 |
| 开场 | **前 4 秒必须是最反常的那一下**，不许铺垫、不许环境空镜 |
| 钩子密度 | 每 15 秒一颗信息炸弹；每 4 秒一个信息点 |
| 台词长度 | **≤ 15 字**（比正文基准的 20 字更狠）。全篇只有一句例外，见 C03 |
| 禁止 | 内心戏、环境铺垫、闪回、文艺空镜、"他在想…" |
| 数字 | 必须打出来：**1,095 次 / 72 小时 / 00:47:12**。短剧一半信息靠字幕 |
| 集尾 | 最后 3 秒**必须断在钩子上**，且钩子是"未解释的信息"或"反常的动作" |
| 单集只讲一件事 | 不铺世界观。世界观靠冲突带出来，一个字都不解释 |

## 1. 三处手术（相对长版）

### ① 开场从「敲门」换成「我不续」

长版 C01 是敲门 + 义工通报，安静、克制、符合原著——但那是**小说**的开场，不是短剧的。短剧的第一帧必须是全场最反常的画面。

**一个已经死了三天的老人，亲口拒绝活下来。** 这句话放在 0 秒，比敲门强一百倍。

### ② 删掉全部"非信息镜头"

以下内容在长版里都保留，短剧版**全部删除**，因为它们不推进信息：

| 删除 | 理由 |
|---|---|
| 签字闪回（四个半小时之前） | 内心戏 |
| 「进门不能哭」整段 | 设定说明 |
| 「桌上摆过的咖啡比喝过的水多」 | 文艺，48 字换 0 信息 |
| 走廊 / 清洁工 / 「都过午了，小沈」 | 唯一作用是节奏缓冲，短剧没有缓冲位 |
| 记录板整场（「认知区轻度衰减」） | 侧面信息，观众不看 |
| 「他记得那天的题…记得窗外有个女生在哭」 | 内心戏 |

**代价**：这版丢掉了原著"冷"的味道。短剧化的本质就是**用悬念换克制**。如果你要的是原著那种冷，长版 3:04 那份更合适。

### ③ 把施压方从"口述"变成"画面"

原文里女儿**从头到尾没有出现**，只有义工一句"家属又来了"和电话里的哭。短剧必须让压力具象化：**第 1 集 4 秒处直接给一个女人跪在门外的画面**，观众立刻知道谁在逼、为什么逼。

## 2. 第 1 集《七十二小时》　`68s · 竖屏`

### 逐秒时间轴

| 秒 | 画面 | 台词 / 字幕 |
|---|---|---|
| **0–4** | 陈素芬特写（竖屏，人物占画面 2/3），手里那只白纸杯。她抬眼。 | **「我不续。」**<br>字幕：`她已经死了三天` |
| **4–12** | 门外走廊低角度——一个女人跪坐着，膝盖上一块淤青。义工蹲下。 | 义工：「陈素芬家属又来了。」<br>沈砚（画外）：「多久了。」<br>义工：「早上六点。现在十一点四十。」 |
| **12–22** | 回到注销间。陈素芬擦杯子，手指停住。沈砚笔尖悬在记录板上方。 | 沈砚：「按规程，你的窗口满了。」<br>陈素芬：「哦。」<br>沈砚：「我没问你要不要续。」<br>陈素芬：「你问的是你让不让。」 |
| **22–34** | 交替特写。屏幕上「续期申请」四个字。 | 沈砚：「续期不是免费的。」<br>沈砚：「算力从在线的人身上抽。」<br>陈素芬：「抽谁的？」<br>沈砚：「抽那些不会有人问的。」 |
| **34–44** | 沈砚正面，陈素芬背影，两人之间夹着那只杯子。 | 陈素芬：「所以你们就抽别人。」<br>沈砚：「签字的人不下手，但是签字的人也不拦。」 |
| **44–54** | 陈素芬把杯子拿起来，慢慢擦。 | 陈素芬：「你们不是坏人。」<br>陈素芬：「你们只是把坏事办完了。」 |
| **54–62** | 沈砚站起，逆光剪影。 | 沈砚：「您还有两个半小时。」<br>陈素芬：「你是有两个半场。」→ 修正：**「你是有两个半小时。」** |
| **62–68** | **断点**：屏幕特写 `00:47:12`。她抬手挡了一下。 | 陈素芬：「小伙子。」<br>陈素芬：「你是不是也不太想走。」<br>沈砚的手指停在半空。→ **黑** |

### 本集信息炸弹（每 15 秒一颗）

1. `0:00` 她已经死了三天（而且是她自己不续）
2. `0:22` 续期的钱是从活人身上抽的
3. `0:44` 抽的是那些不会有人问的
4. `1:02` 这个老人看穿了沈砚

### 钩子逻辑

断在「你是不是也不太想走」——**一个将死之人问出了经办人最想逃的问题，而他没有回答。** 第 2 集开头用档案里的名字回答。

## 3. 第 2 集《第 1,095 次》　`62s · 竖屏`

### 逐秒时间轴

| 秒 | 画面 | 台词 / 字幕 |
|---|---|---|
| **0–4** | 屏幕特写，两行灰字占满画面。 | 字幕：`最近一次续期：第 1095 次`<br>字幕：`申请人签名：沈砚` |
| **4–12** | 沈砚工位，俯拍。任务队列十六单，按时间排。他的鼠标往下扫。 | 沈砚（低声）：「三个半。我接了一个半。」<br>周执（画外）：「那比我忙。」 |
| **12–20** | 鼠标停在"关闭"上不动。屏幕最底下多了一条，**没有颜色，没有加急符号**。 | 字幕：`不是今天的单`<br>字幕：`是三年前的` |
| **20–32** | 特写：`E-1109-林秀云` / `已注销` / `2042-10-12`。他调亮屏幕，**画面没变化**。 | 沈砚（低声）：「有人用我的名字。」<br>沈砚（低声）：「求了一千零九十五次。」<br>字幕：`一次都没批` |
| **32–40** | 闪切第 1 集那个跪着的女人，只 1 秒。 | 沈砚（低声）：「今天早上我拒了她。」<br>沈砚（低声）：「那不是大事。那是规程。」 |
| **40–52** | 详情页往下滚，字段全灰。停在两行。 | 字幕：`归档方式：织机自动注销`<br>字幕：`归档原因：72小时窗口到期`<br>沈砚（低声）：「那天夜里，没人按过键。」 |
| **52–62** | 最后两行。手指压在桌沿上。 | 字幕：`最后一次续期申请：已驳回`<br>字幕：`申请人签名：沈砚`<br>他站起来。他按的不是负一。→ **黑** |

### 本集信息炸弹

1. `0:00` 他的名字出现了一千零九十五次
2. `0:20` 三年前那个已经注销的档案
3. `0:40` 那天晚上没有人按过键——**他自己也不在场**
4. `0:52` 驳回记录上的申请人签名，还是他

### 钩子逻辑

断在「他按的不是负一」——**全书最强的一个动作钩**（原著文风基准钦定的校准段落）。第 2 集的信息全部服务于这一下：他要去哪、他要查什么、他三年前到底在不在场。

## 4. 台词精简对照（长版 → 短剧版）

| 长版原句 | 短剧版 | 处理 |
|---|---|---|
| 「那不是什么事。那是规程。」 | 保留 | 这句本身就是炸弹 |
| 「你们以为自己在做坏事，其实你们只是把坏事办完了。」 | **「你们不是坏人。你们只是把坏事办完了。」** | 25 字压到 18 字，拆成两句，落点更狠 |
| 「我知道她姓什么。知道她四十二岁。知道她…」 | **整段删除** | 90 字长台词是长版的王牌，短剧里是灾难。信息量由字幕承担 |
| 「三年前那个夜里，没有人按过键…」四句铺陈 | **「那天夜里，没人按过键。」** | 11 字，留白交给观众 |
| 「你们以为自己在做坏事」前的三句算力解释 | 压成两句 | 「算力从在线的人身上抽」「抽那些不会有人问的」 |
| 「签字的人不下手，但是签字的人也不拦。」 | **原样保留** | 18 字，全剧唯一超 15 字的台词。这是主题句，不改 |
