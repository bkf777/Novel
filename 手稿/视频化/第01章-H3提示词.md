## 0. 使用说明

### 0.1 竖屏专项规则（与长版最大的差别）

| 项 | 长版 | **短剧版** |
|---|---|---|
| 画幅 | 16:9 | **9:16 竖屏**，关键帧 832×1479 |
| 构图 | 人物 + 环境关系 | **人物占画面上 2/3，眼平或微仰**，环境只留一条边 |
| 每段镜头数 | 2–3 个 | **3–4 个**，切点更密 |
| 台词长度 | ≤ 20 字 | **≤ 15 字**（C03 的主题句例外，18 字） |
| 信息载体 | 对白 + 表演 | **对白 + 屏幕字幕**，字幕承担一半信息 |

### 0.4 模式分配

| 模式 | 片段 | 理由 |
|---|---|---|
| **FL2VA** | **C01、C05、C07、C10** | 四个钩子片段，首帧/尾帧都是"停住"的硬静止，模型自由发挥最容易破坏 |
| **I2VA** | C02、C03、C04、C06、C08、C09 | 单一首帧锚点即可 |

### 0.5 剧本级红线

1. **禁用「系统」二字**。终端只用「织机 / 终端 / 内网 / 后台 / 主脑」，语汇是公文式中文单色字，**不许游戏 HUD、进度条、赛博霓虹**。
2. **沈砚台词短、不解释、不道歉**，第 23 章前不说「对不起」。本版全部台词已压到 ≤15 字，不得在生成时"还原"成长句。
3. **陈素芬不得演成贪生**。她的体面在那句「我不续。」
4. **回声不会疼，所以不会变**。断电不惨叫、不挣扎、不做粒子飞散。
5. **竖屏里不要给大全景**。短剧没有全景，全景=观众划走。

## 4. ComfyUI 关键帧生产路径

> **短剧版比长版更需要这一步。** 竖屏裁切会把脸放大，一致性容错更低；10 次独立生成必须先用静态帧锁死。

### 4.1 现有资产（已验证）

服务：`~/ComfyUI` → `http://127.0.0.1:8188`，在线，设备 `mps`，统一内存 51.5 GB。

| 工作流 | 本集用途 |
|---|---|
| `Qwen-Image 2.1 修图（图像编辑）.json` | **主力**：10 段首帧 still，竖屏 832×1479 |
| `Qwen-Image 2.1 局部修图（涂选区域）.json` | C05 / C07 / C10 的尾帧（改状态不重绘）、C01 的女儿 |
| `Qwen-Image 2.1 战斗漫画页（四格分镜）.json` | 把 10 张 still 排四格，一眼看出节奏断点 |
| `Qwen-Image 2.1 GGUF 文生图.json` | 无人场景（C09 空注销间） |

### 4.2 四步走

1. **出 10 张首帧 still**——「修图（图像编辑）」，`<Picture 1>` 沈砚肖像作参考图，**832×1479 竖屏**，人物占画面上 2/3。
2. **补 3 张尾帧**——C05（悬停的笔）、C07（停住的鼠标 + 无色行）、C10（按下的按钮）用「局部修图」改状态，别重绘。
3. **女儿**——只有 C01（约 4 秒）和 C08（1 秒）两次戏，但两次必须同一人。单独跑一次文生图锁死外形（黑色长款羽绒服、三十来岁、右膝淤青、湿发），存成 `人物图/12_陈素芬之女_portrait.png`。
4. **过四格**——排成三页四格页看节奏，再上视频。

### 4.3 三个坑

- **参考图入参名是 `images.image_1`，不是 `image_1`。** 写错报 `TextEncodeQwenImage21.execute() got an unexpected keyword argument 'image_1'`，几秒内失败，不进推理。
- **竖屏尺寸必须是 832×1479。** 复用长版的 832×1216 会把头顶裁掉，或在 9:16 里留下黑边。
- `/tmp/comfy_gen.py` / `comfy_gen_ref.py` / `jobs_*.json` 都在 `/tmp`，重启即丢。跑通后连 prompt 一起归档进 `手稿/视频化/`。
