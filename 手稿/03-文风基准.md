# 《注销通知》文风基准

> 本文件是全书的文风宪法。每一章动笔前先扫一眼，写完后再回来对照检查。
> **判定标准**：如果某一章读起来像"另一个作者写的"，就是文风跑偏了。

---

## 一、文风指纹

| 维度 | 目标 |
|------|------|
| **对话占比** | 38%–44%（对话是本书的主干，叙述是骨架） |
| **句子节奏** | 短句为主。单句均值 ≤ 18 字。动作段单句 ≤ 10 字。禁止出现超过 35 字的叙述长句 |
| **段落呼吸** | 每段 1–4 行。连续叙述不超过 3 段，第 4 段必须是对话或独立成段的动作 |
| **叙述距离** | 贴脸第三人称限制（严贴沈砚）。**沈砚看不见的东西，读者也不许先知道**——包括全知旁白、上帝视角、"后来才知道"式的前置剧透 |
| **描写倾向** | 克制。全书形容词密度控制在每百字 ≤ 4 个。情绪不靠形容词，靠**动作和物件** |
| **情绪最高点** | 始终压在水面下。不允许一章里出现两次以上"心口一疼""鼻子一酸"。人物越痛苦，句子越短 |

### 五个硬指标（每章自检）

1. **开篇 200 字内必须有动作或对话**，禁止天气、禁止背景铺垫、禁止回顾
2. **新名词首现必须给可感知线索**，不许用定义句（详见设定词典）
3. **每章结尾必须是钩子**，且钩子必须是**具体物或具体动作**，不能是抽象感慨
4. **每章至少 1 处"展示而非讲述"** —— 把情绪换成一个动作、一件物品、一句没说出口的话
5. **沈砚的台词**：短、完整、无形容词。**全书禁止沈砚说超过 20 字的台词**

## 二、基准段落

### 范例 A · 沈砚视角（专业温柔 + 深层麻木）

> 注销间的灯是两盏，可调的。现在调到最暗那一档。
>
> 桌上两杯水。沈砚那杯没动过。他坐得笔直，手放在膝盖上——标准姿态，四年练出来的，看起来像在听课。老师傅说这是敬业，他说这是习惯。习惯和不紧张是两件事。
>
> 对面的老人把杯子握在手心里，指头很粗，指甲剪得很短。她讲她老伴，讲了大概六遍。前五遍他都在听。第六遍他也在听。
>
> "他走了十二年了，"她说，"今年该轮到我领低保了。"
>
> "嗯。"沈砚说。
>
> 老人笑起来。回声的笑和活人不一样——活人的笑是往上走的，回声的笑是**回来的**，像一段被录好的东西又播放了一遍，起点比终点高一点点。
>
> 他看了一眼手腕。屏幕上还有一小时四十分钟。
>
> "您还有想说的吗？"他问。这句话他每天说四遍。四个小时下来，四个注销间，他一共问了三十二遍。每一遍他都听得很认真。
>
> 他不是装的。装不了这么久。
>
> 老人想了想，说："小同志，你说人死了以后……会不会有人记得我？"
>
> 沈砚没有立刻回答。他在心里过了一遍标准话术——"您的音容笑貌会被妥善保存"——这句话他一年要说八百遍，说到自己都信了。
>
> 他今天说的是另一句。
>
> "会。"他说，"至少今天有人记得。"
>
> 老人点点头，低头看杯子。杯子里的水凉了她也没发现。
>
> 沈砚把记录板上的时间改了一下。他多给她留了二十分钟。
>
> 这不算违规。二十分钟的偏差，内网会记在核验员头上。而核验员这一栏，永远是他自己的名字。

**这段在示范什么**：
- 全部情绪靠动作承担——"杯子里的水凉了她也没发现""他多给她留了二十分钟"
- 沈砚破了一次例，例外本身比台词更重要
- "回声的笑是回来的，起点比终点高一点点" —— 一句话建立一个世界观
- 短句、贴脸、无形容词、贴脸第三人称

### 范例 B · 陆时衍视角（制度性的诚实）

> "第四季度，回收时长 4.7 亿小时。"陆时衍念完，把眼镜往上推了推，"折合人均每周 22.6 分钟。这是我要说的全部。"
>
> 没人说话。
>
> "我知道你们想听什么。"他说，"你们想听我说我们在控制，在优化，在找办法。我都可以说，但说了对你们没用，对那 4.7 亿小时更没用。"
>
> 他把手里的纸翻了一面。纸很薄，翻过去的时候有声音。
>
> "分配规则贴在公告栏里，公示期一百八十天，任何人可以提异议。我不隐藏任何数字。"他停了停，"我不是在说服你们。我是在告诉你们数字。"
>
> 沈砚看着那张纸的背面。背面是空的。
>
> "陆局，"他说，"住院儿童那部分，为什么排在第一优先回收？"
>
> "因为他们最便宜。"陆时衍说得很平，"住院儿童的非必要活动时长，可回收比例是常人的三倍。他们不是在直播，不是在上班，不是在打游戏。他们在等。"
>
> 他把纸放下。
>
> "你觉得这很脏。我知道。"他说，"但你告诉我，一个不用脏的办法要花什么代价？我算过。第九版方案的核心假设是回声总量在两年内下降到 0.3%。实际是 4.7%。我念给你听的是第几版你知道吗？"
>
> 沈砚知道。第九版。
>
> "十四版。"陆时衍说，"数字不会撒谎。人会。但数字也不够用。所以我才站在这儿。"
>
> 他停了两秒。
>
> 这两秒不在他的稿子里。

**这段在示范什么**：
- 反派不是靠"坏"写出来的，是靠"他说的每一句都对，但结论他接受"写出来的
- "等待的两秒不在稿子里" —— 全书的情感只能这样放进去
- 数字就是这本书的修辞，不需要翻译成形容词

## 三、负面清单（AI 写作痕迹清除）

以下写法**每章禁止**：

| 禁止 | 正确做法 |
|------|---------|
| 沈砚"心中五味杂陈" | 写他把手放在门框上，指节发白 |
| 描述角色的心理活动超过两行 | 一句心理 + 一个外部动作，立刻结束 |
| "他知道，这只是开始" | 直接写下一件事发生 |
| 每段开头用人物名 | 用动作、声音或物件起头 |
| "不禁""仿佛""似乎"连用 | 删掉，让句子直说 |
| 环境描写超过 3 行且不带信息 | 删到 1 行以内，或让它携带信息（如"灯调到最暗那一档"） |
| 沈砚用抽象词表达情绪（痛苦、愧疚、释然） | 换成具体行为 |
| 对话前后加"他淡淡地说""他冷冷地说" | 删掉，靠台词本身区分人 |
| 章末用感慨收尾 | 章末必须是物、动作或信息 |
| 解释读者已经能推断的东西 | 删 |
| 排比句用于抒情 | 排比只用于**机构发言**（陆时衍、制度文本） |

## 四、沈砚台词红线

- 单句 ≤ 20 字
- 不使用"我"开头超过 2 次的段落
- 紧张时省略主语和助词
- 从不说"对不起"，全书一次都没有——这是他最核心的说话特征，第 23 章第一次说出口
- 表达关心 = 动手（倒水、解鞋带、把东西摆正）

## 五、本书校准段落（取自已定稿的第一章）

> 第 1 章已定稿。**后续每一章动笔前先读这一段**，它比第二节的范例更接近本书真实语感。

**校准 1 · 情绪怎么落在物件上（第一声中场）**

> 一分十二秒里有很长一段。
>
> 陈素芬忽然说："小伙子。"
>
> "嗯。"
>
> "你是不是也不太想走。"
>
> 沈砚的手指停在半空。
>
> "陈姨。"
>
> "我就随便问问。"她说，"不答也行。"

> **看什么**：全段没有一句情绪形容词。最重的那个问题问出口之后，作者立刻把镜头交给一根停住的手指和一句转移话题的"陈姨"。**读者感受到的东西，一个字都没写。**

**校准 2 · 职业惯性怎么写（沈砚的"手感"）**

> 沈砚走回三号注销间，重新坐下。
>
> 陈素芬还在擦那个杯子。

> **看什么**：全章第一次介绍这位老人，是用**她正在干什么**带出来的，不是一句"她八十二岁，长得慈祥"。信息量最小的那个动作，承担了全部介绍。

**校准 3 · 悬念怎么留（章末钩子）**

> 电梯往下走。
>
> 他按的不是负一。

> **看什么**：钩子是**一个动作**，不是一条信息。读者已经知道他在查什么，但不知道他要去哪。**信息钩（档案里有个 ID）放在前一格，情绪钩（他按了电梯不是负一）必须放在最后一行。**

**校准 4 · 台词红线的实际样本**

> "续多久。"
>
> "二十四小时。"
>
> "那你倒是接啊。"

> **看什么**：沈砚全书台词的标尺是这一档——短、完整、无形容词、**从不解释自己**。第 23 章他说出"对不起"之所以有分量，正是因为前面 22 章他一次都没有破过这条线。

## 六、第一章专属规则（血泪教训，最高优先级）

> **这一节的规则高于上面所有规则。**

### ❌ 犯过的错（不要重犯）

初版第一章 3672 字，读者反馈**「看不懂」**。诊断结果：

1. **把设定写成段落**——「回声纪元三年。织机上线三年了。」然后整段解释。读者读了 20 轮对话才知道这是科幻。
2. **冷到没有温度**——为了执行「形容词≤4/百字」「情感压在水面下」，把老太太讲老伴那段最暖的戏，用「这声音他听了四年」摁死了。
3. **自欺欺人的机器病**——写了「公共交通 retired. 不对。是"退休"」，试图模拟真人打错字，实际效果是**读者觉得作者有毛病**。
4. **钩子需要前情才懂**——钩子是「一个已注销的回声出现在队列里」，而读者当时连「回声」是什么都刚知道。

### ✅ 第一章的铁律

| 规则 | 说明 |
|------|------|
| **规矩用演，不用讲** | 六条规矩必须在**同一场戏里走完一整轮完整流程**（有人求续期 → 拒签 → 陪完 → 按键 → 人消失）。禁止出现任何独立于场景的设定讲解段落。 |
| **规矩未立，禁上情绪** | 读者还没搞懂这个世界之前，任何情感冲击都会被当成信息噪声吞掉。先交付规则，再交付情绪。 |
| **前因靠行为立，不靠回忆** | 沈砚第一章必须**亲手拒签一次**。读者亲眼看见「签字是有分量的」，前因就立住了——不需要任何回忆插叙。 |
| **钩子必须是动作，不能是编号** | 「档案里有个 ID」是信息钩，「他按了电梯不是负一」才是情绪钩。**两个都要**，但情绪钩必须放在最后一行。 |
| **禁止自我纠错句式** | 任何「不对。是……」「其实应该是……」的自我改写一律删除。这是机器味最重的特征。 |
| **核心术语必须首现即立** | 「续期」是全书核心冲突，第一章必须出现两次：一次规则演示，一次章尾钩子。 |
