## 一、《注销通知》

> 科幻 / 伦理悬疑 / 家庭救赎　24 章　主线 9 天（2045-10-18 — 10-26）

**一句话**：人死后，生前预录的记忆权重在网里再「活」三天；三天后想多留，烧掉的每一秒算力，都要从活人的脑波里硬抽——而最便宜、最隐蔽的抽血方式，是抽死者的亲生骨肉。

**三方死局**

| 角色 | 立场 | 动机闭环 |
| :--- | :--- | :--- |
| 牧羊人（周正清，45） | 寄生者 | 4 岁女儿小满 2039 年内测脑死亡。他看准沈砚雨夜不敢进门的懦弱，盗用 `EDO-019` 密钥把林秀云锁进 3-C 当防弹衣，续命 1095 天。自己脑衰竭后触发「直系血亲代偿算法」，血袋换成沈苓——仅剩 4 个月 |
| 陆时衍（56） | 做局者 | 掩盖「算力庞氏骗局」（维持正常 72 小时就已在抽活人）+ 36 个权贵私服黑档投鼠忌器不敢动牧羊人。**2041 年亲手挑中沈砚入职**，发现黑账后引而不发，等着沈砚自己走去拆弹 |
| 沈砚（44） | 破局者 | 从「以为是自己害死母亲的罪人」，到「发现自己是防弹衣和擦枪布」，最后亲手按下唯一的物理熔断键 |

**沈砚为什么偏偏是他（人事阳谋 × 物理死锁）**

- **陆时衍挑人**：2041 年改制前夕他审完几百份心理评估，看中的不是业务能力，是「极度自律、情感隔离、面对压力只会机械服从、绝不生事」——**账本只有最不敢查的人才会替全局驮满三年**。
- **三条不可复制的交集**：① 他是经办人，持唯一物理熔断密钥 ② 母亲林秀云卡在公测元年第一批，拥有「72 小时可合法转永久挂起」的唯一外壳状态 ③ 妹妹沈苓高强度在线 14 小时，最适合当抽血泵
- **合谋产物**：陆时衍制造条件①③，牧羊人等待条件②，两人各据一头从未通过气，却把同一份档案锁死三年。**沈砚不是随机被选中的钥匙，他是被制度主动制造的。**
- 全书最狠的一层：**他以为自己是受害者，在被选中之前他就已经是共犯。**

**关键锚点**

- 沈苓月回收率 **31.2%**（全平台第一），剩余可抽周期 **118 天**
- 陆时衍放出的数字：**4.7 亿小时**季度回声债；三年积压 **9.1 亿小时**
- 三年前那个雨夜：2042 年 10 月 12 日 20:47—02:58，沈砚在对面公交站牌下站了 **6 小时 11 分**，实际到场，早晨补交了假病假条
- 牧羊人的工单里唯一有温度的数字：**39.1℃**（小满最后一次体温）
- 「对不起」全书只在第 23 章说出口一次

**写作红线**（摘自 `手稿/03-文风基准.md`）

1. 新名词首现必须当场给线索
2. 规矩用演不用讲——第一章完整走一遍流程：家属求续期 → 按规程拒签 → 陪完 72 小时 → 按键 → 人消失
3. 规则未立禁上情绪
4. 禁止「不对。是……」这类自我纠错句式
5. 沈砚台词 ≤20 字；第 23 章前从不说「对不起」
6. 🚫 全篇禁用「系统」二字 → 统一用「织机」「终端」「内网」「后台」「主脑」
7. 文风基准第六章「第一章专属规则」为最高优先级，每章动笔前先扫

## 构建与部署

五个站点共用同一套构建脚本模式：**Markdown → 自包含静态站**（侧边导航 / 目录 / 全文搜索 / 深色主题 / 阅读进度）。

```bash
cd <项目目录> && node build-site.mjs     # 产物 → <项目目录>/site-dist/
```

- 依赖 `marked`，装在上级 `.build-deps/`（不污染源码目录）
- `无尽杀戮/vendor/mermaid.min.js` 已本地化，站点离线也能渲染图表；`双相潮主/vendor/mermaid.min.js` 同源复用（Mermaid 10.9.1，支持 `timeline`）
- **改稿流程**：改 Markdown → 重跑 `node build-site.mjs` → 带 `node_id` **原地更新**（同一 URL，内容整体替换）
- ⚠️ 改稿后**必须重跑构建脚本**，否则线上仍是旧内容
- `site-dist/` 已加入 `.gitignore`，不入库；需部署时本地重建即可

### Mermaid 配色坑（两个站点都踩过）

Mermaid 渲染出的 SVG **内嵌 `<style>` 用 `#mermaid-xxx` ID 选择器**，特异性远高于站点 CSS 的类链，
所以 `.doc .mermaid .node rect{fill:...}` 这类覆写**默认不生效** —— 必须加 `!important`。
另外 Mermaid 10 的具名主题（`dark` / `default`）会**忽略传入的 `themeVariables`**，
只有 `theme: 'base'` 才完全由 `themeVariables` 决定配色。
故 `双相潮主/build-site.mjs` 采用：`theme:'base'` + CSS 变量（`--mg-*`）驱动，主题切换时重绘 SVG。
