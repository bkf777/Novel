# AI 短剧文档工厂

把「一个创意 + 一个大纲」转化为「一套可直接投喂 AI 生成流水线的竖屏短剧制作文档 + 白模空间 + 交接包」。

**本团队不生成视频。** 硬边界见 `00_团队章程.md` §一。

---

## 三条铁律

1. **JSON 是真源，Markdown 是产物。** 交付物先写 JSON，再由脚本渲染出 MD。
   **单向**，绝不做 MD→JSON 反向同步。人工修订必须改 JSON。
2. **出口硬校验。** 任何交付物落盘后必须跑校验器且 `error = 0` 才算完成。
   校验不过 = 交付物不存在，不得进入下游。
3. **上游合规裁决 > 派活指令。** 冲突时依上游改写并说明，不盲从。

## 常用命令

```bash
# 校验（每份交付物出口必跑）
node 短剧文档工厂/04_工具/validate.mjs --project 短剧文档工厂/02_项目/双相潮主 --unit U01

# 只看某一份 / 机器可读输出
node 短剧文档工厂/04_工具/validate.mjs --project 短剧文档工厂/02_项目/双相潮主 --doc D07
node 短剧文档工厂/04_工具/validate.mjs --project 短剧文档工厂/02_项目/双相潮主 --json

# 渲染 JSON → MD
node 短剧文档工厂/04_工具/render-md.mjs --project 短剧文档工厂/02_项目/双相潮主

# D08 字数重算（先试算，加 --write 才落盘）
node 短剧文档工厂/04_工具/fix-wordcount.mjs --project 短剧文档工厂/02_项目/双相潮主 --unit U01 --write
```

**退出码**：`0` 全绿 ｜ `1` 有 error ｜ `2` 参数或 IO 错误。

## 校验规则 V1–V10

| 规则 | 名称 | 检查什么 |
|---|---|---|
| V1 | 字段完整性与枚举 | JSON Schema 全字段校验，未知字段报错 |
| V2 | 跨文件引用完整性 | 角色/场景/镜号引用存在，minor 标记与 D04 一致 |
| V3 | 镜号连续与唯一 | 本集镜号连编，全局号唯一递增 |
| V4 | 时长求和与四段制 | 镜位合计=集时长，四段边界连续无缝 |
| V5 | 术语收口与禁用同义写法 | 全文扫描 D05 术语表的禁用同义词 |
| V6 | 禁词与贬称未成年一票否决 | 血腥禁词零容忍；贬称指向未成年 → 一票否决 |
| V7 | D12 角色描述 ⊆ D10 锚点表 | 不生成参考图的一致性补偿机制 |
| V8 | 单元钩子链闭合 | hook_in/hook_out 链式闭合，与单元定义对齐 |
| V9 | 字数两档 | 基础 180–240，总量 ≤330，合规增量单列 |
| V10 | 伏笔埋收与爽点密度 | 回收不早于埋设，每单元爽点 ≥3 |

阈值改 `03_规格/rules.json`，不改代码。
