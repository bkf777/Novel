## 〇、镜头语言总纲（承 D10 `camera_language`）

**本表每镜的 `景别 / 机位 / 焦距 / 运镜` 均按下列总纲执行**；单镜若要例外，须在该镜 `note` 里写明依据与回指规则。

| 项 | 口径 |
|---|---|
| aspect | 9:16 竖屏，全片统一，不混用横屏 |
| safe_area | 底部 15% 留字幕带；右下角 25%×10% 为 AI 生成角标常驻区，主体与关键动作不得进入该区 |
| shot_size_ladder | 远景、全景、中远景、中景、中近景、近景、特写 |
| shot_size_rule | 远景承担灰潮规模与人群压迫，中景承担动作与站位，近景承担情绪，特写只给道具与数据界面；大特写不用于人体痛苦表情 |
| camera_angles | 平视、俯视、仰视、顶视、过肩、主观视角、客观跟拍 |
| movement_vocab | 固定、推、拉、摇、移、跟、升降、环绕、手持、变焦 |
| movement_rule | 压迫感用推与缓慢跟拍；力量宣告用升降与环绕；异化的持续显形用固定机位让几何自己运动，异化自下而上顶出显形时用升降跟住显形过程（固定机位会让出画）；手持仅用于受伤、失控与近身交击段落，且不贴脸 |
| lens | 以 24／35／50／85mm 为主：场景交代 24–35mm，人物近景 50–85mm；不使用超广角畸变 |
| rhythm | 45 秒四段制，每集 4 镜＝四段制 1 镜/段，镜时严格等于 D07 段界（U01 共 32 镜）；【并行段例外】凡 D07 标注 mode=并行的段（U01 实例：ep002 段3）由两镜在该段内交替并置实现，不适用「1 镜/段」，但每集镜数总量仍为 4 镜、镜时仍严格等于 D07 段界不变；每镜只承载一个可见事实；段落边界用同机位接续　【历史口径留痕】原「段内单镜 1.5–4 秒」口径已于 2026-10-22 废止，理由是与 D17/D12/D15 的单元产量预算（4 镜/集）冲突；裁决由 Chief 以 C1 裁出，企划合规登记进 D18 decisions。 |
| composition | 竖屏优先：主体居中偏上，头顶留 8% 空间，前景遮挡不超过画面三分之一，主体不贴边 |
| banned | 贴脸突发惊吓、血腥特写、人体内部细节特写、运动相机式贴地跟拍导致主体出框、长时间静止无信息镜 |
