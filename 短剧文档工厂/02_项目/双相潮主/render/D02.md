## 一、定位

《双相潮主》＝ 男频末世升级流 × 无限流系统流，红果平台竖屏 9:16，160 集 × 45 秒，正片 7200 秒（120 分钟）。仿真人漫剧路线：人物写实、异化体与特效风格化，合规尺度 zero_gore。世界观基底为「现代都市灾变末世 + 灰潮规则科技」——数据化面板接管全球、雾核作为硬通货、律条作为规则条款载体。核心人物七位：陆沉（22，双相归档重生体）、叶红衣（20）、苏清辞（25），反派叶崇岳（54）、叶承钧（26）、闻照白（63）、商既衡（48）。故事从灾变前 3 小时起算：陆沉自归档死锁回滚重生，抢占机械厂与归废处置线、救下叶红衣、组建死士营，把「活下去」推成「能建城」。五势力（薪火城 / 云顶财阀 / 叶家 / 雾盟 / 境外基因财阀）围绕雾核配额与规则载体展开资源—规则双轨争夺。产品定位是工业化可滚动的单元制男频爽剧：能力成长自带可见倒计时（归一度读数），每一集都有「变强一次、代价一格」的同频节奏。差异化不在题材新（无限流系统流为成熟品类），而在三点：一、代价线可核对（12 点读数锚点表，读者能拿数字验证代价叙事）；二、能力机制受硬约束（律条改条款、骨纹执行权限，二者互不越界，杜绝主角特权无边界）；三、零血腥不减爽点（去血腥改造只换表达通道，不删爽点、不删台词、不改情绪曲线）。本企划不登记具体对标作品名，宣传口径同样不得出现对标作品名。


## 二、卖点矩阵

- 稀缺双线升级：公开的 LV 线（雾核 → 经验 → 等级四维）人人可走，隐藏的骨纹线（规则余烬 + 律条 → 淬骨升阶）只有主角能走。两条线共用同一货币体系却指向不同终点，天然制造「只有他走得更快、也只有他付得更多」的落差。
- 代价可视化且可核对：归一度按 12 点锚点表推进（ep003 0.5% → ep010 1.0% → ep026 1.5% → ep035 4.5% → ep054 6.0% → ep059 8.0% → ep067 16.0% → ep089 40.0% → ep094 50.0% → ep128 70.0% → ep131 85.0% → ep151 100%）。锚点集必须精确命中，非锚点集读数落在相邻锚点闭区间内且单调不减，逐集概述已有显式数值的集一律锁定（ep028 = 1.5%、ep094 = 50%、ep151 = 100%）。观众能拿数字验代价，而不是听旁白说代价。
- 机制受硬约束，主角没有无限特权：律条/天律只能按所载条款及其适用域改变规则条件或提供破境凭证；骨纹权柄只能按已解锁技能作用于自身骨体及明确授权对象。判定规则固定为三问——这场戏是在改「谁在什么条件下能做什么」的规则条款吗（用载明该条款的律条或天律）／是在对已授权目标执行已解锁的具体操作吗（用骨纹）／是否涉及破境凭证、未授权权限或十阶重铸（凭证必须照交、权限不得外推、重铸必须熔炉式归档）。另有 9 条执行约束逐级限定一至十阶的能力边界。
- 零血腥不减爽感：全片零创口、零血肉、零喷溅、零器官特写、零肢体断裂，异化体一律陶俑化无五官，异化消散统一为「溃散为灰烬光尘」。改造只换表达通道（远景剪影 / 遮挡 / 光影粒子三档替代法），不删爽点、不删台词、不改情绪曲线——在合规红线内保住工业化爽点密度。
- 工业化产能结构：8 集 = 1 单元、20 单元 = 160 集、每卷 40 集 × 5 单元。单元锁四条件（单元内交付物 JSON 齐全 / 校验器全绿 / 人工审读通过 / 承接钩子链闭合）逐条可查，未锁单元不得开下一单元。口径漂移由「术语只在 D05 收口一次 + 校验器 V5 逐词拦截 + 单元锁人工审读」三重兜底。
- 势力博弈密度高：五势力各有可执行的资源诉求（雾核配额、药物、安全屋、律条载体、救治资格），主线不是打怪而是「配额 → 后勤 → 规则 → 秩序」的递进博弈；每卷换一套博弈规则（建城 → 争律条 → 全球远征 → 终局重铸），不靠重复刷怪撑集数。
- 双线世界的可扩展性：公开 LV 线 + 隐藏骨纹线 + 律条载体三件套，是可无限续写的设定骨架；EP01–EP160 是一个完整闭环，同时每个单元钩子链天然可切分投放，兼顾长线留存与分季变现。


## 三、节奏模型

【四段制 · 45 秒】每集固定 4 段，边界连续无缝，段内合计 = 单集 45 秒；段内可并行交叉剪辑，但必须显式标注并行关系（承接钩子链验证以末集 hook_out 对下一单元首集 hook_in 为准）。【单元制 · 8 集】U01–U20 共 20 单元，单元 = 最小叙事单位，集 = 最小投放单位；单元锁四条件同时满足才开下一单元，锁由企划合规登记进 D18。【四卷结构 · 每卷 40 集 × 5 单元】卷一《暴雨烬火》ep001–040（U01–U05）：抢占据点、救叶红衣、反杀暗杀组、双潮暴雨夜立薪火城，卷末以指尖泛雾的代价伏笔收束。卷二《骨窖争锋与规则篡夺》ep041–080（U06–U10）：骨窖开、争律条、石碑揭「潮主不是境界，是供位」、六→七跨档破境夺得天律、初代律条归属。卷三《天下同悲与远征灰国》ep081–120（U11–U15）：灰海合流、旧大陆灰化、薪火铁骑全球远征、归一度逼近 50%、与雾盟首座对决、终局道破「地球是一具神骸」。卷四《原初大葬与万古潮主》ep121–160（U16–U20）：神骸真相、归零抹除倒计时、七→八收缴潮罚规则体、八→九直面神骸、地心白骨原终局、十阶熔炉式归档重铸纪元。【幕结构（另一层级切分）】幕一 ep001–040、幕二 ep041–120、幕三 ep121–160；卷二全部落在幕二，卷三前半亦落在幕二。【节奏骨架】每集 45 秒 = 四段，段内台词与动作密度按「冲突可见性三档替代法」分配；单集字数基础档（剔除合规增量段）180–240 字、总量 ≤330 字，由字数工具自动重算。【代价线节奏】归一度读数在非锚点集只落在相邻锚点闭区间内且单调不减，不另设阶内锚点；「归一度攀升」类钩子指化雾进程加速，不等于读数跃升。

## 五、风险

- 代价线与爽感曲线的对冲风险：归一度读数越高，主角越接近彻底消散；若观众把代价读成「削弱主角」而非「加注赌注」，会在中段流失。处置：代价只在里程碑集显性化（ep028 / ep089 / ep094 / ep128 / ep131 / ep151），其余集读数落在相邻锚点闭区间内且不喧宾夺主；卷末的代价伏笔用余韵收束，不用断崖。
- 160 集体量下的跨文档口径漂移风险：术语、人物锚点、镜号、合规挂点一旦在长链路中漂移，返工成本呈倍数上升（此前已出现 16 处跨文档冲突与一批结构占位壳）。处置：术语只在 D05 收口一次、校验器逐词拦截、单元锁四条件含人工审读、D04 与 D06 禁止并行。
- 零血腥表达通道在大场面失效的风险：双潮暴雨夜、灰海合流、旧大陆灰化、终局重铸等超大尺度场面，用远景剪影/遮挡/光影粒子三档替代容易退化成「看不清所以不算违规」，反而丢掉压迫感。处置：D12 逐镜继承禁构图 V1–V10，AI 标识净空与主体构图同帧校验；大场面强制至少两档叠加使用。
- 主角特权无边界化的剧情风险：骨纹线若被写成「主角想改什么就改什么」，力量体系会自我拆台，设定可信度崩塌。处置：律条改条款、骨纹执行权限的边界写入 D05 力量体系（法条边界 / 骨纹边界 / 机械判定规则 / 9 条执行约束），D06–D10 引用不改写，V7 校验角色描述必须出自 D10 锚点表。
- 商业模式与卡点未拍板导致返工：分类、备案路径、片头标注格式、宣发口径、D17 成本全部悬在两项拍板上。处置：相关项全部登记 D01 gaps 并显式标注「待用户确认」，不脑补数值；已落地的合规与结构工作不受影响，可先行推进。
- 出片不在本产线内的衔接落差：团队只交到 D14 交接包，出图/出片/音频/投放由用户自行执行，交接规格若写得不够精确，落地端会返工。处置：D13 说明书给出可复现命令，D14 写清规格、净空与净空约束，附一键脚本。
- 白模环境与扩展的可复现性风险：白模依赖 Blender 5.2.2 LTS 与 minimax_h3 扩展，换机或版本漂移会导致 D13/D14 不可复现。处置：全部 --background 脚本化，D13 给出可复现命令与版本自检步骤，扩展路径写进交接包。
- 去对标化与现实指涉的残余风险：旧作名、真实科学家姓氏与对标作品名仍可能从宣发端或素材注释回流。处置：正文与画面禁用同义写法由校验器逐词拦截；宣传口径不得出现对标作品名；境外基因财阀保持模糊泛称、标识为抽象几何。
- 反派与后期单元的素材债：4 个反派的外貌锁与标识已落，但素材原始参考图缺失；卷二至卷四的节拍表尚未逐单元细化。处置：单元制下不阻塞 U01/U02，各单元开工前细化，超出当前单元的缺口登记为该单元的前置卡点，不提前脑补。
