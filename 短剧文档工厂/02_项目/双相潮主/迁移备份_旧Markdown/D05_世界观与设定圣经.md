**结论**：

1. **「云顶财团」与「云顶财阀」是同一实体的两个称谓**（财阀的**商业体称谓**），不是两个实体。setting_db 全库 0 命中「云顶财团」，正文亦 0 次使用；D03 §5.3 已明确其为「云顶财阀」的商业体称谓。→ **按 D03 §5.3 裁定，一律用「云顶财阀」（T12），「云顶财团」不另立条目**。
2. **「叶氏宗阀」与「叶家」是同一实体的两个称谓**（世家的宗族化旧称）。→ **统一为「叶家」（T13），「叶氏宗阀」作废**。
3. 因此，「一物四名」实为**两名两写**：**云顶财阀**（T12）＋ **叶家**（T13），**两个独立实体**，非一物四写。派活单 §三·交付物 1 所问「云顶财团是否为独立实体」的答案是：**否，是云顶财阀的商业体称谓，不另立条目**。
4. **⚠️ 素材内部矛盾（事实陈述，不作判断）**：白皮书 L135 把 `Z1["云顶财团 / 叶氏宗阀"]` 写为**同一节点的两个名字**，即图上呈现为「一节点双名」；但该节点挂在「现世 + 作废组织名」的 subgraph 之下，而**叶家是 setting_db 明确分列的独立势力**且承载 B03 全场（叶红衣被弃、叶二少下令处置、族长被杀）。→ **图上「云顶财团 / 叶氏宗阀」并列书写，与 setting_db 的势力分列及正文情节线不一致**。此矛盾已登记至 **D06 §素材内部矛盾清单**，由用户/制片总监裁定是否回改白皮书（源文件只读，本岗不动）。
