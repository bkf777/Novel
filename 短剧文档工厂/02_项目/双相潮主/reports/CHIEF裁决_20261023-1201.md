## 三、新立 Q104：画外音必须结构化（**本批次最要紧的一条**）

### 现状证据（现盘实测）

| 集 | D11 镜1 有台词 | D15 首句 VO | 语义 |
|---|---|---|---|
| U01 ep01/02/03/04/07/08、U02 ep09–ep16（14 集） | 有 | shot_id=1 @0.4–0.5s | 在场说话（onscreen） |
| **U01 ep005** | **无** | YJ-ES / **shot_id=2** / 0.5s | 说话人不在画面 |
| **U01 ep006** | **无** | LC / **shot_id=2** / 0.5s | 说话人不在画面（镜1 仅有剪影） |

**缺陷**：D15 的 VO 条目只有 `char_id / shot_id / at_sec / dur_sec` 等字段，**没有任何字段表达「这条声音在 at_sec 时刻不在画面内」**。画外音语义只能靠人读 `shot_id≠当前画面` 去推断。

**后果**（这才是问题所在）：D14 白模 / D16 / 字幕后期**无法机器判定**说话人是否在画面 → 会出现「画面有嘴型没声音」或「声音响但人没入画」的错位；校验器无法查；分镜导演只能用自然语言在 note 里写「角色不入画」。

### 裁决

1. **D15 VO 条目新增两个字段**：`vo_type: "onscreen" | "offscreen"`、`speaker_in_frame: bool`；D16 的 `golden3s_first_line` 同步这两个字段。
2. **新增规则 V13**（挂 D15/D16）：
   - `at_sec ≤ 1.5s` 的 VO，若说话人不在该时刻所在画面 → **必须** `vo_type=offscreen`，否则 **error**；
   - `vo_type=onscreen` 但对应镜次 `dialogue` 为空 → **error**。
3. **责任岗**：声音设计（字段 + 16 集回填）、企划合规（V13 写入 `rules.mjs` + `schema.json`）、分镜导演（D16 同步）。
4. **本轮 at_sec 不动**——秒级已全部达标，本条只补语义字段，不重排时间。

> 依据：用户裁决的「黄金 3 秒」= 第 0 帧给最强符号 + 0.5s 入画第一句台词。画外音是本剧黄金 3 秒的主力技法（ep001 黑场声音先行、ep005/ep006 人后声先），它必须**可被机器校验**，不能靠人读备注。
