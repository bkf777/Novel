## 三、校验器绿灯的含金量（重要教训）

`node 04_工具/validate.mjs --project 02_项目/双相潮主 --unit U01` 对上述 11 份壳返回：

```
通过 10/10 规则  error 0  warning 10   →  exit 0
```

**即：validate 全绿只证明 JSON 结构合法、枚举合法、镜号连续、时长相加正确，不证明内容为真。**
V1 只看字段在不在与枚举合不合法；V3 只看镜号连不连；V4 只看时长相不加分。**它们不读内容语义。**
