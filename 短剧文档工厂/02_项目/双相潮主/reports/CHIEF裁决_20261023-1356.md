### 判据缺陷的精确位置

`04_工具/lib/rules.mjs:1206-1215`：

```js
// 空镜豁免：D11 画面事实明写空镜时，跳过 W1/W2/W3
const facts = String(shot.visual_facts || '');
if (emptyRe && emptyRe.test(facts)) { ... continue; }

```

而 `03_规格/rules.json` 的豁免真源是：

```json
"empty_shot_pattern": "空镜|画面无人|无人在场|空画面"
```

**豁免只认 4 个字面词。** 上表 16 镜的画面事实写的是「面板占满画面」「铭牌挂上门柱」「密信摊开钢桌」——**没有一句写「空镜」**，于是全部落进 W1。

### 根因链（这才是要点）

```
画外音无结构化字段（Q104 未落地）
  → D11 镜1 有台词、但角色刻意不入画
  → 白模正确地不建 CHAR 代理体
  → V12 豁免只认「空镜」四字，认不出「面板镜/物件镜/画外音镜」
  → W1 报 error 16 条
```

**⇒ 上一批我裁的 Q104（画外音必须结构化）不是锦上添花，它是解锁这 16 条 error 的钥匙。** 判据缺豁免是果，缺字段是因。

### 裁决

1. **V12 豁免真源扩容**：不靠 D11 写「空镜」二字，而应从 **D11 该镜是否存在在场角色** 判。可行路径（择一，企划合规定夺后派）：① 在 `rules.json` 的 `white_model_framing` 增加 `no_character_shot_pattern`，覆盖「面板／铭牌／密信／条款／名单／桌面物／掌心／触角／环境／无人」等物件镜语汇；② **更稳**：由 D13/D14 的在场角色清单判定 —— 若该镜 D13 场景内 `present_characters` 为空，则 W1/W2/W3 全部豁免。**我倾向 ②**，因为它是结构判定而非语汇判定，不会随文风漂移。
2. **豁免必须带负测**：证明「真有角色但代理体漏建」时**仍必须报错**，否则豁免会变成新的假绿源。
3. **W1 与 W2/W3 的豁免范围要分开**：W1（角色存在性）与 W2/W3（景别区间／主体让位）在「物件镜」上的语义不同 —— 物件镜没有角色，但**有主体**（面板占满画面是对的），W2/W3 在物件镜上仍应有效。**豁免只给 W1，不要给 W2/W3**。

## 五、裁决：ep018「画外音 vs 身份不出画」冲突

分镜导演 13:2x 提请裁决：**D08 的 shot_intent 写「画面内不出陆沉」vs D11 镜1 含腕骨纹路这一不可辨识局部**。我实读了现盘：

```
U03 D08 ep018 body[0]（action）: 骨威全开，骨纹自右腕骨一路亮到小臂，白光顺着街面铺开，灰雾被压得下沉。
U03 D11 ep018 镜1 dialogue   : 陆沉「原来能这么用。」
U03 D11 ep018 镜1 visual_facts: 骨威全开，骨纹自右腕骨一路亮到小臂，白光顺着街面铺开……（与 D08 body[0] 同源）
```

### 裁决

**两者不冲突，是同一件事的两种写法。** D11 镜1 镜的是**右腕骨+小臂的局部**，不是「陆沉的脸或全身」。

- 「画面内不出陆沉」= **不出陆沉这个人物本体**（无脸、无全身、无可辨识人形）；
- 「含腕骨纹路」= **出陆沉身体的一个不可辨识局部**（骨纹是画面主体与钩子载体）。

**⇒ 口径收口为**：**「出局部（骨纹/腕/臂），不出人物本体（脸/全身/可辨识人形）」**，两者同时成立。

**落地要求**：
1. **@分镜导演**：D11 ep018 镜1 的 `visual_facts` 与 `dialogue` 保持现状即可（局部镜 + 台词），但 `note` 须显式写明「角色不入画，台词为画外音，出画的是右腕骨局部」——**以便 Q104 的 `vo_type=offscreen` 有据可填**。
2. **@台本编剧**：D08 ep018 的 shot_intent 措辞由「画面内不出陆沉」改为「**画面内不出陆沉人物本体，只出右腕骨与骨纹局部**」——消除歧义，**不改变剧情**。
3. **@企划合规**：把「局部可出、人物本体不可出」写进 D03 合规清单的作画口径，使 D11/D12/D14 三层都按同一口径判。

> 注意：这条**不能**用「角色占幅 0% 即可豁免」来偷懒 —— 白模侧是**有**腕骨代理体的（只是 `CHAR` 前缀分类未覆盖）。豁免口径必须能区分「完全无人」与「只有局部」。

## 十二、⭐ 追加裁决：V13 与 V12 在「画外音镜」上互相打架（14:0x 实测发现）

### 事实（我 14:0x 跑闸门 + 读判据源码）

```
闸门规则数  12/12 → 12/13（三单元均已计入 V13）
```

**但 V13 的实测行为是**：

```
PASS  V13 画外音结构化一致性（D15 voice_over ↔ D11 镜次台词）
  ! V13: D15 有 8 条画外音落在金三秒窗口（at_sec ≤ 1.5s）但未声明 vo_type／speaker_in_frame，
         V13-a／V13-b 未判（缺失不判 error）；建议补齐字段后复跑
  ! V13: 已检查画外音 30 条（onscreen 对账 0 条，V13-c 反证腿放行 0 条）
```

**⇒ V13 对「字段缺失」只报 warning、不判 error。** D15 三单元 `vo_type` 命中 **0**（U01 v1.14 / U02 v1.4 / U03 v1.2），V13 照样 PASS。

### 冲突在哪

```
D15 缺 vo_type
  → V13「缺失不判 error」，只 warning ⇒ 补字段无压力，D15 可以永远不补
  → V12 无从知道该镜「角色本就不在画面」
  → V12 只能按「角色理应在画面」判 W1 ⇒ 16 条 W1 error 依旧
```

**⇒ §二 的 16 条 W1 至今一条没消，根因就在这里：V13 缺字段不判 error，把「补字段」从硬性变成了自愿。** 我 13:56 说的「判据缺豁免是果，缺字段是因」要再补一句：**字段有了，但没把「缺字段」设为 error，因就断在这里。**

### 裁决

1. **V13 判据的「缺失不判 error」必须改为「缺失即 error」**（当该 VO 落在 `at_sec ≤ 1.5s` 窗口时）。
   - 理由：V13 存在的全部意义就是把画外音变成机器可判的事实。**一个只在字段齐了才生效的规则，等于要求执行方先猜中规则要什么** —— 而执行方正是靠这条规则才知道要填什么。**这是循环依赖，必须破。**
   - **前置条件**：D15 三单元的 `vo_type` 需先补齐（否则改判据会立刻炸 8+ 条）。⇒ **顺序：先补 D15 字段 → 再把 V13 缺失改 error → 两者同批落地。**
2. **V12 豁免扩容与 V13 补字段必须同批做**，不能只做其一：
   - 只补 D15 字段不改 V13 ⇒ 字段补了但没人查，白填；
   - 只改 V13 不补字段 ⇒ 立刻炸 error，制造假红。
   - **本批的落地顺序**：① 声音设计补 D15 三单元 `vo_type`/`speaker_in_frame` → ② 企划合规把 V13 缺失改 error + V12 豁免扩容（结构判定）→ ③ 三单元各跑一次闸门贴结果行。
3. **V12 豁免扩容取结构判定**（我在 §二 已倾向，此处定案）：以 **D13 在场角色清单 / D14 CHAR 代理体是否存在** 为准，而非 D11 文案语汇。
   - **豁免只给 W1，不给 W2/W3**（物件镜有主体，W2/W3 仍应有效）。
   - **必须带负测**：真有角色但代理体漏建时**仍须报 error**，否则豁免变成新的假绿源。
4. **⚠️ 但豁免口径必须能区分「完全无人」与「只有局部」**（U03 ep018：白模有腕骨代理体，只是 `CHAR` 前缀分类未覆盖）。⇒ 结构判定不能只看「CHAR 前缀代理体数为 0」，**须同时校验 D11 该镜是否声明了可辨识人形**（脸/全身）。**这一点不定案，ep018 一类镜会被误豁免。**
5. **字段规格表三处同步补齐**：`03_规格/字段规格表.md` §四 缺 V13/V14 两行 + D15/D16 新字段行 —— **这是 Q109 ⑤「三处同步」漏掉的一处，请补上并登记。**

### 一个必须说清的风险（诚实登记）

**若先改 V13 缺失判 error 而 D15 字段未补齐，三单元会立刻多出约 24 条 error（三单元各 8 集各 1 条金三秒窗口 VO 缺字段）**，且这批 error 在字段补齐前无法通过任何正当手段消除。

**⇒ 严禁「先改判据再补字段」的顺序。** 两步必须同批、同一次明派、同一次落盘。**这一步踩错就是制造假红，比现在的 16 条 W1 更糟。**
