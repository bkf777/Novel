### 40.7 三个真实坑（都是「回磁盘取真实结构」的老教训）

| 坑 | 现象 | 处置 |
|---|---|---|
| **字段名照记忆写** | D07 的时长字段是 `duration_sum_sec`，**不是** `duration_sec`。首版脚本按 D06 的字段名取 → 首次落盘 `duration_sec: null` → **V1 报 8 条 error** | 改脚本取 `duration_sec or duration_sum_sec` → 重建 → error 0 |
| **改了 A 变量却没写回** | `build_D08.py` 首版构造 body 项时**漏写 `char_id`** → D09 从 D08 抽取台词时全为 `None`（28 句全废） | 修生成脚本后**两文件同批重建**（不手工补 JSON），D09 自检当场拦下 |
| **口头禅尾句号** | 生成脚本按「包含」判定 catchphrase，与 D04 原文不一致却放行 | 改为严格相等 + 报错不写盘 |

**三条都指向同一件事**：JSON 由脚本产出时，**改脚本 ≠ 改 JSON**，而「脚本跑通」不等于「字段名对」——必须由下游校验器（V1／V2／V6）交叉拦一道，不能只看自己脚本 exit 0。
