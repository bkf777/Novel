## 四、为什么这么改

**1）黄金 3 秒：第 0 帧给后果，不给环境。**
短剧观众在第 0.5 秒决定划不划走。所以第 0 帧必须是一张「已经出事的画面」——这里是**手腕上的骨纹**，不是空房间。台词放在 0.5 秒，一句话把三件事交完：上一趟（重生）、第三个小时（时间坐标）、死过一次（经验）。面板和前史一律后置到 1.5 秒之后。

**2）零血：代价改用物证。**
「他刚刚死过一次」不用伤口来证明，用**满地狼藉 + 吃了一半的压缩饼干 + 还冒着热气的咖啡**——这些都是「刚刚发生过」的时间物证，画面干净，一滴红都没有。「身体被回滚倒带」也不用血痂，用**膝软、扶墙**。骨纹是纹路不是创口，天然合规。

**3）骨纹提到第 0 帧，但不激活。**
ep001 就能看见黑白游龙纹，但**不发光、没有归一度读数**（ep003 才第一次亮起、第一次读 0.5%）。这样第 0 帧就把全剧最强符号摆出来，观众的问题是「他身上为什么已经有了」，不是「这是什么」——后者更抓人。

**4）片头四行：每集白赚 2 秒。**
原来 0–2 秒画面上盖着剧名、「节目编号：〔待平台给出〕」、「编剧：〔待定〕 导演：〔待定〕」、「本片由人工智能生成」。观众最关键的 2 秒看到的是「待定」和「待平台给出」——半成品观感，直接劝退。现在这四行全部挪到片尾 43–45 秒（短剧惯例署名在片尾），AI 标识义务由**每镜右下角常驻角标**（本来就已逐镜声明）+ 片尾字幕满足，合规不降级。

**5）四段制一个字没动。**
还是 4 镜 45 秒（13/13/12/7）、景别还是中景/特写/中景/全景。白模几何、预算链、D12 提示词卡全部只改内容不改结构——所以这一集改完，D14 白模和 D17 预算都不用推倒重来。
