### 1.2 六条铁律

| # | 铁律 |
|---|---|
| 1 | **一卡一事实**：每张卡只描述一个可见事实组合，**不得把多张卡拼进同一次生成** |
| 2 | **锚点只引用**：正负提示词里禁止改写 STYLE-01 锚点句；角色锚点句从 D10 复制 |
| 3 | **角标位必须预留**：每张卡的构图说明都写明「右下 72%~78% 画面高度留净空，供 AI 标识角标」——**生成前预留，不得后期遮挡**（D16 §140） |
| 4 | **Seed 策略**：同角色固定 seed（§五 分域表）；场景光效每镜独立 seed；**换 seed 必须重述全部锚点句** |
| 5 | **母版先行**：CHAR-01 / CHAR-02 先出母版并确认，再用参考图锁外形；参考图权重 0.6~0.75 |
| 6 | **术语不进画面**：本文件所有专有名词只用于制作单据，**绝不写进正向提示词的画面元素描述**，也不进入任何观众可见文字 |

### 1.3 通用参数（各卡可覆盖）

| 项 | 默认值 |
|---|---|
| 尺寸 | 生成端 **832×1472**（9:16）或 **1024×1792**；交付端统一上采样 **1080×1920** |
| 采样器 | DPM++ 2M Karras（备选 Euler a / DPM++ 3M SDE） |

| CFG | **6.5~7.0**（>8 易过饱和出塑料感） |
| 视频帧率 | 24fps |
| 视频模型 | 图生视频（首帧＝本集 IMG 卡产出图，尾帧＝可选；成片模型由用户在 H3 端执行，见 D14 交接包） |
| 运动强度 | 低（静物/微动）· 中（人物动作）· 高（快速位移）——见各卡 |
