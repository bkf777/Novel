## 〇、本集声音设计总纲（一页读完）

| # | 核心判断 | 说明 |
|---|---|---|
| 1 | **本集的恐怖来自「声音变少」，不是「声音变可怕」** | 001 后颈符纹裂隙不给怪物音，给的是**雨声被吸走**；011 黑衣男子轮廓丢失给的是**声音被抽走**。首尾同构，构成听觉闭环 |
| 2 | **能量类声部必须「非生物化」** | 极低频 30~50Hz 是**涌**，不是吼；共鸣是**晶体**，不是兽吼；**禁止**任何兽吼/龙吟/非人化怪音（D03 R7 必改项） |
| 3 | **心跳符号＝全片声音的脊柱** | 两次落点：**31.5s（入体）** 与 **41.5s（完成）**。**一律单拍重音（one-hit），禁「咚-咚」双拍**——既保留心跳可识别度，又零器官搏动联想 |
| 4 | **本集 BGM 极少** | 0~5s 与 5~8s **几乎无旋律**；完整主题动机全片只出现 2 次（004、010）。**45 秒里旋律越少，每一次出现越重** |
| 5 | **爽感补偿集中在 009→010 的「一刀」** | 009 末 31.0s 全层抽空 → 31.5s 一记心跳 → 32.0s 010 立刻全奏。**上一帧是空，这一帧是满**——这是 EP01 的声音主峰 |
| 6 | **「非人」由音效层承担，不由人声处理承担** | 黑衣男子的**人声必须是人声**（一个正在坏掉的人）；「非人」全部交给极低频共振、反向吸声、晶体嗡鸣。**人声一处理就穿帮** |
| 7 | **绝对静默全片只有 2.0 秒** | 012 的 43.0~45.0s。其余所有「静」都是 ducking / 抽空，**不是绝对静音** |

## 一、通用规范（全剧口径，EP01 落地值）

| 项 | 规范 |
|---|---|
| **整体音色** | **写实电影感**：真实环境声（暴雨/水/风）为骨，能量类声部（共振/嗡鸣/吸入）为「超现实设计层」。**两层结构，不是恐怖片音效三层**。基调＝**冷蓝湿夜**。⛔ 全片不使用 jump scare 冲击音、不使用神怪音、不使用任何非人化兽吼（D03 §6.4 全剧锁 L1~L2，禁 L3） |
| **混响空间感** | **场景 A（金水桥桥面）**：湿沥青＋开阔江面反射，**RT60 ≈ 1.2~1.6s**，**干湿比 6:4**（雨幕铺底占干声位，环境反射做湿）｜**场景 B（金溪河寒段水底）**：**低通闷响**（截止 400~600Hz，高频全切），**干湿比 100:0**——水下声场是「闷」**不是「空」**，**不铺混响**（水下没有镜像反射面）｜**交界 005→006 @18.0s**：按 D16 §二 走**声音先行的硬切＋J-cut 声桥**（17.8s 起水下闷响提前 0.2s 侵入，雨幕在切点前 0.2s 内压低） |
| **BGM 编制** | **混合编制，无人声旋律**：低音大提琴 / 低音合成器 pad / 晶体玻璃质感合成器 / 钢琴单音 ＋ 电子低频层。⛔ **禁止人声吟唱/吟经/梵音/钟磬/法器/寺庙钟声**（D03 §6.1 L-02 迷信规避＋派活硬约束）｜**主旋律动机＝「裂隙三音」贯穿全剧**（见 §五·3）｜**本集无片头曲、无片尾曲、无歌词**（D16 §四 序 10）→ 送审「歌曲的字幕表」为空表 |
| **配音音色** | 少年男声（偏低不亮，18 岁）＋ 中年男声（沙哑破碎，40~50 岁外表）。语速见 §二｜**全片仅 3 句台词**（D09：3 句 / 19 字），**无旁白、无字幕音、无片头人声**（D09 §四）｜⚠️ **若启用 AI 配音，须同时满足音频侧 AI 生成标识要求**（D03 §6.5 扩展适用条款，见 §四·6） |
| **拟音原则** | **部分拟音＋分层设计**：环境层（雨/水/风）＝真实录音｜能量层（共振/嗡鸣/吸入）＝设计合成｜**Foley 拟音只用于动作接触点**（轮胎擦水、链条、车架、栏杆震颤、衣物撕扯、脚步、入水）｜⛔ **禁止用拟音模拟人体创伤**：**零骨节声、零撕裂声、零喷溅声、零呛咳声、零泡沫声**（D03 R5／§9 声音设计执行卡） |
| **动态范围** | **峰值 -1 dBTP**（true peak，防平台转码削波）｜**整体响度 -15 LUFS**（竖屏平台常用 -14~-16 区间中值，手机外放留 1dB 余量；容差 **-16 ~ -14 LUFS**）｜**LRA 5~8 LU**｜**环境底噪基准**：场景 A 雨幕 **-24 dBFS RMS**／场景 B 水下低通铺底 **-28 dBFS RMS**｜**绝对本底（digital silence）不高于 -50 dBFS**（防手机端可闻嘶声）｜⚠️ **43.0~45.0s 的绝对静音段不计入响度积分窗口**，但**不得因此降低全片响度补偿**（防平台二次归一化把全片推高） |

## 二、角色配音音色卡

> 台词原文、语气、潜台词见 D09 §一/§二。**本表只补「怎么录、怎么混」的工程口径**，不新增任何台词、不改任何字。
> ⛔ **本集台词总量 3 句 / 19 字，下游不得自行加台词**（D09 头注）。

### 2.1 张陈（18 岁 · 少年 · 救人者）

| 项 | 内容 |
|---|---|
| **音色特征** | 少年男声，**偏低、不亮**；胸腔共鸣薄，喉位靠前。喊叫用**推喉＋抬颚**打满力气，**不是气声、不是台词腔、不是播音腔、不是偶像剧少年腔**。湿透＋寒冷让声音发紧，**允许一点气息抖，但不允许抖成害怕**（D09 §2.1） |
| **语速** | **快**。句①「别过去！那边有人！」7 字 ≈ **1.5s**（≈**4.7 字/秒** ≈ 280 字/分）；句③「救人啊！」3 字 ≈ **0.8s**（≈**3.8 字/秒** ≈ 230 字/分）。⚠️ **两句之间不接气、不重复、不结巴**——「慌」体现在速度与气息，**不体现在重复** |
| **句式 / 口头禅** | 极短句、动词开头、不修饰（6 字级主谓「别过去/那边有人」；3 字级动宾+语气词「救人啊」）｜**「啊」字尾语气词全集仅 1 次**；⛔ **不设其他口头禅**（2 句语料不足以立口癖，立了就会失真） |
| **情绪幅度上限** | 喊叫峰值 **不破音、不嘶吼**（上限＝全力气的 80%）；**不哭腔**（本集无哭点）；张力上限＝「喊叫的全力度」，**本集不进入恐惧/崩溃档** |
| **录音与混音口径** | ① 建议**同期声**录制（模拟中等雨噪环境）以便后期 duck 干净；② **EQ**：轻微切 200~250Hz（去箱音）＋ 2.5kHz 提 2~3dB（提亮但保留「薄」），**保留少量近讲效应**；③ 两条台词的**尾音被雨声吃掉一半**（D08 情绪提示）——处理方式：**台词轨在收音后 0.3s 让雨声「盖回」（雨声 +3dB 渐入）**，⛔ **不是把台词淡出**（淡出会读成「底气不足」） |
| **情绪禁区（不演的）** | ① 不解释世界观名词 ② 不自嘲/不吐槽 ③ 不说劝退句（「不行」「来不及」「别跳」）④ 不说礼貌词 ⑤ 不说与在校身份相关的词 ⑥ 不出内心独白/自语 ⑦ **不喊「救命」**（他是施救者不是被救者） ⑧ 长线冷讽语气不启用 ⑨ ⛔ **不做恐惧音/濒死音/受苦音**（D03 R5 降调，人物状态是「震惊与自愿」） |
| **本集录音时码（交剪辑端）** | 句① **03.5~04.8s**（字幕 03.4~05.0s，D16 §四 序 5）｜句③ **15.3~16.2s**（字幕 15.1~16.8s，D16 §四 序 7） |

### 2.2 黑衣男子（外表 40~50 岁 · 渡桥者 · 暗能承载者）

| 项 | 内容 |
|---|---|
| **音色特征** | **沙哑、破碎**，像喉咙已经被什么堵住（D04 §3.4）——⚠️ 表演上**只做「气与声的损耗」，不做血腥联想**。**实声:气声 ≈ 1:1**，每个字之间有气口；**气息像漏气，不靠音量**。⛔ **绝不做非人化怪音、不做混响叠层、不做降八度、不做反向处理**——**他是一个正在坏掉的人，不是一个亡者**（D05 T13） |
| **语速** | **极慢**。9 字分 **3 个气口**：「孩子」／「……」／「被选中的是你」。**句首吸气 0.5s →「孩子」后停 ≥1.5s →「被选中的是你」内部再停 0.5s**；全句 ≤4s，本集**按 2.5~3.0s 演**（D08 单元 4 给 3.0s，留白给雨声与漩涡起音） |
| **句式 / 口头禅** | 单句陈述＋呼语＋判断句；省略主语（无「我」）、省略宾语（不说「选中的是你」）；⛔ 不用疑问句、祈使句、感叹号｜**「。」必须落下**——那是判决，不是商量｜**口头禅：无**（9 字不足以立口癖） |
| **情绪幅度上限** | 音量上限＝**正常说话的 60%**（气息损耗所致）；**峰值不高于张陈喊叫的 1/3**；⛔ **不靠提高音量表达「威严」**、不做威胁腔、不做索命腔 |
| **录音与混音口径** | ① 干声录制，**不加任何空间混响**（空间感全部由场景混响提供）；② **EQ**：切 180~220Hz（去「嗡」）、2~4kHz 稍收（去「亮」），保留喉部粗糙的**不规则瞬态**——**毛躁感来自瞬态而不是持续的高频噪声**；③ 三个气口**必须是真吸/真呼**，⛔ 不用后期拼接的「呼吸素材」；④ **「……」是表演性停顿，不是省略号音**（⛔ 不得给「……」加任何音效化处理——不加颤音、不加延迟） |
| **情绪禁区（不演的）** | ① 不解释「选中」是什么 ② 不报家门 ③ 不说「救我/拉我一把」 ④ **不威胁、不恐吓** ⑤ 不说第二句台词、不出画外音 ⑥ **不表现出已死者的语感** ⑦ 不用文言腔、不说教、不留训诫 ⑧ ⛔ 禁贬称（用「孩子」） ⑨ **不表演痛苦**——交付是仪式，不是求救 |
| **本集录音时码（交剪辑端）** | 句② **05.5~07.8s**（字幕 05.4~08.0s，D16 §四 序 6） |

### 2.3 声音分工总原则（防止各层抢戏）

| 层 | 承担什么 | 不承担什么 |
|---|---|---|
| **人声层** | 全部信息量（3 句台词） | **不承担「非人感」** |
| **能量层**（极低频/共振/嗡鸣/吸入） | 全部「非人感」与仪式感 | 不承担叙事信息，不承担情绪说明 |
| **环境层**（雨/水/风） | 空间真实感 + 计时器（让观众知道「过了多久」） | 不承担奇观 |
| **拟音层** | 动作接触点的可信度 | **不模拟人体创伤**（零血腥） |

## 三、【第 01 集：深渊换心】· BGM 情绪曲线

> **四段结构严格对齐 D07 v1.3 / D11 / D16**：① 0~5s 黄金前戏｜② 5~18s 冲突升级｜③ 18~32s 水下奇观｜④ 32~45s 高潮卡点。
> **「裂隙三音」＝全剧主题动机**（定义见 §五·3）。本集它只出现 2 次完整形态：004 与 010。
> **dB 标注**＝该层相对满刻度的 RMS 电平；峰值另标于备注。

### 3.1 情绪曲线总表（精确到秒）

| 时间码 | 镜号 | 段 | 情绪/强度 | 描述 | 关键事件 |
|---|---|---|---|---|---|
| **00.0** | 001 | ① | **静默级 / -inf（旋律层）** | **BGM 旋律层＝0**。只有暴雨底噪（-24dBFS）＋ 30~50Hz 极低频共振垫底（-30dBFS）。开场的全部力量交给画面 | 暴雨建立；闪电 |
| **01.2** | 001 | ① | **浮现 / -30dB** | 推镜抵达后颈，**极低频共振上浮 +3dB**；雨声高频开始被极轻地「抽」走（反向吸声起，0.3s 渐入） | 后颈三道符纹裂隙（全片第一钩子） |
| **01.2~03.0** | 001 | ① | **单音 / -20dB** | **「裂隙三音」动机只出现第一个音**（D 低音，晶体质感，1.5s 自然衰减）。**三个音只给一个**——观众数不清三道，却觉得「有什么东西在数」 | 定格读数段（观众已看清裂隙） |
| **03.0** | 002 | ① | **退让 / -26dB** | 动机余音归零，BGM 退回**纯垫底**（极低频共振 -32dB）。让位给张陈的第一句喊话 | 急刹 + 台词① |
| **05.0** | 003 | ② | **让位 / -30dB** | **BGM 压到最低**：雨幕与共振一起降到 -30dB（**半静默 duck**），让这句金句独占听觉 | 台词②「孩子……被选中的是你。」 |
| **06.3~07.8** | 003 | ② | **留白 / -32dB** | 「孩子」后的 ≥1.5s 停顿：环境层保持 -30dB，**不绝对静音**（观众仍知自己在雨里） | 停顿＝气力不支 |
| **08.0** | 004 | ② | **起 / -24dB** | 漩涡起音前 0.15s **全层抽空**；随后「裂隙三音」**完整形态首次出现**（三音于 8.0/8.6/9.2s 依次落下，末音重音） | 桥面塌陷漩涡亮起 |
| **11.0** | 005 | ② | **上行 / -10dB（峰值）** | 动机**加速变奏**：节奏密度加倍（8 分音符脉冲型），加入心跳型低频节拍，弦乐层急促 | 弃车 → 脱外套 → 冲刺 |
| **15.3~16.2** | 005 | ② | **弱化重拍 / -14dB** | 台词③「救人啊！」落点上给一记**弱重拍**（不盖台词），16.2s 收 | 翻越护栏 + 喊话 |
| **16.9~17.6** | 005 | ② | **坠落感 / -20dB** | 动机**尾音随人身下坠**（音高整体下滑 1 个半音 + 混响拉长），17.6s 入水时被雨声吞掉 | 入水（一带而过） |
| **18.0** | 006 | ③ | **切入水下 / -28dB** | **J-cut 声桥**（17.8s 起水下低通闷响提前 0.2s 侵入）。BGM 整体切至水下声场：低通 500Hz，无旋律，只剩**符文场谐波铺底**（起，此后不切） | 睁眼上浮 + 符文场包裹 |
| **22.0** | 007 | ③ | **下潜 / -16dB** | 「裂隙三音」**变奏 1：晶体共鸣型**（三个音变成嗡鸣的三个泛音层），极低频轰鸣 30~50Hz 抬到 -12dB。**这一段的听觉逻辑是「往下沉」** | R6-1 符纹自内向外亮起 |
| **26.0** | 008 | ③ | **收拢 / -14dB** | 变奏 1 保持；叠加**粒子聚拢声**（四周向中心收），能量感从「下沉」转为「集中」 | R6-2 体外凝核悬浮 |
| **30.2** | 009 | ③ | **吸 / -8dB（渐强）** | **能量吸入声**渐强至峰值，动机泛音持续上行。听觉上「有东西正在被抽走」 | R6-3 光带沿手背→前臂→胸口 |

| **4** | **004 @07.85~08.0s** | **瞬时静默**（0.15s） | 漩涡起音前的全层抽空 | 「世界先让开」 |
| **5** | **011 @39.5~41.5s** | **渐次抽离**（⛔ 非静默） | 逐层撤走至仅剩地板 + 耳鸣 | 轮廓丢失＝声音被抽走；与 001 呼应形成首尾闭环 |
| **6** | **012 @43.0~45.0s** | **绝对静默 2.0s** | 全部轨道 -inf | **本集最后一个信息**；黑场留白（D16 §六） |

> **规则**：⛔ **绝对静默全片只允许出现在 012 的 43.0~45.0s**；其余所有「静」一律用 **ducking / 抽空 / 逐层撤走**，不得做成绝对静音。
> ⚠️ **012 的黑场不得被音效「填满」**——常见错误是给黑场加环境底噪或持续心跳，这会直接毁掉本集钩子。

### 5.3 跨集主题动机

#### 5.3.1 主动机：「裂隙三音」（The Fissure Three）

| 项 | 规格 |
|---|---|

| **EP01 出现位置** | 001（**只有第一音**）→ 004（**完整三音**，首次）→ 010（**全奏**，主峰）→ 011（**逐音抽离**）｜**EP01 全集只出现 2 次完整形态**（004、010）——45 秒里旋律越少，每一次出现越重 |

#### 5.3.2 次级符号：「心跳」（Heartbeat One-Hit）

| 项 | 规格 |
|---|---|
| **音色** | 50~60Hz 正弦 + 极短包络（10~30ms 攻击 / ~300ms 衰减）｜⛔ **不带混响**、⛔ **禁「咚-咚」双拍**（双拍＝器官搏动联想，与 R6-2「禁搏动收缩」冲突）、⛔ 不加心跳监护仪式的「滴」声 |
| **本集出现** | **2 次**：31.5s（入体）· 41.5s（完成） |
| **叙事含义** | 「身体里有东西」的听觉符号。EP01 观众还不懂它是什么，只听见两记闷响——**它先于观众理解** |

## 六、混音与响度规范

### 6.1 交付格式与技术规格

| 项 | 规格 | 理由 |
|---|---|---|
| **采样率 / 位深** | **48kHz / 24bit WAV** | 平台通用；24bit 留足低频动态 |
| **声道** | **立体声（2.0）**，⛔ 不交 5.1 | 竖屏平台为手机端播放 |
| **低频处理** | **30~50Hz 极低频层必须做「体感替代」**：在 **60~90Hz 放一份同相位谐波能量**，并在 **150~250Hz 留一层柔和替代层** | ⚠️ **手机小扬声器放不出 30Hz**。若只做 30~50Hz，**观众在小屏外放上会完全听不到本集的核心低频**——这是最容易被忽略、也最致命的一处 |
| **声像** | 环境层宽而相关（左右相关系数 >0.7，⛔ 不做宽立体声展开）；**能量层与心跳严格中置**（⛔ 禁左右漂移） | 竖屏窄画幅；平台下混单声道时，能量层若偏移会相位抵消 |
| **手机单声道下混检查** | 交付前必须做一次 **mono fold-down 试听**（能量层与心跳在中置，折叠后电平无抵消） | 平台与用户大量使用单声道外放 |

### 6.2 分层电平表

| 层 | 基准电平 | 峰值上限 | 说明 |
|---|---|---|---|
| **对白层** | **-18 dBFS RMS** | -3 dBTP | 最高优先级；任何时刻不被掩盖（张陈 002/005、黑衣男子 003） |
| **情绪/能量音效层** | **-24 dBFS RMS** | -6 dBTP | 极低频、嗡鸣、吸入、聚拢、水体位移 |
| **Foley 拟音层** | **-26 dBFS RMS** | -10 dBTP | 轮胎、链条、栏杆、布料、脚步 |
| **环境底噪层（场景 A 雨幕）** | **-24 dBFS RMS** | — | 恒定铺底；**同时承担场景 A 的 BGM 底噪功能** |
| **环境底噪层（场景 B 水下闷响）** | **-28 dBFS RMS** | — | 低通 400~600Hz |
| **心跳重音（① 31.5s / ② 41.5s）** | — | **-3 dBTP** | ⛔ 不带混响；② 比 ① 沉一档 |
| **绝对本底** | **≤ -50 dBFS** | — | 防手机端可闻嘶声 |

### 6.3 动态与 ducking 规则

| 规则 | 规定 |
|---|---|
| **整体响度** | **-15 LUFS**（容差 **-16 ~ -14**）；**LRA 5~8 LU**；峰值 **-1 dBTP** |
| **对白 duck** | 台词起音前 **0.2s**，环境层与情绪层自动压低 **6~8 dB**；台词结束后 **0.3s** 恢复（⛔ **不做硬切**）。侧链参数建议：attack **20ms** / release **300ms** |
| **对白优先** | 任何时刻，**对白轨不得被任何层掩盖**；能量层与对白同时发声时，能量层峰值不得高于对白 6 dB |
| **呼吸与喘息** | 张陈 002 的喘气（-16dB）与黑衣男子的三个气口，**均不得被 duck 处理掉**——它们是表演的一部分 |
| **003 的半静默** | 06.3~07.8s：环境层压至 -30dB（**连续渐变，不是阶跃**） |
| **004 的起音抽空** | 07.85~08.0s：0.15s 内全层线性抽至 -inf |
| **009 的骤停** | 31.0~31.15s：0.15s 内全层抽至 -inf；31.5s 心跳重音落在空场 |
| **012 的静默** | 43.0s **硬切**至 -inf（⛔ 非淡出），保持至 45.0s |
| **响度积分** | 43.0~45.0s 的绝对静音段**不计入 LUFS 积分窗口**，但**不得因此下调全片响度补偿** |
| **禁止** | ⛔ 动态压缩把能量层「推平」；⛔ 限制器在心跳重音上留下泵感；⛔ 任何让本集听起来像「恐怖片音效包」的处理 |
