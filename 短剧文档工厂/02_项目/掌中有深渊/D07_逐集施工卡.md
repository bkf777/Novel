## 一、场景需求 · 场景 A（金水桥桥面）

> 写给白模场景师：**只写空间、尺度、道具、出入点、动线、光源关系、负向约束**。机位与镜头语言由 D11 定，D13 据 D11 出白模说明书。

### A1 平面与尺度

| 项 | 规格 |
|---|---|
| 桥面宽度 | **6.0 m**（单车道 + 两侧各 0.5 m 边缘）。够一辆自行车 + 一人侧身通过，**不允许两车并行** |
| 桥面纵向长度 | **≥ 40 m**（需完整容纳"骑车进入 → 急刹 → 弃车 → 冲刺 → 翻越"的连续动线，并保留远景纵深） |
| 桥面横坡 | **向两侧排水的 2% 横坡**，雨水流向护栏外侧（**排水方向必须与护栏外侧是河一致**） |
| 桥面材质 | 旧水泥/沥青，湿滑反光，有积水洼与车轮碾痕；**急刹落点处需留出刹车滑行痕与轮胎擦痕** |
| **桥面到水面的落差** | **≥ 8.0 m**（决定坠入的下坠量级与"环形冲击波"的对比尺度） |
| 护栏外侧 | **直接就是河**，**不得有河滩、护坡或台阶**——本集不存在"从桥下到岸"的动线 |

### A2 桥栏杆（**最关键的可翻越结构**）

| 项 | 规格 |
|---|---|
| 形式 | **金属立柱 + 上下两道横杆**（不是实心女儿墙、不是密闭栅栏） |
| 高度 | **1.10 m**（张陈可翻越的高度区间） |
| 横杆净空 | **≥ 0.35 m**（必须容得下一个人侧身通过/翻越） |
| 连续性 | 沿桥两侧**连续不断**；与桥面之间有 0.05 m 排水缝 |
| 湿态表现 | 表面挂水、锈迹、雨水顺杆流下 |
| **指定翻越点** | **右侧栏杆（张陈骑行方向的右手侧）**，距黑衣男子站位 **1.5 ~ 2.5 m** 的一段栏杆，**该段需预留"刚刚被翻越过"的形变/位移量**（白模给出一个可复位的松动或形变节点） |
| **⚠️ 外套搁置点（D03 新增）** | **同一段栏杆上、翻越点旁 0.3~0.5 m 处**，需有一个**可挂放一件外套**的横杆/节点。张陈在此**脱下校服外套并甩在栏杆上做记号**（D03 §3.3）。白模需保证外套有地方待着，且**不坠落**（可搭在横杆上）。 |

### A3 出入点与在场动线

| 项 | 规格 |
|---|---|
| **出入口 1（张陈进入）** | 桥面上游引道口，**平缓上坡**，张陈由此骑车入画 |
| **出入口 2** | 桥面下游口（本集不使用，仅为空间完整性保留） |
| **不得有第三个出入口** | 桥面封闭、无商铺、无路灯杆、无广告牌形成额外可通行口 |
| **黑衣男子：无入场动线** | 白模中他**已存在于场**，站在右侧栏杆边。**不为他设计任何入场路径**（避免白模暗示"他刚走上桥"，那会破坏"择人仪式"的伪装逻辑） |
| **张陈动线（5 段，必须一镜到底的空间连续性）** | ① 骑车由上游引道进入桥面 → ② **急刹落点**（距黑衣男子 **8 ~ 12 m**，车轮打滑，需留出滑行痕）→ ③ **弃车点** → ④ **脱外套 + 外套搁置点**（A2）→ ⑤ 冲刺至**翻越点**并翻出护栏 |
| **自行车落点（须精确指定）** | 位于**弃车点**，距翻越点**纵向 3 ~ 5 m**。姿态：**被甩弃后自然侧翻**——车体侧倒、**车头朝向来路方向**（惯性前扑式）、前轮离地翘起、车把缠胶布、车铃失灵。**不是整齐停放**，不许做成"停好的一辆车" |

### A4 黑衣男子站位（场景 A）

| 项 | 规格 |
|---|---|
| 位置 | 右侧栏杆边，距栏杆**约 0.3 m**（半个身位），**面朝河外侧**（背对桥面来向），迎风站立 |
| 姿态 | 迎风站立、迎向暴雨，**头发与风衣下摆被风压向前**（给出下压力方向参考） |
| 服装占位 | **黑色长风衣**，过膝；下摆已浸水、拖曳、贴地 |
| 异变占位 | **后颈三道几何状暗金符纹裂隙**（三道，位置在颈后）—— 白模阶段用**三个独立占位体**标出，**不建实际几何细节**（视觉由 D10/D12 负责）。⚠️ **不得建任何"嘴/齿/黏膜"形态** |
| 湿痕 | 服装上**深色水痕与泥浆渍**（几何上是材质分区；**画面不得出现任何红色液体**） |
| **⚠️ 脚下漩涡（D03 新增）** | 黑衣男子**站立点位正下方的桥面**，需预留一个**直径 ≈ 2.5 m 的塌陷暗色漩涡**的占位（几何上是**桥面局部凹陷/扭曲**的形变区）。白模只给**凹陷体积与边缘**，不建"洞"——⚠️ 99_交付说明 白模指令明确：**桥面暗能漩涡无物理破口**（不得做成能落人的洞） |
| **正面** | ⚠️ **不展示正面全脸**，只给半张被符纹爬满的侧脸。位置与朝向需允许"侧头"这个动作 |

### A5 光源与天气

| 项 | 规格 |
|---|---|
| **唯一环境光源** | **闪电**——自上方偏侧方的**高频频闪**，方向在每次雷击时随机偏移（建议预设 3~4 个主方向供分镜调度） |
| 路灯 | **不设路灯**（保证闪电是唯一环境光，画面不会平） |
| 雨 | **暴雨**：雨幕密度高、能见度低、桥面形成镜面水膜、栏杆挂水、雨点在镜头前形成失焦光斑 |
| 雷 | 闪电时**桥面与栏杆产生锐利高对比边缘光**，其余时刻接近全黑（**明暗差极大**是本场景的视觉主特征） |
| 天光 | 暴雨夜天光极低，仅提供**极弱的冷蓝环境底光**，保证阴影里不是死黑（建议保留 5~8% 的冷蓝底噪） |
| 漩涡自发光 | 脚下漩涡**不作为场景照明**，仅在自身范围内给一点极弱的暗金底噪 |

### A6 场景 A 的负向约束（**不要做**）

❌ 不要河滩／护坡／台阶（会让人以为能走到岸）
❌ 不要路灯、护坡灯、广告牌、车辆、行人（**本集桥上只有两个人**）
❌ 不要完整无损的护栏（必须是可翻越的横杆结构）
❌ 不要自行车停得整整齐齐
❌ 不要给黑衣男子安排入场路径
❌ **不要在桥面做任何物理破口**（漩涡只是凹陷/扭曲，不是洞）
❌ **不要任何红色液体**（血渍、红色符文、红色水痕一律不要）

## 二、场景需求 · 场景 B（金溪河寒段水底）

### B1 空间尺度

| 项 | 内容 |
|---|---|
| 河宽 | **≥ 30 m**（保证水下有纵深，不是"一个小水坑"） |
| 水深（落水点至河床） | **6 ~ 8 m** |
| 水面以上空气层 | **≥ 8 m**（与场景 A 落差对应，黑衣男子自桥面高度被漩涡卷落） |
| 河床性质 | **硬质河床**（碎石、淤泥、冬季冰碴），**必须是能承重/能悬浮站立的面**，不能是流沙（否则"直立水中"不成立） |
| 桥下结构 | **至少一个桥墩**（带水下柱身、冲刷坑、附着物），提供纵深与"这里是金水桥"的可信度；黑衣男子落水点**靠近该桥墩** |
| 水体色 | 墨绿偏黑、浑浊，**不透明**（视线穿透不超过 3~4 m），**不得清澈见底** |
| 水面层 | 需保留一个**水面层**（用于涟漪、雨点打水、反射闪电），白模需支持从水下仰视水面的视角 |
| ⚠️ 负压/真空区 | **不建任何真空/负压空腔**（D03 R8）。冲击波是**能量扩散**，不是"水的缺失" |

### B2 上下浮沉动线（**白模必须能复现这三条线**）

| 角色 | 动线 |
|---|---|
| **黑衣男子** | ① 自桥面落差高度**被漩涡卷落**（旋转入水，非仰面栽入）→ ② 下沉至河床上方 → ③ **直立悬浮于河床上方**（垂直站姿；⚠️ **删除"尸体般"表述**，风衣在水中呈**违反物理的上扬姿态**）→ ④ **R6-1** 隔着完整风衣，胸口符纹自内向外亮起 → ⑤ **R6-2** 神核在**体前 ≥30 cm** 处凝聚悬浮 → ⑥ **横向平移** 1.5~2 m 靠近张陈 → ⑦ **R6-3** 神核碎解为光带，沿张陈手背→前臂→胸口没入 |
| **张陈** | ① 入水点与黑衣男子落点**横向错开 1.5 ~ 2 m**（制造"够不着"的距离）→ ② 下沉 6~8 m → ③ 悬停于**河床上方约 1 m** → ④ **睁眼上浮、四肢自然舒展、不挣扎**的悬浮姿态（**不得做抽筋、拍打挣扎、呛咳、口吐泡沫**；受困感由下沉速度与视野变暗表达）→ ⑤ 瞳孔中映出金色符纹；一片**旋转的金色符文场**自身侧升起并将他缓缓向下包裹 → ⑥ 神核渡化时**仍在河床上方约 1 m 悬浮** |
| **神核** | ① 起始**在黑衣男子胸口内**（隔着完整风衣可见符纹）→ ② **R6-2** 在体前 ≥30 cm 处**体外凝聚成形并悬浮**（多面几何核，表面旋转符文环，内部暗紫金能量涡流）→ ③ **R6-3** 碎解为金色光带与粒子流，沿手背→前臂→胸口移动并没入 → ④ 入体后**原地爆开** |
| **金色符文场** | 自身侧升起、旋转、**向下包裹张陈**的体积场；光粒沿他的校服轮廓流动。⚠️ 这是**场域体积**，不是道具，需在白模中给出**可包围一个人形的体积边界** |

> **关键空间关系**：两人在**同一深度层**（河床上方 0~1 m）、**相距 1.5~2 m**、**面朝对方**。这个"并排悬浮"的关系是 18~32s 段全部动作的舞台，不能一高一低、一远一近。
> ⚠️ **R6-3 的空间纪律**：光带走位是 **手背 → 前臂 → 胸口**（一条沿手臂到躯干的路径），**不是**从体外直线飞进胸口。白模需保证**张陈伸出的手**在两人之间可见、可达。

### B3 光源方向（**本段最容易做错的地方**）

| 光源 | 位置 / 方向 | 强度 | 说明 |
|---|---|---|---|
| **神核 / 符纹**（暗金几何符文环 + 能量涡流） | 起点在黑衣男子胸口（隔着风衣透出）→ R6-2 移至体前 → R6-3 沿光带走位至张陈胸口 | **唯一强光源** | ⚠️ 暗金符文是**符文自发光**，不是"吞噬光的暗源"，也不是白灯泡。R6-1 阶段它**隔着衣料**透出（只照亮布料表面纹路）；R6-2 阶段它在体外，**全强度**照亮两人之间的水域；R6-3 阶段它碎解成光带，成为**移动光源** |
