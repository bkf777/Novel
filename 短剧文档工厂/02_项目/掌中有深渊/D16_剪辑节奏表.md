## §二 转场设计

| 项 | 规定 | 理由 |
|---|---|---|
| **总体形态** | **全片 11 个切点全部硬切**，不使用叠化（dissolve）、淡入（fade in）、划像、翻页、白闪 | 竖屏快切节奏（D02 §4.1「竖屏快切」）；叠化会吃掉 45 秒里的宝贵时长并削弱钩子 |
| **场景 A → 场景 B（005→006 @18.0s）** | **硬切 ＋ 声音先行**：切点前 0.3s 起，把 005 的环境声（雨幕）**在切点前 0.2s 内压低**，让 006 的水下低通闷响**提前 0.2s 侵入**（J-cut），观众先"沉下去"再"看见" | 本集唯一的场景切换。硬切＋声桥可避免观众误以为又回到桥上；这是唯一允许的声音预铺位 |
| **并行双线内部切换（006→007 @19.6s）** | 同场景、同色调、同光位，**直接硬切**，不加任何转场效果 | 两镜属同一水下空间，观众视角连续；任何转场效果都会把「两条线索并行」误读成「两个时空」 |
| **片头（001 起幅内）** | 片头文字层**层内淡入 0.2s（0.0~0.2s）**、**淡出 0.3s（1.7~2.0s）**；文字层本身不产生切点 | 淡的是文字层，不是画面；画面 0.0~45.0s 连续无切口，钩子首帧即有内容（D10 §5.2 第 3 条） |
| **片尾（012）** | 41.5s 硬切进全黑后**画面不再变化**至 45.0s | 黑场只允许用于集尾（D10 §5.2 第 3 条） |
| **禁止** | 任何闪白、频闪、故障（glitch）转场；任何暗示「异化/疯狂」的视觉特效转场 | D03 §6.4 惊悚强度锁 L1~L2，禁 L3；频闪属平台与审核高风险项 |

## §三 字幕样式规范

| 项 | 规格 | 依据 |
|---|---|---|
| **字体** | 思源黑体 / Source Han Sans **Medium**（或同类规范黑体）；**必须为规范汉字** | D18 §3.2.2（A4） |

| **颜色 / 描边** | 文字 #FFFFFF，**描边 #000000 2px**，不透明度 100%；不使用半透明底板 | 可读性与平台 UI 叠加下的对比度 |
| **位置** | **底部上移 ≥15% 画面高度**（1080×1920 下字幕基线距画面底 ≥288px），**水平居中** | D18 §3.2.3 ／ D10 §8.2（避开点赞/评论/关注区） |
| **行数 / 行宽** | **单行 ≤15 个汉字**；超行断为两行；本集全部为单行 | D18 §3.2.1 |
| **行距** | 1.3（两行时 1.25） | — |
| **停留时长** | **每条字幕 ≥1.2 秒**，与配音同步；出点不早于配音尾音 | D18 §3.2.4 |
| **入出点** | 字幕**不得早于配音起音**，出点**不早于配音收音** | 同步性 |
| **与角标避让** | 对白字幕区（画面下 1/4）与 AI 角标区（基线 72%~78%）**不得重叠**；角标在字幕行上方 | D10 §8.5 |

| **外文** | 本集无外文台词；**若后续出现外文，必须加中文字幕** | D18 §3.2.6 |
| **术语纪律** | **本集字幕不得出现任何世界观名词**（神核／暗能／异化体／噬核／深渊／镇夜司／渡化）——第 01 集观众不获得任何名词 | D05 §五 ／ D08 §一「本集刻意不给」 |
