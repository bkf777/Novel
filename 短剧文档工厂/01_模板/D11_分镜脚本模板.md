## 填写规则

1. **景别**只用：远景 / 全景 / 中远景 / 中景 / 中近景 / 近景 / 特写 / 大特写。
2. **机位**：平视 / 俯视 / 仰视 / 顶视 / 过肩 / 主观视角 / 客观跟拍（写清高度与左右）。
3. **焦距**：写毫米数并保持同一场景的视觉语言一致（对白戏多 35–50mm，情绪特写 85mm，场景交代 24mm 以内）。
4. **运镜**：固定 / 推 / 拉 / 摇 / 移 / 跟 / 升降 / 环绕 / 手持 / 变焦。**一个镜头只给一种主运动**。
5. **画面只写可见事实**：不写「气氛紧张」「她很痛苦」，写「右手握紧杯子，指节发白」。
6. **时长合计**必须等于该集预估时长；单个镜头超过 6 秒要在备注里说明原因。
7. **镜号**全局连续（本集从上一集末尾编号续接，不从 001 重来）。
8. 需要 AI 生成参考画面的镜头，在备注里标 `[需出图]`，供 D12 建立提示词卡。
