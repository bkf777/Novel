# D12 AI 提示词卡 · 模板

> 负责人：视觉设定｜上游：D10 视觉圣经、D11 分镜脚本｜下游：用户执行端（图像/视频生成）
> 硬性验收点：每张卡只描述**一个可见事实组合**；负向词必须填；一致性引用必须能被检索。

---

## 通用块（所有卡复用，不重复抄写，只引用编号）

| 编号 | 内容 |
|---|---|
| STYLE-01 | 全局风格句：<年代 + 视觉语言 + 色彩 + 材质 + 细节密度 + 氛围> |
| CHAR-01 | <角色名> 外形锚点句：<年龄感/体型/发型/服装材质/标志物> |
| CHAR-02 | |
| LOC-01 | <场景> 环境句：<地点 + 时代 + 材质 + 光源 + 景深> |
| NEG-01 | 全局负向词：<通用词> |

> 风格句、角色锚点句**只在此处定义一次**，每张卡用 `STYLE-01` 引用。跨卡复制粘贴会导致风格漂移，是 AI 短剧最常见的崩点来源。

---

## 图像提示词卡 · IMG-<镜号>

| 字段 | 内容 |
|---|---|
| 关联镜号 | D11 第 __ 镜 |
| 画面构图 | <景别 + 机位 + 主体在画面中的位置与比例> |
| 主体描述 | <谁/什么，只写可见特征> |
| 环境描述 | <地点 + 背景元素 + 纵深> |
| 光线 | <光源方向 + 硬软 + 色温> |
| 风格引用 | STYLE-01, CHAR-01, LOC-01 |
| 正向提示词 | <可直接粘贴的一段话> |
| 负向词 | NEG-01 + 本镜专属负向词 |
| 参数建议 | 尺寸 / 采样器 / 步数 / CFG / seed |
| 一致性说明 | <与前后镜必须一致的要素> |

## 视频提示词卡 · VID-<镜号>

| 字段 | 内容 |
|---|---|
| 关联镜号 | D11 第 __ 镜 |
| 起始帧引用 | IMG-<镜号> |
| 动作描述 | <主体怎么动，一句话只写一个动作> |
| 运镜描述 | <镜头怎么动，与 D11 运镜字段一致> |
| 时长 | __ 秒 |
| 结尾状态 | <末帧定格在什么状态> |
| 负向词 | NEG-01 + 运动类负向词（形变/闪烁/漂移/多手多脚） |
| 参数建议 | 模型 / 种子 / 运动强度 |

## 一致性台账

| 角色/道具 | 锚点编号 | 出现镜号 | 已知易崩点 | 处理方式 |
|---|---|---|---|---|
| | CHAR-01 | 001, 003, 012 | 发色漂移 | 固定 seed + 每卡重述锚点 |

## 执行提示

- 每张卡**单独复制**使用，不要把多张卡拼进同一次生成。
- 视频卡先生成图像卡并确认，再用图像卡做首帧。
- 同一角色跨镜保持同一 seed 策略或同一锚点句，二选一，全剧统一。
