## 一、复刻边界声明（先看这一页）

本项目采用的口径是：**保留机制重写故事**。

| 维度 | 源著的处理方式 | 本项目《末世火葬工》 | 处理 |
| :--- | :--- | :--- | :--- |
| **核心机制** | 以焚烧尸体为唯一攻击手段，从死者身上夺取力量 | 余烬焚尸，继承死者骨纹 | ✅ **唯一继承项**（抽象骨架） |
| 灾变来源 | 全球性规则降临 | 地球骸骨翻身，灰潮十四日一临 | 原创 |
| 能力代价 | 无代价，纯收益 | **忆蚀**——继承即承受死者最后一段记忆 | 原创增强 |
| 分级体系 | 字母等级制 | 骨纹一至九纹 | 原创 |
| 属性维度 | 常规体能四维 | 体魄 / 血气 / 影速 / 骨性 | 原创 |
| 规则道具 | 规则卡牌 | **律条**：撕下即改写一片区域的规则，且使用即受其约束 | 原创 |
| 副本体系 | 多重秘境，规则各异 | **骨窖五层**，每层一条规则 | 原创 |
| 榜单 | 双榜并行 | **潮名录**（官方版 + 民间版，长期互相造假） | 原创 |
| 终极威胁 | 后期升维玩法与规则反噬 | **双潮交汇 / 潮主 / 潮罚** | 原创 |
| 终局 | 击杀平行体的通关式收束 | **自愿焚己，完成"大葬"** | 原创 |
| 人物 | — | 陈野、苏晓棠、裴烈、纪梵、赵岚、陈远… | 全原创 |
| 视觉母题 | 火球 / 系统面板 / 掉落物 | 窑火 / 骨纹 / 潮名录 / 窑门 | 原创 |

> **结论**：全剧除"以焚烧尸体为唯一攻击手段，并从死者身上夺取力量"这一**抽象机制骨架**外，
> 不沿用源著任何具体表达。人物、命名、世界规则、叙事走向、视觉符号均为独立设计。
>
> **另有一处本剧自加的原创增益**：源著的焚尸掠夺是纯收益，本剧为其加了一条贯穿全剧的**代价线**——
> 每继承一道骨纹，死者最后一段记忆就住进主角脑子里。这条线是全剧的情绪引擎，
> 也是"变强"与"失去自我"同时结算的关键。
