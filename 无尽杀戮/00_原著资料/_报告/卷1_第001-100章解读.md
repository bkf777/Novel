## 一、卷 / 篇章划分

| 卷次 | 起止章 | 卷名（一句话） | 核心矛盾 |
|---|---|---|---|
| 卷一·上 | 第 1—25 章 | **《焚尸者的第一日》**——重生者回到杀戮游戏降临的一刻，靠一个不能伤人的火球在体育馆、宿舍与天台连开三条线 | **「信息差」**。林川知道怎么变强，但所有人都不知道；一旦被发现，藏不住就要被杀。于是"先装废物、再抢榜首、再藏锋"成了唯一解 |
| 卷一·下 | 第 26—50 章 | **《至暗十小时》**——午夜零点属性清零、秩序崩塌，真正的末世才开始，他顺势把排名、道具和仇人一起结清 | **「环境的第一次背叛」**。上一卷让人变强的大雨，转头变成屠杀；旧秩序（洛家/栾家/戚家/聂家）一夜之间变成新秩序 |
| 卷二·上 | 第 51—75 章 | **《恶龙与勇士：平行世界初见》**——两千人来自两千个平行世界，他在其中一边打工一边把恶龙阵营打成自己的私产 | **「规则漏洞」**。规则只说"理论如此"，漏洞就是唯一的生机；同时要跟一群随时能反咬的"队友"共生 |
| 卷二·下 | 第 76—100 章 | **《崩塌与登顶》**——秘境将崩，他把两个"另一个自己"带回自己的世界，顺手登顶世界杀戮榜 | **「收割与反收割」**。谁在利用谁、谁在扮演谁，边界彻底模糊；主角从"藏着的强者"变成"所有人都盯着的靶子" |

**分卷依据小结**：第 25/26 章（第 25 章末仍在暴雨夜、第 26 章直接跳到 3 级与全球公告）、第 50/51 章（公主被捏碎、下一秒切到"第 1801 名勇士"视角）、第 75/76 章（酒馆卡座 → 恶龙巢穴 16 连破），是三处最硬的时间/空间断点。

## 六、章末钩子类型统计（100 章采样）

| 钩子类型 | 占比 | 说明 | 本区间典型章 |
|---|---|---|---|
| **悬念 / 反问式** | 约 25% | 章末以"这是……？""难道……"收束，把解释权推给下一章 | 第 1、24、30、50、77、86、93 章 |
| **反转 / 认知推翻** | 约 20% | 刚建立的常识被掀翻（袁封是纸糊的、大雨是陷阱、勇士会变恶龙、盟友是凶手） | 第 6、14、23、28、42、73、99 章 |
| **危机 / 威胁逼近** | 约 15% | 敌意、杀机、死亡威胁直接压到脸前 | 第 5、19、37、47、67、89 章 |
| **信息差 / 身份马甲** | 约 15% | 读者知道而角色不知道（或反之），核心张力来自"身份何时被揭穿" | 第 26、44、51、52、84、92 章 |
| **新目标 / 新任务抛出** | 约 15% | 明确给出下一步行动指令或悬赏，形成追读驱动 | 第 3、27、33、47、96 章 |
| **倒计时 / 时间压力** | 约 10% | 限时任务、即将崩塌的秘境、24 小时窗口 | 第 37、48、87、89 章 |

**结构观察**：本区间钩子以"悬念 + 反转"双核驱动（合计约 45%），且大量使用**章末即高潮**的写法——第 11、22、30、50、67、86、93 章的收尾画面本身就能单独剪成一集短剧。前 25 章的钩子几乎全部是"身份差"型（我知道火球真用途，你们不知道），51 章之后逐渐切换为"规则差"型（我找到了规则的漏洞，你们不知道），这是本卷两段最重要的钩子换挡。

| 每日限额 + 越级取利 | 资源有硬上限，但品质无上限 → 逼迫玩家做"以次充好"还是"以质换量"的战略选择 | 极通用的资源节流机制，可嵌进任何养成系统 |
| 属性上限 + 稀缺突破资源 | 数值天花板必须靠稀有资源（清灵果 / 月渎石）打破，且资源本身绑定其他阵营 | 把"上限"改成多维（属性上限、等级上限、技能数量上限），形成多层天花板 |
| 榜单即 Boss 榜 | 排名的公开可视性自动把强者变成猎物，把荣誉变成负债 | 把"头顶金字"换成任何可见标识（灯塔、光柱、颜色），即可保留"越强越危险"的核心张力 |
| 至暗十小时式节律翻转 | 先给福利（暴涨）再收账（归零），且事先有知情者预告 | 通用节拍：每场大型活动前设一次"公开福利—私下预警"双轨 |
| 平局即全灭的秘境规则 | 用"零和"而非"胜负"定义对抗，让阵营双方都无法苟 | 换成"双方同时失败"或"资源归零"等零和变体 |
| 卖身契 / 连胜擂台 | 把副本包装成一份带契约、带赌注、带观众的"合同" | 极适合竖屏短剧的"打擂—押注—反杀"三段式 |
| 契约伦理灰区 | 用可交易的"活人"（死亡封印）与主仆契约制造道德不适感 | 弱化卖人，强化"用规则漏洞搬运自己人"，规避伦理风险 |
| 规则问答 + 文字漏洞 | 由中立 NPC 回答规则提问，答案的措辞留缝，角色靠抠字眼取胜 | 极低成本的高智斗设计，几乎可原样套用于任何规则型副本 |
| 舆论围剿 → 反杀立威 | 匿名频道先造"杀人狂"人设，主角反手用更强战绩打脸 | 配合"人言可畏，实力为尊"的价值观收束，是爽点的标准件 |
| 收割与反收割 | "你以为你在捡漏，其实你在被捡" | 用在主角身边的每一个"临时盟友"身上，制造连环反转 |

### ⛔ 不宜直接搬用（本书专属识别度过高）

| 素材 | 原因 |
|---|---|
| 「火球焚尸掠夺」这一具体天赋组合 | 已被书名占用，是本书最强识别符号，等同核心 IP |
| 死神系列四神器（死神之握 / 之镰 / 之面 / 之斗篷）及"神器榜前十"设定 | 专名化且已形成体系，改名不彻底会显得像抄 |
| 杀戮游戏 / 等级榜 / 杀戮榜 / 区域榜 / Boss 榜整套名词体系 | 名词密度高、专有化强，是本书世界观签名 |
| 「30 天后世界融合 + 强制击杀另一个自己」的主线骨架 | 是作者贯穿 830 章的终极悬念，属核心创意资产 |
| 完整数值表（上限 100、每日 10 枚、越 5 级减半、2000 人秘境） | 直接搬数值会构成实质性雷同，且后续难以自洽 |
| 自在天 / 位面等级（低等·中等·高等·本源）/ 竞技场卖身契 | 「无限流 + 副本竞技 + 位面Hierarchy」组合已被本书写透，原创者若沿用极易撞车 |
| 角色姓名与人设组合（林川、寺尾由以奈、宿灵、骆姝红、明夏、徐问剑等） | 姓名 + 身份 + 性格三重复制风险最高 |
| 黑色盲盒 + 命运扑克 54 张的具体道具形态 | 牌面四象限设计有辨识度，复刻需更换媒介与命名体系 |
| "恶龙与勇士"秘境的角色配置（200 恶龙 / 1800 勇士 / 公主 / 水晶球） | 借用童话母题但规则细节已高度定制，直接搬运等于搬运整个副本 |
| 「借尸还魂 + 替死娃娃」组合作为收尾反转 | 本区间最巧的收束方式之一，建议只借鉴"身份错位反转"这一抽象，不复用具体机制组合 |

### 一句话结论

**可复用的是"骨架"，不可复用的是"零件名"**。最值得提炼的三件事是：① 资源限额 × 品质无上限的成长曲线设计；② 用中立 NPC 的规则问答制造文字漏洞解谜；③ 把排行榜变成"公开的死亡通缉令"。而"火球焚尸""死神神器""杀戮榜"这三组是本书的姓名，绕开它们，换一套自己的命名体系，才算真正的原创复用。
