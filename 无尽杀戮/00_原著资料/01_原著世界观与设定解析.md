## 一、灾变与降临机制

**表层设定**：杀戮游戏在全球降临，所有人同步觉醒"数据化面板"与"天赋"，随后全球出现次元生物入侵。

**降临节奏**（作者自述的三个硬时间点，构成全书时间骨架）：

| 阶段 | 时长 | 设定要点 |
| :--- | :--- | :--- |
| **新手福利期** | 降临后 9 小时（至当日午夜 0 点） | 全球仅存在"次元虫"一种低威胁生物；防御与攻击都拉垮，唯一优势是触角可远程绞杀；速度属性高于 1.2 即可闪躲。此阶段会自发出现"人比怪多"的抢怪现象 |
| **末世暴雨** | 暴雨期约 4 小时 | 暴雨中玩家四维属性临时暴涨，但雨停后属性跌回 0.5 以下并维持 10 小时——**"至暗十小时"**，秩序崩塌，旧世家一夜失势 |
| **常态期** | 之后 | 维度裂隙、秘境、职业、转职、位面融合逐层开放 |

> **结构价值**：作者把"变强期"与"屠杀期"用天气切换强行焊在一起，一夜之间完成新旧秩序的置换，这是全作最省力的结构杠杆。

## 二、面板与四维属性

```
【林川】
【等级：0（0/10）】
【力量：0.9】【体质：1】【速度：1.2】【精神：1.1】
【天赋：火球】
```

| 项 | 规则 |
| :--- | :--- |
| **四维** | 力量 / 体质 / 速度 / 精神 |
| **等级** | 0 级起，升级所需经验随等级递增 |
| **经验来源** | **杀怪不掉经验，晶核才是唯一经验源** |
| **晶核换算** | 同阶 +1 点；越 1 级 +10 点；越 2 级 +100 点 |
| **每日上限** | 每人每天最多吸收 10 枚晶核，午夜 0 点刷新 |
| **属性上限** | 首次世界融合前四维极限 **100 点**；清灵果可提升神魂从而突破 |
| **等级压制** | 面对高出 5 级以上的目标，自身属性减半，天赋技能威力同样减半 |

> **结构价值**：每日 10 枚的吸收上限，把"资源稀缺"写进了日常节奏，逼迫角色持续外出猎杀——这是长线连载不掉速的引擎。

## 三、天赋体系与技能点

### 3.1 等级划分

**F 级 → S 级**（共 7 档）。S 级为当前公开上限，全书最高出现过 SSS 级（需特殊途径）。

### 3.2 天赋与技能

* 每个天赋都有**对应技能**；
* F 级需 1 技能点，每升一档 +1 点，S 级需 7 点；
* **天赋者学习自身对应技能需付出 10 倍技能点**——这是防止天赋自选、逼玩家进入副本与黑市的关键经济阀门。

### 3.3 关键天赋实例

| 天赋 | 级别 | 机制 |
| :--- | :--- | :--- |
| **火球** | 无标注 | 对活物零伤害；可焚尸并掠夺死者属性 / 技能 / 天赋（主角金手指，见 §十三） |
| **龙炎爆** | A | 范围火焰攻击，书中首批 A 级 |
| **禁魔领域** | S | 领域内低等级天赋与技能失效；仅对人类与类人形次元生物有效 |
| **血炼秘术** | S | 把 24 小时内死亡且肢体完整、晶核未挖的尸体炼成天赋血晶，**等级降一档**；每人只可吸收一枚 |
| **影分身** | A | 把属性 / 天赋 / 技能分割给分身；分身有独立面板，可升级、可上榜、可领榜奖 |
| **替死娃娃** | — | 代主死亡；每人使用不超过 3 次，第 4 次灵魂死去、身体被娃娃掌控 |
| **借尸还魂** | S 级持有 | 死亡 3 分钟内、晶核未被挖走的尸体可被附身并使用其天赋技能，但榜单显示的仍是灵魂本名 |
| **起死回生** | S | 复活 24 小时内死者，代价为 10000 × 死者等级点经验；晶核若被挖走则复活也失去天赋技能 |
| **二极变** | S | 两态切换：极小化时力量锁 1 点而精神翻百倍；巨人化时精神锁 1 点而力量翻百倍 |
| **主仆契约** | 可强化 | 普通契约经月渎石强化；强 1 版仅共享 1% 属性，共享天赋需强 7 版，且强化须辅以命运系道具、失败率高 |
| **死亡封印** | B | 把无战斗力的活人封印为死亡状态，绕开"不能交易活人"的限制 |

## 四、榜单与频道系统

| 项 | 规则 |
| :--- | :--- |
| **等级榜 / 杀戮榜** | 各记录 999 名 |
| **聊天频道** | 分世界 / 国家 / 区域三层 |
| **论坛** | 发帖需 10 枚 0 级晶核；榜强者免发帖次数、可置顶 |
| **交易系统** | 以物易物、**匿名** |
| **榜单奖励** | 第 1—999 名属性果；1—100 名蓝箱；1—10 名职业卷轴 / 秘境券；1—3 名紫箱；第 1 名绿晶 / 红晶；每 24 小时午夜 12:30 发放 |

### 4.1 绿晶与红晶

| 道具 | 效果 |
| :--- | :--- |
| **绿晶** | 抵挡一次致死攻击 |
| **红晶** | 无视等级造成致死 |
| **互斥** | 同场相撞时按概率一方失效 |
| **阵营互斥** | 在存在阵营对抗的秘境中，敌对阵营之间红晶 / 绿晶一律无效 |

> **结构价值**：一张"先手即定义规则"的底牌，把日常逻辑在副本里局部改写。**"规则可被道具改写"**是本书副本设计的地基。

| 等级 | 说明 |
| :--- | :--- |
| 七色常规 | 白 / 绿 / 蓝 / 紫 / 橙 / 红 / 金 |

## 六、秘境体系

### 6.1 进入方式

| 方式 | 性质 |
| :--- | :--- |
| **入场券** | 一次性门票；有主秘境需凑够人数才激活 |
| **令牌** | "VIP 会员卡"，可多次进入 |

### 6.2 秘境类型与规则

| 秘境 | 规则要点 |
| :--- | :--- |
| **恶龙与勇士** | 恶龙 200 人 / 勇士 1800 人；天赋封印、属性重置，恶龙属性为勇士十倍；恶龙不得离巢，勇士入巢满半小时且双方存活方可离开；限时 24 小时；**平局全员抹杀**。杀死公主并捏碎水晶球，可使天赋永久化带离秘境 |
| **屠龙勇士转恶龙** | 勇士击杀恶龙即自动转为恶龙阵营且属性更强；公主已死则链条中断 |
| **自在天** | 虚拟世界，死亡非真死但退出后冷却 24 小时；需门票进入、需定代号；通用货币"自在点"；竞技场需卖身契；擂台为车轮战，连胜方可赎身 |
| **食尸鬼巢穴** | 晶核爆率近 90%；"腐灵珠"实为喂食死灵系宠物的道具，可把食尸鬼催熟到 5 级乃至进化成 Boss |
| **命运之渊** | 凝聚命运之流，可换信息、化为攻击防御或实物道具；**凝聚失败会反噬自身** |
| **桌游秘境** | 有隐藏规则；打哈欠等日常动作也可能触发抹杀，豁免卡也救不了 |
| **永恒之塔 / 永恒竞技场** | 竞技场规则由**杀戮点少者**制定；输者全部杀戮点归胜者 |

### 6.3 秘境设计的三个通用手法

1. **阵营不对称 + 转换机制**：让"敌我"随时可互换，读者永远算不准下一章谁是谁；
2. **平局惩罚**：平局全员抹杀——逼迫选择而非观望；
3. **隐藏规则**：日常动作可能触发抹杀，**已知规则反而成了陷阱**。

## 七、职业者体系与转职

| 项 | 规则 |
| :--- | :--- |
| **职业星级** | 3 星 至 9 星 |
| **升级** | 固定属性 + 星级数自由点 |
| **卡点** | **不做职业任务则卡住无法升级**——强制角色进入剧情 |
| **隐藏职业** | 少数人 0 级即觉醒 |
| **转职属性上限** | 未转职上限 100，转职后 1000 |
| **等级压制** | 一转强者对未转职者有等级压制 |
| **觉醒条件** | 神源级血脉魂灵髓：78 处关节依次注入骨髓，**要求全属性 1000** |

> **结构价值**：职业任务是长线副本引擎；属性上限 100→1000 是一次明确的"换挡"，让中期战力有统一标尺。

## 八、位面体系与世界融合

| 层级 | 设定 |
| :--- | :--- |
| **低等位面** | 由数万平行世界融合而成 |
| **中等位面** | — |
| **高等位面** | — |
| **本源位面** | 自诞生即唯一、从无融合；位面顶端者可毁灭低中高等位面 |
| **世界融合** | 融合后产生"主场命运判定权"，因此千个世界同场竞技 |
| **世界主权秘境** | 通关可取得"执法者玉牌"——大圆包小圆时以小圆判主客场，故在秘境内仍为命运眷顾者，且**疑能免疫天罚** |

## 九、神眷者 / 神罚 / 清灵果

| 概念 | 规则 |
| :--- | :--- |
| **神眷者** | 极少数受神明眷顾者；次元生物会自动远离；击杀必掉清灵果 + 神明祝福，并触发全球"神罚"任务 |
| **月神祝福** | 消除头顶等级榜文字与神罚定位；**击杀月神眷顾者的人本人不可用** |
| **清灵果** | 每日可吸收晶核数 +1；本质是提升神魂，可突破四维属性上限（每颗 ≈10 点上限） |
| **神罚任务** | 杀神眷者即开启，全球公开该玩家实时位置坐标，击杀者领奖 |
| **天罚** | 累计第三次击杀神眷者引来天罚；**天罚反哺属性**，普通人天罚下无法动弹，神眷者可勉强行动 |

> **结构价值**："杀神眷者 → 被全球通缉 → 天罚反哺" 是一条**自我加压的收益循环**，把"变强"和"被追杀"焊在同一条线上。

## 十一、禁石 / 决斗 / 食言球

| 道具 | 三态 / 规则 |
| :--- | :--- |
| **禁石** | **固态**：范围内屏蔽天赋技能（半径约 5 米）→ **液态**：需"逆转水火"造出，可注入剥夺全部天赋技能 → **气态**：呼吸吸入即失天赋技能（生化武器） |

## 十二、核心金手指：焚尸掠夺的完整规则

这是全作的机制核心，也是本次复刻**唯一被继承的抽象骨架**。

### 12.1 规则链

```
火球接触尸体
   ↓
瞬间焚尽（连渣不剩，速度远高于同级别火焰天赋）
   ↓
掠夺死者生前属性（+0.1 / +1 …）
   ↓
掠夺死者天赋（掠夺等级越高者，天赋越强）
   ↓
掠夺死者技能
```

| 约束 | 内容 |
| :--- | :--- |
| **对活物无效** | 火球打中活人毫无伤害（主角前期被当作废物、遭队友抛弃的原因） |
| **速度是核心卖点** | 焚尸速度极快，"连渣都没剩"，与 A 级龙炎爆"只炸成焦尸"形成对比 |
| **掠夺效率与死者等级挂钩** | 强者尸体才有价值 |
| **重构能力** | 焚尸所得可"十合一"融合成更高级的火球；进一步可融合生死太极、逆能，演化出"模拟天赋"等第三形态 |

### 12.2 三次质变

| 阶段 | 能力 | 意义 |
| :--- | :--- | :--- |
| 一阶 | 焚尸 + 掠夺属性/天赋/技能 | **能力** |
| 二阶 | 进化版火球 / 融合道具 | **量变** |
| 三阶 | 融合生死太极 + 恐怖逆能 + **模拟天赋** | **质变**：从"夺取"升级为"成为" |

> **结构价值**：三段式升级的经典范式——先给能力，再给量，最后给质变，且质变素材来自**敌方机制**（吞并对方的规则来变强），这让每一场战斗都有长尾收益。

## 十三、叙事结构特征（量化）

### 13.1 章末钩子类型分布（基于 301—400 章 100 章末句实测）

| 钩子类型 | 占比 | 说明 |
| :--- | :--- | :--- |
| **悬念 / 谜团（问句式）** | ≈52% | 本书最主力钩子，末句常用反问与待解之谜收束 |
| **信息差 / 内幕** | ≈23% | 用"他不知道的是…"提前剧透，制造读者优越感 |
| **反转 / 打脸** | ≈15% | 末句直接推翻上一章的判断 |
| **危机 / 死亡逼近** | ≈5% | 少用，但每次都是高潮章 |
| **新角色 / 新势力登场** | ≈3% | 以人物入场作为断点 |
| **倒计时 / 规则限定** | ≈2% | 极稀缺 |

> **结论**：本书几乎不用"倒计时式"钩子。爽点常落在**章中**（如夺玉牌、破棺、抢人头），钩子留给下一章的信息揭示。
> **这正是短剧改编必须反转的地方**——短剧的付费卡点必须落在"章末动作中断"，而不是"章末疑问"。

### 13.2 篇章递进模型

全书 830 章可归纳为**四段式循环 × 多次套娃**：

| 阶段 | 主角状态 | 爽点类型 |
| :--- | :--- | :--- |
| **滚雪球期** | 个人战力速成 | 秒杀 |
| **代价期** | 每一步都在还债（复活代价、契约失败、天罚） | 布局 |
| **信息期** | 用预知 / 情报换主动权 | 预判 |
| **格局期** | 个人战力让位于世界格局 | 文明级博弈 |

每个副本内部又套用同一循环，因此**长线不塌**。

## 十四、作者自述与创作观（终章后记）

* **完本体量**：830 章 / 245 万字，跨度约两年；
* **创作自述核心**：作者在后记中反复强调三点——
  1. **故事是时间的产物**，写作与读者的陪伴是双向的；
  2. **不完美也是作品的一部分**，回头看仍有大量想改的地方，但不后悔；
  3. **写作是为了让读者快乐**，不是逃避现实；
* **收尾方式**：终章（826—830）以"还天碑于生灵"完成世界观闭环，并留下明确续写接口。

## 十五、总结：这本书最值得学的三件事

| # | 手法 | 为什么有效 |
| :--- | :--- | :--- |
| **1** | **把"焚尸"做成有明确边界的规则**（对活物无效） | 天赋自带弱点，主角前期合理地被当作废物，反转空间巨大；同时规则一目了然，短剧改编成本极低 |
| **2** | **"变强"与"被追杀"共用一条收益线**（杀神眷者 → 全球通缉 → 天罚反哺） | 爽点与压力同时结算，长线不疲劳 |
| **3** | **高阶位面只做侧写不登场**（天碑震动、校长误判） | 极低成本抬高主角，且不破坏力量上限，可无限复用 |

> 逐条「可继承 / 不可搬用」的判定与本剧的实际改写落点，见
> [`03_机制提炼与复用边界.md`](03_机制提炼与复用边界.md)。
