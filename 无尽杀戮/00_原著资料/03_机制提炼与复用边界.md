# 机制提炼与复用边界

> **本文档是本项目的合规基准。**
> 目的：把源著《无尽杀戮：我的火球有bug！》拆解为「可继承的结构骨架」与「不可搬用的具体表达」两层，
> 并给出《末世火葬工》的**实际改写落点**，确保成品是独立作品而非换皮。

---

## 一、判定方法

对源著的每个机制，按三条标准判定归属：

| 标准 | 说明 |
| :--- | :--- |
| **抽象性** | 是"一种通用的故事机制"，还是"这本书专用的名词与数值"？ |
| **识别度** | 换掉名字后，观众还能认出来吗？认得出 = 不可搬用 |
| **表达依赖** | 它是否依赖源著的专有名词、人物、视觉符号才能成立？ |

### 三类归属

| 类别 | 定义 | 处理方式 |
| :--- | :--- | :--- |
| **A 类·结构件** | 抽象的叙事机制，换皮后仍是好机制 | **直接继承结构，改写表达** |
| **B 类·可借设备** | 具体的道具 / 规则形态，有用但必须重做外壳 | **借功能，不借形态** |
| **C 类·源著独有** | 与源著世界观、人物、情节强绑定 | **一律不用** |

## 二、A 类 · 可继承的结构件（本作已采用）

| # | 结构件 | 源著形态 | **《末世火葬工》改写落点** |
| :--- | :--- | :--- | :--- |
| A1 | **"攻击手段与目标类型强绑定"** | 攻击只对特定目标类型生效 | **余烬只焚死者，对活物火苗自灭**（第 06 集专门用一整集演示这个限制） |
| A2 | **"从死者身上夺取力量"** | 焚尸掠夺属性 / 天赋 / 技能（抽象动作） | **焚尸继承骨纹**，同一抽象动作，产出物换成"骨纹槽" |
| A3 | **"主角先知（时间差）"** | 重生回到灾变降临那一刻 | **从火化炉醒来，回到灰潮前七天**——先知来源与金手指同源，解释力更强 |
| A4 | **"规则可被局部改写"** | 卡牌 / 律令类道具改变局部规则 | **律条撕下即改写一片区域的规则**；且**使用即受该规则约束**（撕缄默的人也说不出话） |
| A5 | **"公共悬赏把强者变成靶子"** | 击杀稀有特权者 → 全球公开其位置 → 引来规则反噬 | **潮主被现世即全城点名**；官方通缉与民间围猎并存 |
| A6 | **"副本规则博弈"** | 阵营对抗型 / 桌游型 / 规则兑换型秘境等 | **骨窖五层**，每层一条规则，各层规则互不相同 |
| A7 | **"货币即战利品"** | 掉落物 = 经验 + 交易货币 | **骨价**——骨骸是硬通货，等级决定价格 |
| A8 | **"双榜 / 名录"** | 双榜并行，各记 999 名 | **潮名录**，且分官方版与民间版，**两套长期互相造假** |
| A9 | **"高阶位面只做侧写不登场"** | 高阶位面以器物异动、强者误判等方式侧写，从不实体登场 | **白骨原**同样只做侧写与远景，实体到第 86 集才正式进入 |
| A10 | **"阵营不对称 + 平局抹杀"** | 恶龙 200 / 勇士 1800，平局全员抹杀 | **双潮交汇**：两条规则同时生效相乘，无"平局"选项 |
| A11 | **"规则产物可被认主"** | 秘境外规则 / 玉牌 / 骨骸认主 | **律条认主** + **骨窖主**制度 |
| A12 | **"日常动作触发隐藏规则"** | 规则型秘境中，打个哈欠即抹杀 | **骨窖「哑窖」每上一层遗忘一条私人记忆**——"说话"本身就是代价 |
| A13 | **"三段式能力进化：给能力 → 给量 → 给质变"** | 火球 → 融合 → 模拟天赋 | **余烬 → 复燃 → 窑火 → 骨窑 → 白骨** |
| A14 | **"通关即取得判定权道具"** | 通关后可获得一件"判定权"道具 | **潮名录的"留名"律条**——可替死者留名一次，身份与叙事双重用途 |

## 三、B 类 · 可借功能、必须重做外壳

| # | 源著设备 | 借了什么功能 | **本作替代物** | 为什么必须换 |
| :--- | :--- | :--- | :--- | :--- |
| B1 | 规则卡牌类道具 | 一件道具改一条规则 | **律条**（缄默 / 裁断 / 同源 / 孪生 / 价平 / 留名 / 无主 / 倒计） | 卡牌意象与原作绑定；"律条"贴合殡葬与规章的本作语感 |
| B2 | 通用掉落物 | 通用的掉落物与货币 | **骨价 / 骨骸收藏数** | 避免使用源著那个一眼可辨的掉落物名词 |
| B3 | 数据化面板 | 需要给观众一个可读的进度条 | **四维改成"体魄 / 血气 / 影速 / 骨性"** | 四维命名直接对应原作；改成殡葬语境后更贴主角职业 |
| B4 | 字母等级制 | 视觉化的强弱分级 | **骨纹一至九纹** | 字母等级是原作最易识别的符号；改用纹数后可做纹路生长特效 |
| B5 | 稀有特权者与惩罚机制三段式 | 稀有特权者与惩罚机制 | **潮主 / 潮罚** | 三段式世界观自洽度太高，改名搬家极易露怯 |
| B6 | 世界观升维玩法 | 世界观升维 | **双潮交汇** | 源著后期主线关键词不可沿用；改成本剧自有的双潮叠加，且**叠加规则相乘**是全新机制 |
| B7 | 一次性免死道具 | 一次性免死道具 | 律条体系内的代价机制（撕规则即受规则约束） | 免死道具会让"归档"这件事失去重量 |
| B8 | 副本入场券 / 令牌 | 进入副本的两种凭证 | **骨窖的"窖引"**（一次性）与"窖籍"（常客） | 借用"一次性 / 长期"的功能差，命名换掉 |
| B9 | 规则产物认主 | 道具兼作身份证明 | **律条认主** | 同上 |
| B10 | 越古老越强的道具系 | 用物件年代感做强度分级 | **"骨龄"**——骨骸的存世年代越久，继承到的骨纹越强 | 保留"古物更强"的世界观逻辑，命名与体系全换 |

## 四、C 类 · 源著独有，一律不用

### 4.1 判定原则

C 类 = **识别度过高、改名即露怯**的具体表达。四条排除规则：

1. **专有名词**：源著的体系名、道具名、场所名、组织名、术语——全部替换，不做近似改写。
   > 完整名词清单见内部档案 `00_原著资料/04_禁词与人物黑名单.md`（本地，不公开）。
   > **本文档刻意不列出这些名词**——一份公开的禁词清单等于替源著做了一次完整的名词登记。
2. **人物**：源著的具名角色一律不沿用。本剧全部角色为独立命名，与源著无对应关系（不对位、不影射、不改编自任何源著角色）。
3. **情节对应**：凡**结构相同 + 表达相同**的对应关系，均判定为不可用。本剧与源著的共同点**仅限"焚尸掠夺"这一动作本身**；
   凡涉及**场景、事件序列、人物关系、规则组合、结局处理**，一律独立设计。
4. **作者自述**：源著后记中的具体创作事件、书名、章节标题一律不引用。

### 4.2 已规避的高风险对应关系（示例）

| 源著做法 | 不可对应理由 | 本剧的处理 |
| :--- | :--- | :--- |
| 特定公共建筑内的开局 + 抢人头首杀 | 场景与事件序列高度可识别 | **殡仪馆火化间 + 炉中自己的尸体**，开场对象完全不同 |
| 金手指前期被同伴抛弃 | — | 本剧**无任何同伴背叛情节**；主角从第 1 集起就是独狼，困境来自"只剩七天" |
| 全球公告作为固定仪式 | 源著标志性桥段 | 本剧**不做全球公告**；改为纸质名录与民间抄本 |
| 平行体作为系统强制任务 | 源著核心设定之一 | **不采用**。终局是"自愿焚己完成归档"，与平行体无关 |
| 影子分身作为常规战术 | — | **不采用** |
| "稀有特权者掉落 → 全球公开坐标 → 反哺"三段式 | 体系自洽度过高 | 改为**潮主现世即被全城点名**，但**没有掉落、没有反哺** |
| 开箱即作用于本人的黑色盲盒 | — | **不采用** |
| 终局"击杀平行体"通关 | — | **不采用** |
| 结盟势力逐个倒戈的收编流 | — | 本剧的收编压力来自**裴烈的账本理念**，不是逐个势力倒戈 |
| 副线契约 + 道具辅助的"双主角镜像" | — | 本剧镜像关系是**焚 / 缝**的能力对立，不是主副线分工 |

> **自检方式**：发布前用内部黑名单执行关键词扫描，命令见
> `00_原著资料/04_禁词与人物黑名单.md` §四。

## 五、本剧的原创增益（在 A 类骨架之上自行加的）

原作的焚尸掠夺是**纯收益**——没有代价，所以主角可以无限强。本剧为其加了一条**贯穿全剧的代价线**：

| 层 | 原作 | **本剧** |
| :--- | :--- | :--- |
| 能力代价 | 无 | **忆蚀**：每继承一道骨纹，死者最后一段记忆灌入主角 |
| 副作用表现 | 无 | 症状递进：闪回 → 口音串味 → 双人格 → 主动放弃抵抗 |
| 人设后果 | 无 | 主角**主动黑化一次**（第 68 集），再被拉回（第 91 集） |
| 与主角的关系 | 无 | 女主【缝合】可**验魂**——她是唯一能看出"他还是不是他"的人 |
| 主题落点 | 无 | 终局把"焚己"变成**唯一解**：不死记代价，就烧不干净自己 |

> 这一层既是原创增益，也是短剧最需要的**情绪引擎**：
> "爽"与"痛"同时结算，观众才会追。
