# 竖屏微短剧《末世火葬工》一百集分卷与分集核心大纲

> **全部为原创剧情。** 改编自《无尽杀戮：我的火球有bug！》的**机制骨架**（焚尸掠夺），
> 人物、事件、走向、钩子设计均为独立创作，未沿用原作任何情节。

## 〇、本文件怎么用：三层坐标

本文件是**施工图**，不是故事梗概。三层坐标自上而下依赖，下层不得推翻上层：

| 层 | 内容 | 作用 |
| :--- | :--- | :--- |
| **层一 · 时间轴** | 全剧日期、每卷时钟、截止日 | 决定"这集发生在什么时候、还剩几天" |
| **层二 · 卷级结构卡** | 每卷四阶段、卷末状态、情绪目标 | 决定"这一卷分几段、每段干什么" |
| **层三 · 逐集施工卡** | 每集 6 个固定字段 | 决定"这集具体拍什么、交棒给谁" |

### 逐集施工卡的字段约定

| 字段 | 含义 | 写作纪律 |
| :--- | :--- | :--- |
| **集** | 集号 + 小标题 | 集号是**基准编号**，与 `06_映射表` 严格一致，不可移动 |
| **日期** | 该集故事内日期 | 全部落在层一时间轴内，不许出现无归属日期 |
| **在场** | 本集出场的有名角色 | 超过 4 人即为群戏，需单独排期 |
| **承接 → 回答** | 上集留下的悬念 → 本集给出的答案 | **必须闭合**；本集没答的写进"交棒" |
| **本集必须发生** | 事件 + 钩子 | 一集只允许一个主事件、一个钩子 |
| **代价** | 火／忆蚀／身体／关系的损耗 | **每次出现火必须在此栏扣一笔**，空着即不合格 |

### 编号基准声明

- **本文件的 01—100 是基准编号**，`06_原著至短剧改编映射表.md` 的 100 集四拍与之一一对应。
- `02_剧本样章/第01-08集` 是**试播重排版**：样章为了短剧留存，把部分事件前置了 2—5 集，
  因此样章"第 N 集"≠ 本文件"第 N 集"。对照见 **§五、样章对应关系**。

## 一、层一 · 全剧时间轴

### 1.1 世界时钟

| 规则 | 内容 | 出处 |
| :--- | :--- | :--- |
| **灰潮周期** | 每 **14 天**，全球随机出现一片灰雾 | 设定 §1.1 |
| **点名** | 灰雾所及即被点名，名字进入潮名录，开始倒计时 | 设定 §1.2 |
| **归档期限** | 被点名后 **14 天**内必须完成归档；逾期不归档 → **灰奴化**（不可逆，但窑火仍可归档） | 本文件新增口径 |
| **灰奴化** | 逾期者的最终形态；石膏化、磨砂玻璃眼、只扑咬活物 | 设定 §1.1 |
| **潮罚** | 被规则抹除：无尸、无骨、无痕，名字从名录上**除名** | 设定 §7.2 |

> **14 天同时是灰潮周期与归档期限**，所以：**每个灰潮日，也正是上一批点名者的 deadline。**
> 这条算术是全剧时钟的总开关。

| 卷 | 集数 | 卷名 | 故事日期 | 卷时钟 | 截止日 | 卷级爆点 |

### 1.4 "头七"释义

卷一前 14 集发生在灰潮降临前的 **7 天**（10/14—10/20）——火葬行做七的**头七**。
陈野职业世界的行话，正好是全剧的倒计时。10/21 灰潮落地，"头七"结束。

## 二、层二 · 卷级结构卡

### 卷一 · 头七（01—25）｜ 10/14 — 10/28

> **卷核心**：灰潮降临前七天，陈野在火化炉前死过一次。他知道会发生什么，但没人相信他——直到第一场灰雾落地。

| 阶段 | 集 | 任务 | 阶段末状态 |
| :--- | :--- | :--- | :--- |
| **A · 规则** | 01—08 | 建立「点名—归档」机制；亮能力边界（火只认死人）；苏晓棠、阿飞入场 | 观众懂了：被点名会变灰奴，烧掉才能停 |
| **B · 证词** | 09—14 | 建立「归档土法」与名录规则；纪梵、赵岚入场；主角身世第一次自曝 | 观众懂了：他已经死过一次 |
| **C · 落地** | 15—20 | 正式灰潮、大规模焚尸、主角底线立住、忆蚀初显、田坤入场 | 观众懂了：烧人救城，代价是他的自我 |
| **D · 不可焚** | 21—25 | 裴烈线索浮出、烧掉师父、潮主诞生、焚潮主 | 观众懂了：有比灰奴更烧不掉的东西 |

**卷末状态**：陈野升二阶【复燃】，身上背了第一层"城东的灰"；老沈已死且骨骸下落不明；官方把他记成潜在危险；11/04 的全城 deadline 压在他一个人身上。
**卷末情绪目标**：观众开始**替主角数日子**。

---

### 卷二 · 骨窖（26—50）｜ 10/29 — 11/04

> **卷核心**：骨窖是灰潮时代的地下竞技场。陈野在这里第一次遇见了**烧不掉**的东西——而那个东西，正是他最想救的人。

| 阶段 | 集 | 任务 | 阶段末状态 |
| :--- | :--- | :--- | :--- |
| **A · 换骨集市** | 26—32 | 骨窖产业规模亮相；纪梵摊主身份；陈野用规则反坑裴烈的人 | 骨窖=规则博弈场，不是副本刷级 |
| **B · 哑窖** | 33—40 | 记忆作为代价；苏晓棠【缝合】补记忆接口；赵岚上司线开启 | CP 关系建立；能力盲区（烧不掉）摆上台面 |
| **C · 潮汐井** | 41—47 | 窖内时间不同步；赵岚【秩序】强行"既定"归档完成 | 规则可以被写出来 |
| **D · 塌窖** | 48—50 | 骨窖崩塌，忆蚀全面失控；苏晓棠缝回他 | 体内多出"裴烈" |

**卷末状态**：陈野失去一段记忆（不认得苏晓棠），体内住进裴烈的声音；出窖时 11/04 已到。
**卷末情绪目标**：观众意识到**他已经不完全是他自己**。

---

### 卷三 · 双潮（51—75）｜ 11/04 — 11/07

> **卷核心**：裴烈登场。他和陈野焚的是同一把火，区别只在于——裴烈焚"有用的"，陈野焚"该焚的"。而这一卷，是陈野往裴烈那边走的一卷。

| 阶段 | 集 | 任务 | 阶段末状态 |
| :--- | :--- | :--- | :--- |
| **A · 秩序对撞** | 51—54 | 裴烈【骨库】与赵岚【秩序】开战；陈野成为全城出价对象 | 反派理念正式落地 |
| **B · 越界** | 55—60 | 陈远现身（裴烈改造品）；陈野第一次烧活人；城东被裴烈承包 | 主角越过底线，代价是舆论 |
| **C · 倒计时** | 61—67 | 忆蚀数到第四层人；双潮交汇 24 小时；田坤之死 | 观众第一次替裴烈说话 |
| **D · 底牌** | 68—75 | 老沈当年推他进炉；赵岚倒戈；亲手烧掉田坤 | 他烧的第一个人"不是他" |

**卷末状态**：升四阶【骨窑】的资格到手；体内五层记忆，第三层是他自己的死亡记忆。
**卷末情绪目标**：观众意识到**这个主角已经走得太远了**。

---

### 卷四 · 白骨原（76—100）｜ 11/07 之后（时间失效）

> **卷核心**：真相只有一个——灰潮不是天灾，是**点名**。而被点到的第一个人，是陈野自己。

| 阶段 | 集 | 任务 | 阶段末状态 |
| :--- | :--- | :--- | :--- |
| **A · 真相** | 76—79 | 炉里的人是谁；地球是骸骨；【无主】的条件 | "自愿归档"第一次出现 |
| **B · 抉择** | 80—84 | 陈远真伪；苏晓棠缝人；裴烈要吞白骨原 | 两条终局路线并置 |
| **C · 焚规则** | 85—93 | 进入白骨原；焚【潮罚】；身体成灰；纪梵代死 | 时间规则失效，主角身体开始报废 |
| **D · 大葬** | 94—100 | 裴烈之死；万道记忆回流；自愿焚己 | 灰潮停；第二季钩子 |

**卷末状态**：陈野自愿焚己完成大葬，灰潮停止；苏晓棠缝下的最后一针收线。
**卷末情绪目标**：观众要的不是"赢了"，是**"他终于自己做了一次决定"**。
