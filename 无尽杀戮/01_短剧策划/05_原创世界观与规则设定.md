# 《末世火葬工》原创世界观与规则设定

> **本文档为全原创设定。** 改编自《无尽杀戮：我的火球有bug！》的**机制骨架**（焚尸掠夺），
> 但世界观、命名体系、人物、剧情走向、能力代价全部重新设计，未沿用原作任何专有名词与情节表达。
>
> 本文档是短剧《末世火葬工》全案的**设定母本**，人物档案 / 分卷大纲 / 剧本样章均以此为准。

---

## 一、灾变设定：灰潮

### 1.1 表层叙事

每隔 **14 天**，全球会随机出现一片**灰雾**。灰雾所及之处，人会开始异变成**灰奴**——皮肤灰白、眼球浑浊、失去自我意识，只对活物的体温产生反应，只做一件事：**扑、咬、拖走、归档**。

官方称其为"灰潮期"，每隔十四天来一次，像潮汐一样准。

### 1.2 真相设定（分四层揭示）

| 层 | 揭示时机 | 内容 |
| :--- | :--- | :--- |
| 表层 | 卷一 | 灰雾杀人，人会变灰奴，官方在管 |
| 二层 | 卷二 | 灰奴不是"被感染"，是"未被归档"——凡被灰雾浸过，灵魂就被潮标记，必须死一次、留下骨骸，才能停 |
| 三层 | 卷三 | 两次灰潮可以叠加，规则相乘，死亡率指数上升。有人在人为制造"双潮" |
| 四层 | 卷四 | 地球本身就是一具巨大的骸骨。灰潮是这具骸骨**翻身时抖落的骨屑**。所谓拾骨者，是被这具骸骨"认领"过的人 |

### 1.3 灾变的核心恐怖

不是"怪物咬人"，是**"杀不死"**。

被灰雾浸过的人不会自然死亡，会一直灰化、一直饥饿、一直拖人下水。要让他停下来，只有一个办法：**给他一个结局，让他的骨骸落地。**

于是整部剧的核心问题不是"怎么活下去"，而是——

> **人死了以后，那具骨骸，归谁？**

## 二、拾骨者体系

### 2.1 觉醒

第一场灰潮过后，全球约 **12%** 的人身上开始生长**骨纹**——灰白色的纹路沿骨骼蔓延，可被"骨血"驱动。这批人被称作**拾骨者**。

非拾骨者占 88%。他们数量庞大，是绝大多数冲突与悲剧的来源：普通人是负担、是资源、是可以被"归档"换骨价的对象。

### 2.2 骨纹品阶（视觉化 1—9 纹）

不用字母等级，用**纹数**，可直接做视觉特效与分镜。

| 纹阶 | 称谓 | 占比（约） | 视觉 |
| :--- | :--- | :--- | :--- |
| 一纹 | 初醒 | 40% | 腕骨一点灰纹 |
| 二纹 | 正骨 | 25% | 小臂半圈 |
| 三纹 | 骨师 | 18% | 上臂 + 肩胛 |
| 四纹 | 骨将 | 10% | 半边躯干 |
| 五纹 | 骨侯 | 4.5% | 半身 |
| 六纹 | 骨座 | 1.8% | 全身主纹 |
| 七纹 | 骨宗 | 0.6% | 主纹带副纹 |
| 八纹 | 骨极 | 0.09% | 双色骨纹 |
| 九纹 | 骨冠 | 0.01% | 全身覆纹，骨纹自发鸣 |

### 2.3 四维属性

替代常规力量/体质/速度/精神，用**殡葬语境**的四维：

| 属性 | 含义 | 通俗说法 |
| :--- | :--- | :--- |
| **体魄** | 抗打压能力 | 扛不扛得住 |
| **血气** | 续航与恢复 | 能撑多久 |
| **影速** | 身法与闪避 | 跑不跑得掉 |
| **骨性** | 能力强度与规则亲和 | 你的骨纹有多听话 |

### 2.4 面板视觉模板

```
┌─────────────────────────────┐
│ 陈野            拾骨者 · 二纹 │
│ 体魄 4  血气 3  影速 6  骨性 2 │
│ 骨纹槽：余烬·残 ×1          │
│ 归档：3  骨价：12            │
└─────────────────────────────┘
```

## 三、主角天赋：余烬

### 3.1 来源（与金手指同源的设计）

陈野是市殡仪馆的**遗体接运员**，干的是把"死人"从家里拉到医院、再拉进火化炉的活。

灰潮第一夜，他接了一具"意外死亡"的遗体，推进火化炉。炉门合上的瞬间灰雾灌了进来——**他在炉里被烧死了**。

再睁眼，他回到灰潮降临前的**第七天**。

> 这解释了三件事：他为什么懂规则（他死过一次）、他为什么有一手与焚尸绑定的能力（规则刻在他骨头上）、以及他为什么在殡仪馆而不是别的地方醒来（火化炉是他的"出生点"）。

### 3.2 能力机制

| 层级 | 能力 | 说明 |
| :--- | :--- | :--- |
| 基础 | **焚尸** | 手心一点火种。对活物：火苗触及即熄，毫无伤害。对死者：一触即燃，烧尽成灰，不留残渣 |
| 基础 | **继承骨纹** | 焚尽的骨骸上残留"骨纹印"，可被吸入，成为自己身上的骨纹槽。每槽对应死者生前的一项能力或特性 |
| 判定 | **骨价** | 骨骸生前纹阶越高、执念越强，可继承的骨纹概率与品阶越高。普通尸骸只能榨出"体魄+0.1"这种碎屑 |
| 代价 | **忆蚀** | 每继承一道骨纹，死者的**最后一段记忆**会灌进陈野的脑子 |
| 代价 | **滑坡** | 忆蚀累积后，陈野会越来越难分清"我"和"他们"——这让他在某个节点开始接受"活人换骨骸"的效率逻辑 |

### 3.3 忆蚀：全剧最核心的内在冲突

这是本剧与普通"金手指爽剧"的分水岭，也是短剧情绪爆点的富矿。

**具体表现**（按继承数量递进）：

| 继承数 | 症状 | 短剧用法 |
| :--- | :--- | :--- |
| 1—3 道 | 零碎画面闪回；梦里叫不出亲人的名字 | 悬疑气氛 |
| 4—7 道 | 语气、习惯、口头禅开始"串味"；对陌生人产生莫名的熟络感 | 身份错位爽点 |
| 8—12 道 | 出现"双人格"对话；分不清今天是第几天 | 强钩子 |
| 13 道以上 | 主动放弃抵抗，认为"人本来就是一堆要还的骨" | 人设黑化转折 |

**关键台词锚点**（贯穿全剧）：
> "我不是在变强。我是在变成他们。"

### 3.4 五阶进化路径

| 阶 | 名称 | 能力 | 出现集数 |
| :--- | :--- | :--- | :--- |
| 一阶 | **余烬** | 焚尸、继承骨纹 | 01—25 |
| 二阶 | **余烬·复燃** | 被焚者短暂"回光"一次，重复生前最后一个动作或最后一句话 | 26—50 |
| 三阶 | **余烬·窑火** | 可在体外留存火种，形成"窑"，一次烧多具 | 51—70 |
| 四阶 | **余烬·骨窑** | 可焚**规则本身**——把一条律条烧成灰并据为己有 | 71—88 |
| 五阶 | **余烬·白骨** | 焚掉"死者自己"；完成归档 | 89—100 |

## 四、律条（规则道具）

灰潮凝结出的规则碎片，形如一片灰白骨签。撕碎即在一片区域内**改写一条规则**，只在该区域生效，区域边界外失效。

### 4.1 首批律条（剧本常用）

| 律条 | 规则 | 剧情用法 |
| :--- | :--- | :--- |
| **缄默** | 区域内不得出声，违者喉骨化灰 | 潜行、绝境、反杀 |
| **裁断** | 区域内一切伤害延迟结算，可一次性爆发 | 蓄力反杀 |
| **同源** | 区域内所有拾骨者骨纹同阶 | 强制拉平、反套路 |
| **孪生** | 区域内两人共享一条命 | 情感爆点 |
| **价平** | 区域内一切骨骸等价交换 | 黑市、博弈 |
| **留名** | 死者可在潮名录上留名一次 | 伏笔、身份揭示 |
| **无主** | 区域内无主骨骸归最先触碰者 | 抢骨、翻脸 |
| **倒计** | 区域内倒计时归零，全灭 | 极限逃生 |

### 4.2 使用代价

律条不是免费道具——**每撕一条，自己也会被这条规则约束**。撕【缄默】的人，在区域内也说不出话。

## 五、骨窖（副本）

地下的骨窖，每层一条规则，进窖者在规则内博弈求存。骨窖是灰潮时期的"地下竞技场"，各派系争夺入口与产物。

| 窖 | 名 | 规则 | 出场 |
| :--- | :--- | :--- | :--- |
| 第一窖 | **换骨集市** | 以骨骸为筹码的交易场，谁的骨价高谁说了算 | 26—32 |
| 第二窖 | **哑窖** | 全窖无声，且每上一层遗忘一条私人记忆 | 33—40 |
| 第三窖 | **潮汐井** | 窖内时间与外界不同步，出窖时外界已过三日 | 41—50 |
| 第四窖 | **满窖** | 全窖骨骸同时苏醒 | 67—75 |
| 第五窖 | **无主** | 没有骨窖主，只有进去没出来过的记录 | 86—94 |

## 六、潮名录（榜单）

记录"活下来的人"的册子，分**官方版**（收容局认证）与**民间版**（幸存者自行誊抄）两套，两套长期互相造假。

登记项：姓名、纹阶、战绩、**骨骸收藏数**。

- 区域名录 → 世界名录
- 上榜即被"看见"，是荣耀也是靶子
- 除名 = 社会性死亡，档案抹去、骨骸充公

---

## 七、潮主与潮罚

### 7.1 潮主

被灰潮完全同化的顶级拾骨者，成为一片区域的**规则化身**。他本身即一条规则：城东潮主能操纵灰雾，锅炉房潮主能无视距离杀人。

**潮主不可被焚。** 因为潮主没有骨骸——他是"规则"，不是"尸体"。

### 7.2 潮罚

违规者被规则抹除：**没有尸体、没有骨骸、没有残留。**

> 这是主角能力的核心盲区，也是本剧最好的结构性矛盾——**陈野能焚尽一切，却救不了被抹除的人**。赵岚队长的上司就是被潮罚抹掉的，她要陈野帮她"归档"一个根本不存在的人。

---

## 八、双潮交汇

两次灰潮在同一天、同一区域叠加，**两条规则相乘**：区域同时执行两条律条，且两条律条互相干扰、互相加成或抵消。

死亡率指数级上升。

裴烈的"收骨人"组织正在**人为制造双潮**——他需要混乱来收割骨骸。这是卷三的核心阴谋。

---

## 九、白骨原

地底深处。地球这具骸骨的**原初骨架**。

- 拾骨者的本质，是被这具骸骨"认领"过的人
- 灰潮是骸骨翻身时抖落的骨屑，十四天一次，永不停歇
- 要终结灰潮，必须完成一次**大葬**——把这具骸骨归档
- 大葬的条件：需要一个活着的人，被自己的火**完整焚尽**

### 与开局的闭环

陈野是"被自己的火烧过一次"的人。第一集他在炉里死过一次，那是灰潮给他的记号。终局他要再烧一次——但这一次是**自愿的、完整的、清醒的**。

> 全剧最后一句台词：
> "第一次是他们烧的我。这一次我自己来。"

## 十、视觉与合规改造

### 10.1 敏感元素替换表

| 原始概念 | 本剧合规形态 | 底层解释 |
| :--- | :--- | :--- |
| 尸体 / 焚尸 | **骨骸 · 归档 · 窑火** | 只表现"灰白骨骸在窑火中碎成灰白颗粒"，不出现血肉、内脏、缝合创口 |
| 怪物 | **灰奴** | 造型为"灰白陶俑化人形"，皮肤呈石膏质地、眼部为磨砂玻璃球、动作僵硬节律；**不使用写实丧尸妆** |
| 尸体特写 | **局部骨纹特写** | 惊悚点用"骨纹在骨骸表面游走"替代血腥 |
| 焚化过程 | **窑火 + 灰粒上升** | 火为暖橙白，灰为冷灰蓝，形成冷暖对冲的标志视觉 |
| 献祭 / 抹除 | **潮罚 · 归档** | 表现为"人在灰雾中被抹去轮廓"，不给断肢、不给血 |

### 10.2 标志视觉母题（全剧统一）

1. **手心一点火**——暖橙白，跳动但极小，越是高潮越亮
2. **灰白骨纹**——沿骨节生长的哑光纹路，继承时像墨水在宣纸上洇开
3. **冷暖对冲**——橙白火 vs 灰蓝雾，全片主色调
4. **窑门**——陈野的火化炉舱门，作为"重生起点"的视觉锚点，每卷至少出现一次

## 十一、机制对照（复刻边界说明）

> 本节为**类别级对照**，不逐条列举源著专有名词。完整对照与禁词清单见内部档案
> `00_原著资料/03_机制提炼与复用边界.md` 与 `00_原著资料/04_禁词与人物黑名单.md`（本地，不公开）。

| 维度 | 源著的处理方式 | 本剧的处理 | 归属 |
| :--- | :--- | :--- | :--- |
| 核心机制 | 以焚烧尸体为唯一攻击手段，从死者身上夺取力量 | 同一抽象骨架，但产出物改为"骨纹" | ✅ **唯一继承项** |
| 灾变来源 | 全球性规则降临，附带固定时间表 | 地球骸骨翻身，十四日一临的灰潮 | 原创 |
| 能力代价 | 无代价，纯收益 | **忆蚀**：继承即承受死者最后一段记忆 | 原创增强 |
| 分级体系 | 字母等级制 | 骨纹一至九纹（视觉可生长） | 原创 |
| 属性维度 | 常规体能四维 | 体魄 / 血气 / 影速 / 骨性（殡葬语境） | 原创 |
| 规则道具 | 规则卡牌 | **律条**：撕下即改写一片区域的规则，且使用即受其约束 | 原创 |
| 副本体系 | 多重秘境，规则各异 | **骨窖五层**，每层一条规则 | 原创 |
| 榜单 | 双榜并行 | **潮名录**，官方版与民间版互相造假 | 原创 |
| 终极威胁 | 后期升维玩法与规则反噬 | **双潮交汇 / 潮主 / 潮罚** | 原创 |
| 终局 | 击杀平行体的通关式收束 | **自愿焚己，完成"大葬"** | 原创 |
| 人物 | — | 陈野、苏晓棠、裴烈、纪梵、赵岚、陈远… | 全原创 |
| 视觉母题 | 火球 / 系统面板 / 掉落物 | 窑火 / 骨纹 / 潮名录 / 窑门 | 原创 |

> **结论**：全剧除"以焚烧尸体为唯一攻击手段，并从死者身上夺取力量"这一抽象机制骨架外，
> 不沿用源著任何具体表达。人物、命名、世界规则、叙事走向、视觉符号均为独立设计。
>
> 另需说明：本剧在骨架之上**新增了一条贯穿全剧的代价线（忆蚀）**，
> 使"变强"与"失去自我"同时结算——这是源著没有的，也是本剧的核心情绪引擎。
