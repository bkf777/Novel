# 《末世火葬工》原创世界观与规则设定

> **本文档为全原创设定。** 改编自《无尽杀戮：我的火球有bug！》的**机制骨架**（焚尸掠夺），
> 但世界观、命名体系、人物、剧情走向、能力代价全部重新设计，未沿用原作任何专有名词与情节表达。
>
> 本文档是短剧《末世火葬工》全案的**设定母本**，人物档案 / 分卷大纲 / 剧本样章均以此为准。

---

## 一、灾变设定：灰潮

### 1.1 表层叙事

每隔 **14 天**，全球会随机出现一片**灰雾**。灰雾所及之处，人会被**点名**——先是皮肤上出现灰斑，若在 14 天内没有完成归档，灰斑扩散，人就异变成**灰奴**：皮肤灰白、眼球浑浊、失去自我意识，只对活物的体温产生反应，只做一件事：**扑、咬、拖走、归档**。

官方称其为"灰潮期"，每隔十四天来一次，像潮汐一样准。

### 1.1.1 点名的四个阶段（观众可见的机制）

这是全剧最重要的一条规则，**必须在卷一第 1—6 集讲清楚**：

| 阶段 | 名称 | 触发 | 可逆？ | 观众可见标记 |
| :--- | :--- | :--- | :--- | :--- |
| 0 | 健康 | — | — | 无 |
| 1 | **被点名** | 灰雾撩到皮肤 | 可逆（归档即止） | **灰斑**：皮肤上一片灰白 |
| 2 | **逾期** | 被点名后 **14 天**未归档 | 不可逆（但窑火仍可归档） | 灰斑扩散、关节卡顿 |
| 3 | **灰奴化** | 逾期继续 | 不可逆 | 石膏化、磨砂玻璃球眼 |
| 4 | **归档完成** | 窑火处理 | — | 灰白骨骸 |
| 4' | **潮罚** | 灰奴化后仍逾期 | **不可逆、不可焚、无尸无骨** | 名录上**除名** |

> **14 天同时是灰潮周期与归档期限**，所以每个灰潮日，也正是上一批点名者的 deadline。
> 这是全剧时钟的总开关（见 `03_一百集分卷与分集核心大纲.md` §一）。

**灰奴不是另一种生物，是"归档失败的形态"**——同一个人，没走完流程。
所以掌心余烬烧不了他（他还没死透、还欠一次归档），**窑火可以**（窑火是归档仪式本身）。

### 1.2 真相设定（分四层揭示）

| 层 | 揭示时机 | 内容 |
| :--- | :--- | :--- |
| 表层 | 卷一 | 灰雾杀人，人会变灰奴，官方在管 |
| 二层 | 卷二 | 灰奴不是"被感染"，是"未被归档"——凡被灰雾浸过，灵魂就被潮点名，必须在 **14 天**内死一次、留下骨骸，才能停 |
| 三层 | 卷三 | 两次灰潮可以叠加，规则相乘，死亡率指数上升。有人在人为制造"双潮" |
| 四层 | 卷四 | 地球本身就是一具巨大的骸骨。灰潮是这具骸骨**翻身时抖落的骨屑**。所谓拾骨者，是被这具骸骨"认领"过的人 |

### 1.3 灾变的核心恐怖

不是"怪物咬人"，是**"杀不死"**。

被灰雾浸过的人不会自然死亡，会一直灰化、一直饥饿、一直拖人下水。要让他停下来，只有一个办法：**给他一个结局，让他的骨骸落地。**

于是整部剧的核心问题不是"怎么活下去"，而是——

> **人死了以后，那具骨骸，归谁？**

### 1.4 词条：归档（全剧核心术语）

> **归档 = 让一个被灰雾点过名的人，以被承认的方式离开这具身体——留下骨骸、写入名录、不再被灰潮继续点名。**

这一条定义同时解释六种用法：

| 用法 | 归属 |
| :--- | :--- |
| 窑火实焚（陈野的日常动作） | 归档的一种实现 |
| 名录入册（阿飞 / 潮名录） | 归档的第二种实现 |
| 规则宣告（赵岚【秩序】） | 归档的第三种实现：不用烧也能算归档 |
| 潮罚（被抹除） | **归档的失败态**——点了名却没被归档 = 不被允许存在 = 灰奴之源 |
| 大葬 | 把地球这具骸骨归档 = 终极归档 |
| 余烬·白骨（五阶） | 焚掉死者自己 = 自我归档 |

**四条正交轴**（缺一条就有一类情节悬空）：

| 轴 | 取值 | 决定什么 |
| :--- | :--- | :--- |
| **动作** | 实焚 / 入册 / 宣告 | 用什么方式让它离开 |
| **资格** | 谁有资格决定 | 救赎还是屠杀（骆红 vs 陈野） |
| **礼** | 有没有问最后一句话 | 保不保留"人"的部分（老沈 vs 裴烈） |
| **时间** | 被点名后多久必须归档 | **卷二、卷三的时钟**（14 天） |

**术语揭示节奏**（五级链，名字晚、机制早）：

| 集 | 观众获得 | 观众还不知道 |
| :--- | :--- | :--- |
| 01—02 | 灰斑＝被点名；不烧会变灰奴；烧＝归档 | 这套机制叫什么 |
| 06 | 「归档」＝烧给名录看，不是烧给活人看 | 名录是什么 |
| 08 / 13—14 | 名录上陈远、已归档；**归档日期=死期** | 谁在归档、为什么 |
| 44 | 除名＝潮罚，无尸无骨 | 灰潮为什么点名 |
| 96 | **灰潮不是惩罚，是点名** | — |

> **剧本层纪律**：第 01—06 集必须让观众看懂机制，**但"点名"这个词本身不许出现在卷一**——
> 它是第 96 集无主亲口揭开的底牌，提前说破等于烧掉全剧最后一次反转。

## 二、拾骨者体系

### 2.1 觉醒

第一场灰潮过后，全球约 **12%** 的人身上开始生长**骨纹**——灰白色的纹路沿骨骼蔓延，可被"骨血"驱动。这批人被称作**拾骨者**。

非拾骨者占 88%。他们数量庞大，是绝大多数冲突与悲剧的来源：普通人是负担、是资源、是可以被"归档"换骨价的对象。

### 2.2 骨纹品阶（视觉化 1—9 纹）

不用字母等级，用**纹数**，可直接做视觉特效与分镜。

| 纹阶 | 称谓 | 占比（约） | 视觉 |
| :--- | :--- | :--- | :--- |
| 一纹 | 初醒 | 40% | 腕骨一点灰纹 |
| 二纹 | 正骨 | 25% | 小臂半圈 |
| 三纹 | 骨师 | 18% | 上臂 + 肩胛 |
| 四纹 | 骨将 | 10% | 半边躯干 |
| 五纹 | 骨侯 | 4.5% | 半身 |
| 六纹 | 骨座 | 1.8% | 全身主纹 |
| 七纹 | 骨宗 | 0.6% | 主纹带副纹 |
| 八纹 | 骨极 | 0.09% | 双色骨纹 |
| 九纹 | 骨冠 | 0.01% | 全身覆纹，骨纹自发鸣 |

### 2.3 四维属性

替代常规力量/体质/速度/精神，用**殡葬语境**的四维：

| 属性 | 含义 | 通俗说法 |
| :--- | :--- | :--- |
| **体魄** | 抗打压能力 | 扛不扛得住 |
| **血气** | 续航与恢复 | 能撑多久 |
| **影速** | 身法与闪避 | 跑不跑得掉 |
| **骨性** | 能力强度与规则亲和 | 你的骨纹有多听话 |

## 三、主角天赋：余烬

### 3.1 来源（与金手指同源的设计）

陈野是市殡仪馆的**遗体接运员**，干的是把"死人"从家里拉到医院、再拉进火化炉的活。

灰潮第一夜，他接了一具"意外死亡"的遗体，推进火化炉。炉门合上的瞬间灰雾灌了进来——**他在炉里被烧死了**。

再睁眼，他回到灰潮降临前的**第七天**。

> 这解释了三件事：他为什么懂规则（他死过一次）、他为什么有一手与焚尸绑定的能力（规则刻在他骨头上）、以及他为什么在殡仪馆而不是别的地方醒来（火化炉是他的"出生点"）。

### 3.2 能力机制

| 层级 | 能力 | 说明 |
| :--- | :--- | :--- |
| 基础 | **焚尸** | 手心一点火种。对活物：火苗触及即熄，毫无伤害。对死者：一触即燃，烧尽成灰，不留残渣 |
| 基础 | **继承骨纹** | 焚尽的骨骸上残留"骨纹印"，可被吸入，成为自己身上的骨纹槽。每槽对应死者生前的一项能力或特性 |
| 判定 | **骨价** | 骨骸生前纹阶越高、执念越强，可继承的骨纹概率与品阶越高。普通尸骸只能榨出"体魄+0.1"这种碎屑 |
| 代价 | **忆蚀** | 每继承一道骨纹，死者的**最后一段记忆**会灌进陈野的脑子 |
| 代价 | **滑坡** | 忆蚀累积后，陈野会越来越难分清"我"和"他们"——这让他在某个节点开始接受"活人换骨骸"的效率逻辑 |

### 3.3 忆蚀：全剧最核心的内在冲突

这是本剧与普通"金手指爽剧"的分水岭，也是短剧情绪爆点的富矿。

**具体表现**（按继承数量递进）：

| 继承数 | 症状 | 短剧用法 |
| :--- | :--- | :--- |
| 1—3 道 | 零碎画面闪回；梦里叫不出亲人的名字 | 悬疑气氛 |
| 4—7 道 | 语气、习惯、口头禅开始"串味"；对陌生人产生莫名的熟络感 | 身份错位爽点 |
| 8—12 道 | 出现"双人格"对话；分不清今天是第几天 | 强钩子 |
| 13 道以上 | 主动放弃抵抗，认为"人本来就是一堆要还的骨" | 人设黑化转折 |

**关键台词锚点**（贯穿全剧）：
> "我不是在变强。我是在变成他们。"

### 3.4 五阶进化路径

| 阶 | 名称 | 解锁集 | 能力 | 代价 |
| :--- | :--- | :--- | :--- | :--- |
| 一阶 | **余烬** | 01 | 焚尸、继承骨纹 | 忆蚀 1—3 道 |
| 二阶 | **余烬·复燃** | 25 | 被焚者短暂"回光"一次，重复生前最后一个动作或最后一句话 | 忆蚀 4—7 道 |
| 三阶 | **余烬·窑火** | 50 | 可在体外留存火种，形成"窑"，一次烧多具 | 忆蚀 8—12 道 |
| 四阶 | **余烬·焚律** | 85 | 可焚**规则本身**——把一条律条烧成灰并据为己有 | 身体成灰 |
| 五阶 | **余烬·白骨** | 92 | 焚掉"死者自己"；完成归档 | 自我终结 |

> **命名避雷**：四阶能力名**不叫"骨窑"**——「骨窖」是全剧五层副本（卷二主线），
> 「余烬·焚律」是主角阶位。两者必须严格区分，公开文案与分镜中不可混用。
> 面板上的【骨纹槽：余烬·残 ×1】是**槽位名**，与阶位体系无关，不要一起改。

## 四、律条（规则道具）

灰潮凝结出的规则碎片，形如一片灰白骨签。撕碎即在一片区域内**改写一条规则**，只在该区域生效，区域边界外失效。

### 4.1 首批律条（剧本常用）

| 律条 | 规则 | 剧情用法 |
| :--- | :--- | :--- |
| **缄默** | 区域内不得出声，违者喉骨化灰 | 潜行、绝境、反杀 |
| **裁断** | 区域内一切伤害延迟结算，可一次性爆发 | 蓄力反杀 |
| **同源** | 区域内所有拾骨者骨纹同阶 | 强制拉平、反套路 |
| **孪生** | 区域内两人共享一条命 | 情感爆点 |
| **价平** | 区域内一切骨骸等价交换 | 黑市、博弈 |
| **留名** | 死者可在潮名录上留名一次 | 伏笔、身份揭示 |
| **无主** | 区域内无主骨骸归最先触碰者 | 抢骨、翻脸 |
| **倒计** | 区域内倒计时归零，全灭 | 极限逃生 |

### 4.2 使用代价

律条不是免费道具——**每撕一条，自己也会被这条规则约束**。撕【缄默】的人，在区域内也说不出话。

## 五、骨窖（副本）

地下的骨窖，每层一条规则，进窖者在规则内博弈求存。骨窖是灰潮时期的"地下竞技场"，各派系争夺入口与产物。

| 窖 | 名 | 规则 | 出场 |
| :--- | :--- | :--- | :--- |
| 第一窖 | **换骨集市** | 以骨骸为筹码的交易场，谁的骨价高谁说了算 | 26—32 |
| 第二窖 | **哑窖** | 全窖无声，且每上一层遗忘一条私人记忆 | 33—40 |
| 第三窖 | **潮汐井** | 窖内时间与外界不同步，出窖时外界已过三日 | 41—50 |
| 第四窖 | **满窖** | 全窖骨骸同时苏醒 | 67—75 |
| 第五窖 | **无主** | 没有骨窖主，只有进去没出来过的记录 | 86—94 |

## 六、潮名录（点名册 + 榜单）

一本册子，两种用途：

- **左栏 · 点名册**：被灰雾点名的人，名字 + 归档倒计时。这是官方版《潮名录》的正式内容。
- **右栏 · 骨骸榜**：纹阶、战绩、骨骸收藏数。民间抄本只抄这一栏，黑市靠它定价。

分**官方版**（收容局认证）与**民间版**（幸存者自行誊抄）两套，两套长期互相造假。

### 6.1 名录上的三种状态（术语必须区分，不得混用）

| 状态 | 含义 | 后续 | 典型出场 |
| :--- | :--- | :--- | :--- |
| **在册 · 待归档** | 被灰雾点名，倒计时中 | 期限内完成归档即止；逾期 → 灰奴化 | 全城大多数被点名者 |
| **已归档** | 完成归档，名字后盖归档日期 | 从灰潮名单上划掉，灰潮不再认他 | 陈野（01 集烧过前世的自己）、陈远（10/11） |
| **除名** | 名字被彻底抹掉 | **无尸、无骨、无痕** = 潮罚 | 赵岚上司（44 集） |

> **收口说明（2026-10-21 修订）**：早前版本把"除名"同时用作"已归档"与"被官方抹除"，
> 造成第 13—14 集与第 44 集语义相反。现统一为：
> **已归档 = 名字盖了归档日期；除名 = 名字被抹掉（潮罚）。**
> 大纲第 13—14 集已同步改为"已归档"。

### 6.2 其他既有规则

- 区域名录 → 世界名录
- 上榜即被"看见"，是荣耀也是靶子
- 民间版的"除名"另有含义（被人从黑市榜上划掉，骨骸充公），属黑市行话，与官方"除名"不是一回事

## 七、潮主与潮罚

### 7.1 潮主

被灰潮完全同化的顶级拾骨者，成为一片区域的**规则化身**。他本身即一条规则：城东潮主能操纵灰雾，锅炉房潮主能无视距离杀人。

**潮主不可被焚。** 因为潮主没有骨骸——他是"规则"，不是"尸体"。

### 7.2 潮罚

违规者被规则抹除：**没有尸体、没有骨骸、没有残留。**

> 这是主角能力的核心盲区，也是本剧最好的结构性矛盾——**陈野能焚尽一切，却救不了被抹除的人**。赵岚队长的上司就是被潮罚抹掉的，她要陈野帮她"归档"一个根本不存在的人。

---

## 八、双潮交汇

两次灰潮在同一天、同一区域叠加，**两条规则相乘**：区域同时执行两条律条，且两条律条互相干扰、互相加成或抵消。

死亡率指数级上升。

裴烈的"收骨人"组织正在**人为制造双潮**——他需要混乱来收割骨骸。这是卷三的核心阴谋。

---

## 九、白骨原

地底深处。地球这具骸骨的**原初骨架**。

- 拾骨者的本质，是被这具骸骨"认领"过的人
- 灰潮是骸骨翻身时抖落的骨屑，十四天一次，永不停歇
- 要终结灰潮，必须完成一次**大葬**——把这具骸骨归档
- 大葬的条件：需要一个活着的人，被自己的火**完整焚尽**

### 与开局的闭环

陈野是"被自己的火烧过一次"的人。第一集他在炉里死过一次，那是灰潮给他的记号。终局他要再烧一次——但这一次是**自愿的、完整的、清醒的**。

> 全剧最后一句台词：
> "第一次是他们烧的我。这一次我自己来。"

## 十、视觉与合规改造

### 10.1 敏感元素替换表

| 原始概念 | 本剧合规形态 | 底层解释 |
| :--- | :--- | :--- |
| 尸体 / 焚尸 | **骨骸 · 归档 · 窑火** | 只表现"灰白骨骸在窑火中碎成灰白颗粒"，不出现血肉、内脏、缝合创口 |
| 怪物 | **灰奴** | 造型为"灰白陶俑化人形"，皮肤呈石膏质地、眼部为磨砂玻璃球、动作僵硬节律；**不使用写实丧尸妆** |
| 尸体特写 | **局部骨纹特写** | 惊悚点用"骨纹在骨骸表面游走"替代血腥 |
| 焚化过程 | **窑火 + 灰粒上升** | 火为暖橙白，灰为冷灰蓝，形成冷暖对冲的标志视觉 |
| 献祭 / 抹除 | **潮罚 · 归档** | 表现为"人在灰雾中被抹去轮廓"，不给断肢、不给血 |

### 10.2 标志视觉母题（全剧统一）

1. **手心一点火**——暖橙白，跳动但极小，越是高潮越亮
2. **灰白骨纹**——沿骨节生长的哑光纹路，继承时像墨水在宣纸上洇开
3. **冷暖对冲**——橙白火 vs 灰蓝雾，全片主色调
4. **窑门**——陈野的火化炉舱门，作为"重生起点"的视觉锚点，每卷至少出现一次
