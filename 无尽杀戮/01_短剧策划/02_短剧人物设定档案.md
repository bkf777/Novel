# 竖屏微短剧《末世火葬工》人物设定档案

> **全部为原创人物。** 改编自《无尽杀戮：我的火球有bug！》的**机制骨架**，人物姓名、身份、关系、性格、成长线均为独立设计，未沿用原作任何角色。

## 二、主角

### 陈野 ｜ 男 · 26 岁

| 项 | 内容 |
| :--- | :--- |
| **身份** | 安州市殡仪馆遗体接运科，接运员（干过三年夜班） |
| **天赋** | 【余烬】一阶 → 五阶。手心一点火，只烧死者，烧尽成灰，继承其骨纹 |
| **外形** | 瘦高，常年深灰工装，手背有洗不掉的石灰白痕；左掌心一小片灰白骨纹（第一眼唯一不像普通人的地方） |
| **声音** | 低、平、句尾不抬。不解释，不邀功 |
| **关键词** | 脱敏 · 外科手术 · 欠债感 · 失控边缘 |

**性格底色**：他不是冷血，是**脱敏**——三年接运，见惯一百种死法，妻子的丧仪他也能一边流程一边在心里算下一趟的时间。灰潮给他天赋的同时，给了他一个更坏的礼物：他能"看"到尸体的**最后一段记忆**。

**核心矛盾**：他越强，越不像自己。

**短剧功能**：扮猪吃虎 + 视觉奇观载体 + 道德滑坡的观察者

**台词样例**（短、准、不废话）：
> "这具我烧。别动。"
> "我不是在变强。我是在变成他们。"
> "第一次是他们烧的我。这一次我自己来。"

**成长弧线**：
| 阶段 | 集数 | 状态 |
| :--- | :--- | :--- |
| 职业者 | 01—12 | 只敢烧"该烧的"，每烧一次都做噩梦 |
| 归档者 | 13—35 | 学会挑选骨骸，第一次主动放弃一个人 |
| 失控者 | 36—62 | 忆蚀累积，双人格对话，开始接受"效率"逻辑 |
| 半人 | 63—88 | 被苏晓棠拉住一次，主动烧掉一批"记忆"自保 |
| 执火者 | 89—100 | 主动焚己，完成大葬 |

## 三、女主

### 苏晓棠 ｜ 女 · 24 岁

| 项 | 内容 |
| :--- | :--- |
| **身份** | 同一间殡仪馆，遗体修复师（整容缝合） |
| **天赋** | 【缝合】——把碎掉的东西缝回去，可以缝魂；每缝一次，她自己的伤口也会裂开一道 |
| **外形** | 白大褂、护目镜推在额上、口罩；指尖永远缠着线头；手背有大量细密旧疤 |
| **声音** | 温柔、低、说话慢。全剧唯一不喊的人 |
| **关键词** | 执念 · 温柔 · 修补 · 不可替代 |

**核心欲望**：把灰潮第一天死的弟弟"缝"回来。她试过——缝出来的那个**会呼吸，但不认她**。

**与主角的镜像关系**：
> 陈野把死者烧成灰，苏晓棠把死者缝回来。
> 全剧只有这两个人能互为解药，也互为毒药。

**她为什么不可替代**：她是全剧**唯一能看出"陈野还是不是原来那个陈野"**的人。她的天赋能缝魂，也能**验魂**——陈野每继承一道骨纹，她都能看出多了一层。第 61 集她第一次对他说："你身上有四个人的记忆。"

**弧线**：
| 阶段 | 集数 | 状态 |
| :--- | :--- | :--- |
| 执念者 | 01—20 | 一心要缝回弟弟，不惜用活人做材料 |
| 同行者 | 21—45 | 与陈野结盟，第一次承认"缝不回来" |
| 验魂人 | 46—70 | 成为陈野的人形检测仪；代价是自己的身体缝了又裂 |
| 缝合者 | 71—95 | 放弃复活弟弟，把全部手艺用在"缝回陈野"上 |
| 收线者 | 96—100 | 最后一针缝的不是弟弟，是陈野 |

**台词样例**：
> "你烧的都是死人，可我刚才，摸到了你的心跳。你还活着吗？"
> "缝回来的东西会呼吸，会睁眼，但它不记得回家的路。"
> "最后一针，我缝的是你。"

## 四、双反派

### 裴烈 ｜ 男 · 43 岁 ｜ 大反派 · 理念型

| 项 | 内容 |
| :--- | :--- |
| **身份** | "收骨人"组织首领，前收容局外勤教官 |
| **天赋** | 【骨库】——把收来的骨骸拼成能动的临时战士；拼得越久，它们越像人 |
| **外形** | 极干净，白大褂无一丝褶皱，指甲修得一丝不苟，说话永远轻声 |
| **关键词** | 理性 · 账房 · 体面 · 不可理喻 |

**核心理念**（全剧最重要的对立面）：
> "人总会死。区别只在于，是你自己散掉，还是被别人拆开分掉。"
> "我不制造死亡，我只是让死亡变得有效率。"

**他为什么可怕**：他从不咆哮，从不动手动脚。他只是把"该归档的人"排好队，然后按顺序执行。他的队伍里没有疯子，只有**相信账本的人**。

**与陈野的分界线**：
| | 陈野 | 裴烈 |
| :--- | :--- | :--- |
| 焚的对象 | 该焚的 | 有用的 |
| 对活人 | 不为骨骸杀人 | 不为骨骸杀人，但为骨骸放弃救人 |
| 手段 | 一把火 | 拆件 + 拼装 |
| 结局 | 自愿焚己 | 被陈野烧成灰，骨纹全部还给他收集过的人 |

### 纪梵 ｜ 男 · 27 岁 ｜ 副手 · 悬疑核

| 项 | 内容 |
| :--- | :--- |
| **身份** | 裴烈副手、"替身" |
| **天赋** | 【易容】——换骨易形，可完美伪装成任何人；伪装时需承受对方的死法记忆 |
| **身份谜底** | 第 38 集揭示：真正的纪梵在第一场灰潮就死了。现在这个用的是他**哥哥的脸**——他哥哥是第一个被收容局"归档"的试验品 |
| **关键词** | 假面 · 替代 · 模仿 · 恐惧 |

**台词样例**：
> "我不是他。我从来都不是他。我只是没地方可去。"

## 五、血亲

### 陈远 ｜ 男 · 19 岁 ｜ 弟弟 · 道德困境核

| 项 | 内容 |
| :--- | :--- |
| **身份** | 陈野亲弟，建筑系大一学生 |
| **天赋** | 【共振】——感知结构应力，危机时能"听"到承重墙在呻吟 |
| **失踪** | 第 10 集，灰潮第三天，被裴烈带走做"骨种"试验 |
| **回归** | 第 60 集，已被改造成"半潮主"，能听见整座城市的骨骸在响 |
| **关键词** | 愧疚 · 血脉 · 不可对话 |

**核心矛盾**：陈野焚骨为生，陈远被裴烈改成了"骨的乐器"。第 78 集陈野要烧自己的弟弟时，全剧情绪最高点。

**台词样例**：
> "哥，你烧的都是死人。"
> "可我还记得你教我骑自行车。"

## 六、官方与体制

### 赵岚 ｜ 女 · 32 岁 ｜ 收容局现场处置三队队长

| 项 | 内容 |
| :--- | :--- |
| **天赋** | 【秩序】——在一定区域内强制"既定结果"：被击中的必然被击中，被挡住的必然被挡住 |
| **立场** | 从"你这是滥杀"到"我们需要一个能归档的人" |
| **个人线** | 她的上司被**潮罚**抹除——无尸、无骨、无痕。她求陈野帮她"归档"一个根本不存在的人 |

**短剧功能**：官方背书 + 理性制衡 + 女主之外的第二情感支柱

**台词样例**：
> "我上司被抹掉那天，地上连一滴血都没有。你告诉我，我该怎么归档？"
> "我不ask你犯法。我ask你一个更难的问题：谁有资格决定谁该被烧掉？"

### 骆红 ｜ 女 · 46 岁 ｜ 收容局局长

灰色立场：为了保住城市，可以牺牲一个区。代表**体制的复杂性**——她不是恶人，只是每次都选了代价更小的那条路。

## 七、师父与队友

### 老沈 ｜ 男 · 64 岁 ｜ 火葬馆老馆长 · 陈野的师父

- 知道"归档"的土法：焚前要问死者最后一句话，不问就烧，等于把人也烧了
- 灰潮前夜已被灰雾标记
- **第 22 集**：陈野亲手归档老沈——全剧第一场真正的"焚"，也是陈野的第一次忆蚀（他此后每晚都会梦到师父在炉前背过身去）
- 台词："小陈，师傅不怪你。**你记得把我烧干净点。**"

### 阿飞 ｜ 男 · 21 岁 ｜ 黑市掮客 · 情报核心

| 项 | 内容 |
| :--- | :--- |
| **天赋** | 【回声】——触碰物品，能听见死者留在上面的最后一句话 |
| **功能** | 情报来源 / 喜剧担当 / 关键真相揭露者 |
| **口头禅** | "这玩意儿上死过人——他说：'我恨死那个殡仪馆的了。'" |

### 田坤 ｜ 男 · 34 岁 ｜ 货运司机 · 肉盾

- 天赋【铁骨】：骨硬如铁，防御型，扛得住三轮车撞不碎
- 前刑满释放，殡仪馆门前拉过三天尸体，从此留下
- 义气担当 + 笑点担当
- 第 74 集为挡陈远被裴烈拆成骨件，成为陈野第一次失控的导火索

## 八、终局存在

### 「无主」 ｜ 白骨原 · 意识碎片

- 不是人，是地球这具骸骨残留的意识碎片
- **视觉形态（已锁定）**：骨白色人形骨骸，无皮肤血肉，胸腔为通透肋骨骨架并透出微弱暖橙火光，周身漂浮灰烬与骨屑
- 它在等一个**愿意被归档的人**
- 第 86 集揭示，第 99 集成为陈野焚己的推力
- 它没有恶意，它只是**很孤独**
- 台词："你回来了。我等了很久——烧干净一点，别让我剩下什么。"

## 九、人物关系的关键取舍（编剧须知）

1. **陈野 ≠ 冷血**。他对活人不下手，这是他和裴烈的**唯一**分界，前期必须反复强调，不能含糊。
2. **苏晓棠不是工具人**。她有自己的执念线（第 1—40 集独立推进），不能全程只围着男主转。
3. **赵岚不是洗白工具**。她的"秩序"天赋在第 30 集杀过陈野小队的人，第 44 集她自己也因此付出代价。
4. **裴烈不许降智**。他每次输都输在"他没算到人会为感情犯错"，而不是输在计谋。
5. **忆蚀必须可视**。第 30 集后，陈野每次用能力，观众都要能看到代价（手抖、瞳孔变色、口音变化），这是本剧留存的核心。
